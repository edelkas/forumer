#117400 6 2005-11-23T21:28:56Z Ixi
Actually, glitches aside, the Konigsberg level shouldn't be possible. It's a famous topology problem. Konigsberg is a city in Prussia intersected by a river with two islands in the middle. There are 7 bridges connecting the islands and the two banks (represented by those one-use door contraptions in the map) and for a long time, there was a question of whether one could walk across each of the bridges only once and return to where he started. A mathematician eventually proved that it was impossible. More in Wikipedia.

That's not really how open source works. A lot of games and programs have had their source code released--for example, Quake. But you don't hear about the game community being flooded with bad Quake clones. Modifying someone else's source code is a pretty tough task; the unsuccessful attempts wither into obscurity, leaving only a handful of really successful spinoffs. And those spinoffs succeed usually because they're different enough from the original game that they're worth playing for their own sake.

Besides, not everyone is going to directly modify the source code to come up with a new game. I, for one, am interested in looking at the physics and the game engine code, but if I used it, it would be to create my own original game.

So you're right in saying that the world only needs one N. And in the weeks after the source is released, you might see a couple of pathetic clones, but just ignore those and they'll die very quickly. But keep an eye out for the good ones.

N on handhelds and older consoles would be viable if M&R or a third party wrote a new graphics engine specifically for the platform--which they would have to do anyway, I'm pretty sure, because Flash only runs on computers. The only reason the computer version takes so much processing power is because Flash does all of its video rendering through software (i.e. CPU) and not hardware (i.e. graphics card). A platform-specific engine would take advantage of the console/handheld's graphics hardware, so N would need much less processing power. However, obviously this is a lot of work.
