Sorry if already exists, I am so tired I did not search the forums. Anyways, here is everything you need to know in order to make N userlevels without the editor, typing directly into the userlevels.txt file. Please note, that one step means two 1/2 snap movements of the cursor or one movement of the little gray box surrounding the white X. Tile code and Object code must be divided by a vertical divider "|" (without the quotes). Please also note, that this is intended for people who have used the editor before, have read the instructions, and no what I am referring to. For anyone who doesn't know, the X and Y coordinates refers to the number of Pixels. Please let me know if there is anything I forgot, or if you are just confused.

units:
1 step = 24 pixels
1/2 step = 12 pixels
1/4 step = 6 pixels

corners (the center of each corner square:
upper left = 36, 36
upper right = 756, 36
lower left = 36, 564
lower right = 756, 564
(x coordinate, y coordinate)

vector1/vector2:
0/0 = right
-1/0 = left
0/1 = down
0/-1= up

non-vectored directions
0 = right
1 = down
2 = left
3 = up

object coding:
0 = gold
id^x,y
1 = bounce block
id^x,y
2 = launch pad
id^x,y,vector1,vector2
3 = gauss turret
id^x,y
4 = floor guard
id^x,y,1
5 = ninja (must be placed first)
id^x,y
6 = zap drone/homing drone
id^x,y,movement style,type1,type2,non-vectored direction
movement styles:
0 = surface follow CW
1 = surface follow CCW
2 = dumb CW
3 = dumb CCW
4 = alternating surface follow (CW/CCW)
5 = quasi-random
type1/type2
0/0 = zap drone
1/0 = homing zap drone
0/1 = laser drone
0/2 = chaingun drone
7 = oneway platform
id^x,y,non-vectored direction
8 = thwump
id^x,y,non-vectored direction
9 = door:
id^trigger x (normal door x), trigger y (normal door y),orient,type1,col,row,type2,vector1,vector2
type1/type2
0/0 = normal
0/1 = locked
1/0 = trap
orient
0 = horizontal (enter from left or right)
1 = vertical (enter from top or bottom)
vector1/vector2
-1/0 = left
0/-1 = up
0/0 = right
0/0 = down
10 = homing launcher
id^x,y
11 = exit
id^x,y,trigger x,trigger y
12 = mine
id^x,y



tile coding (713 tiles per stage)

0 = empty square
1 = full square
2 = triangular half (w)
3 = triangular half (q)
4 = triangular half (a)
5 = triangular half (s)
6 = concave curve (w)
7 = concave curve (q)
8 = concave curve (a)
9 = concave curve (s)
B = shallow triangle [part 1] (w)
C = shallow triangle [part 1] (q)
D = shallow triangle [part 1] (a)
E = shallow triangle [part 1] (s)
F = steep triangle [part 1] (w)
G = steep triangle [part 1] (q)
H = steep triangle [part 1] (a)
I = steep triangle [part 1] (s)
J = steep triangle [part 2] (w)
K = steep triangle [part 2] (q)
L = steep triangle [part 2] (a)
M = steep triangle [part 2] (s)
P = half square (w)
Q = half square (q)
N = half square (a)
O = half square (s)
> = shallow triangle [part 2] (w)
? = shallow triangle [part 2] (q)
@ = shallow triangle [part 2] (a)
A = shallow triangle [part 2] (s)
: = convex curve (w)
; = convex curve (q)
< = convex curve (a)
= = convex curve (s)
