First off, you obviously need a controller. Most people would use a game pad. I use my PS2 controller.

There are two different ways to do this. But, you need this first.

Note: I did not create the above program

Now, with the easiest. Game pad.

First, plug your game pad up to the computer. Now, go into control panel and go into "Game Controllers." Now, double click the controller you wish to use. Now, push a button. One of the red numbers should light up. Now, press the button on your game pad you wish to use space bar as(usually start.) Now, remember the number that lights up. Then do the same thing except press the button you would like to set jump as. Remember this number too. Now, go into Joy2Key and create a new config named "N". Now, set Left as The Left Arrow. Then, set right as the right arrow. Now, remember the space bar number? Go to the Button number and set it as space bar. Now, remember the jump number? Go to the button number and set it as shift. Now, minimize it and play N.

Now, a console controller is a lot more complicated. First of all you need an adapter that will convert your controller to USB. It's easy from there. For example, I use a universal converter and I plugged my PS2 controller up to it and set the keys. Just do the same thing as the above.

Note: This will probably won't work with windows vista
