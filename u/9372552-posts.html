Hmm, that demo is quite lovely, but it's not actually the kind of collision and response I need. I'm doing rather simple AABB sprite and tile interaction, where the moving sprites are people and the non-moving sprites are stuff like walls, rocks, turrets, etc. that are totally solid.

What I've just tried is a message system, where the enemy sprite objects don't project from each other (they're relatively soft bodies, after all), but instead pass a message based on their relative position when they collide (sprite1: "Hey, you're crowding me to the left!", sprite2 "Yeah, well, you're crowding me to the right!"), so in their next update, they look at their messages and use that to make a decision about their next position.

Still tuning it, but this seems like a cheap way to keep the speed, keep the moving on solid collision response, and cheat the moving on moving collision interaction.

In a nutshell:
def touch(self, other):
    # Crowding avoidance
    	
    if ['person',True] in other.quality_set:
        if other.coll_rect.centerx > self.coll_rect.centerx:
            self.messages.append("CROWD_RIGHT")
        elif other.coll_rect.centerx < self.coll_rect.centerx:
            self.messages.append("CROWD_LEFT")
        else:
            pass
        if other.coll_rect.centery > self.coll_rect.centery:
            self.messages.append("CROWD_DOWN")
        elif other.coll_rect.centery < self.coll_rect.centery:
            self.messages.append("CROWD_UP")
        else:
            pass

def think(self):
    if self.target == None:
        self.target = world.ego
    target = self.target.coll_rect
    coll = self.coll_rect
    if target.centerx > coll.centerx+self.speed:
        if "CROWD_RIGHT" in self.messages:
            if self.x_direction == right:
                 self.stopRight()
        else:
            if self.x_direction != right:
                self.startRight()
    else:
            if "CROWD_LEFT" in self.messages:
                if self.x_direction == left:
                     self.stopLeft()
            else:
                if self.x_direction != left:
                     self.startLeft()    
    if target.centery < coll.centery-self.speed:
           if "CROWD_UP" in self.messages:
               if self.y_direction == up:
                    self.stopUp()
           else:

                    self.startUp()
    else:
           if "CROWD_DOWN" in self.messages:
                if self.y_direction == down:
                    self.stopDown()
           else:
                if self.y_direction != down:
                    self.startDown()
    self.messages = []

If you want free server-side SWFs, try using Motion-Twin (mtasc.org). The SWF standard (Flash movies) is actually open-source. What you're paying for with Macromedia tools (or SWiSH) is the IDE and such. You could pop open a hex editor and write a SWF based on its white paper... I wouldn't recommend it, but it's entirely possible.
