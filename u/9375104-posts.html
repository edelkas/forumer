Portable N

Description:
This batch file will keep track of your saved game data, which makes it easier to have backups, or even better, put N on a flash drive and very easily, and quickly move your saved game data from computer to computer

Installation:
  1. Download the ZIP attatched to this post, and unzip it into your N (or Portable N) folder
  2. Make sure you have run N atleast ONE time on the destination computer, without the use of portable N
  3. After you are sure that N has run on the computer atleast once, make sure N is closed
  4. Move your .sol file from C:\Documents and Settings\?????\Application Data\Macromedia\Flash Player\#SharedObjects\*******\localhost into your Portable N folder, it can even be in a sub folder to keep things organized
  5. Open "Portable N.bat" file
  6. The .bat file will open N for you, do not close the black window, it will close after you are done playing N
??????? = Username on windows
****** = Random string
