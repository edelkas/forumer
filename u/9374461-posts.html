New Sig and a tutorial that originated from a PM!


Here is how you make the sig:

First you place your render and duplicate it. Put the duplicate on the bottom and smudge the balls out of it with mai settings to get a matching bg.

Make duplicates of the original render and call them, "Dark Smudge," "Normal Smudge," "Light Smudge," "Original," "Original 2." Put "Dark Smudge" on the bottom, "Normal Smudge" above that, "Light Smudge" above that, "Original" above that, "Original 2" above that.

Set all of the layers to Overlay except for "Original."

Now smudge "Dark Smudge" on Darken.

Smudge "Light Smudge" on Lighten.

Smudge "Normal Smudge" on Normal.

Smudge "Original 2" a bit to make it look cool.

Smudge "Original" to add to the coolness.

Now, New Layer, Image -> Apply Image. Filter -> Sharpen -> Sharpen. If it's too sharp, go to Edit -> Fade Sharpen -> about 50%.

Now, New Layer, Image -> Apply Image. Filter -> Blur -> Gaussian Blur -> 4.3 px. Set this layer to Lighten and 50% opacity.

Now, New Layer, Image -> Apply Image. Set this layer to Overlay and 50% opacity.

Now, New Layer, Image -> Apply Image. Filter -> Distort -> Glass -> Distortion = 8, Smoothness = 12, Texture = Frosted, Scaling = 200%. Set this layer to Soft Light. You can reduce the opacity a bit if you want.

Now, New Layer, Image -> Apply Image. Filter -> Distort -> Lens Correction -> Default Settings except for Vignette -> Amount = -200%.

Now you add your text and your border, and you're finished.

#21018 1 2008-08-04T17:18:58Z Izzy
Hi guys. Today you will be learning how to make something like this:

Step 1: Radial Gradient
Start off by opening a new 400x150px canvas. Place the render, or in my case, 2 merged stocks.

Using two colors, preferably from the main render, make a Gradient using the Gradient tool set to Radial.

The Gradient Layer should be at the bottom.

----------------------------------------

Step 2: Blur Layer
Place your render on a new layer and Sharpen it by going to Filter->Sharpen->Sharpen. If it's too sharp, go to Edit->Fade Sharpen. Now duplicate this layer twice and hide all of them except for the bottom one. On this layer go to Blur->Gaussian Blur-> 5.6 px. Set this layer to Pin Light.


----------------------------------------

Step 3: Luminosity & Smudge Layer
Unhide one of the hidden layers and set it to Luminosity. Now find a good Smudge Brush, I chose a blood brush, and use these settings:

Shape Dynamics- Size Jitter: 100%
Control: Pen Pressure
Minimum Diameter: 3%
Angle Jitter: 100%
Control: Pen Pressure
Roundness Jitter: 56%
Control: Off
Minimum Roundness: 25%

Scattering- Scatter: Both Axes, 237%
Control: Off
Count: 2
Count Jitter: 31%
Control: Off

Other Dynamics- Strength Jitter: 66%
Control: Pen Pressure

Now smudge this layer here and there, not too much. If it doesn't look good, undo it. Change the Brush Size here and there to add depth. Now go to Filter->Sharpen->Sharpen. If it's too sharp go to Edit->Fade Sharpen. Remember, this is only meant to make the Smudging stick out so if it's too sharp, erase some, most, or all of the focal.


----------------------------------------

Step 4: Ocean Ripple Layer
Duplicate this layer and go to Filter->Distort->Ocean Ripple. Change the settings to 8 and 3. If the focal looks too distorted, erase it with a Soft Brush on 60% Opacity.


----------------------------------------

Step 5: Overlay Layer
Unhide the Hidden Layer that is on top or duplicate the Smudged Layer and set it to overlay. I Unhid the Hidden Layer.


----------------------------------------

Step 6: Clouds Layer
On a New Layer go to Filter->Render->Clouds using 2 good colors, I used a brown color and a very light, slightly pinkish, cream color. Set this Layer to Soft Light.


----------------------------------------

Step 7: Adjustments, Smudging, and Lighting effects
Now on a New Layer, go to Image->Apply Image. Go to Image->Adjustments->Hue/Saturation, Lower the Saturation to about -40 or until you think it looks good. Now Smudge this Layer a bit more but not too much. Right now use Filter->Render->Lighting Effects, use the Default Settings and change the shape until it fits the flow of the sig.


----------------------------------------

Step 8: C4D Tiem!
On a new layer place a C4D on Color Dodge and move it around, scale it, and/or rotate it until it fits the flow of the sig. I used the same C4D 3 times.


----------------------------------------

Step 9: Border, Text, and Cookies
Make a new layer and Select All (Ctrl+A). Go to Edit->Stroke, Choose Black, 5px, and check the circle that says Inside. Click OK. Now using the Rectangular Marquee Tool, erase the sides. *I made a 1 px line through the division of the 2 sides, selected it, went to Edit->Stroke, chose Black again, 2px and checked the circle that says Outside, and clicked OK*. Now, using the Magic Wand Tool, select the border. Now, on a new layer, while the border is still selected, go to Edit->Stroke, choose a color from the sig, 1px, make sure the Outside circle is checked and click OK. I set this layer to Overlay and Duplicated it.

*This step is not mandatory, I only did it because there were 2 images.*

For the Text I used the Eurostile font at 14 Pt. I placed it, set it to Multiply and 47% opacity. I duplicated the text, set it to Overlay and 100% opacity.


Now Save it as a .png and you're done. If you want to keep this for future use or reference you should also save it as a .psd.

Congatulations!! You have finished my tutorial! Now go get yourself some cookies or any other enjoyable snack.
