N only refreshes the window up to the point that has most recently changed (from left to right). The more of the screen that is redrawn the higher the ms/f is. Therefore you want the minimum amount of screen to be redrawn per frame. By having the timer change each frame you are causing the window to be redrawn up to that point instead of the right most moving object

To illustrate what is going on, try this. Play 0-0 and move from where the timer is to the right of the screen. As you move to the right the ms/f increases, this is because more of the window is having to be drawn. Next, move from the left of the screen to the point of the timer. The ms/f will stay the same. This is because the timer is causing the window up to the point of the timer to be redrawn instead of just up to the ninja. Now do the same but with practice mode on. The increase of ms/f will now occur. This is because the window is now only being drawn up to the ninja.

The effect of this is that when the ninja stands at the left of the screen with practice mode on I get 8 ms/f but with practice mode off I get 14 ms/f.

The framerate in N is measured diferently to most other games. Whereas most other games measure how many frames occur in each second, N measures how long each frame takes to occur. So whereas a high framerate is good in other games a low framerate is preferable in N. Therefore flicking inbetween 14-60 (for me) would be preferable to a constant 50 ms/f. There are things that you can do to help speed up N.

1. Play N in a lower quality setting. Go into the configure menu and change the setting there.
2. Lower the color quality of the screen. (16 bit instead of 24 bit.)
3. Do not run other programs while playing N. The more programs you run the slower N will. You may also want to prevent some background processes from running. (start->run->msconfig->startup->disable programs you dont want to run.)
4. Scan for viruses. Download the trial of kaspersky and scan with that. I would even do this step if you are already using an antivirus scanner as kaspersky will probably detect viruses the scanner you are using now wont.
4. Scan for spyware. Download adaware and scan with that.
5. Defragment your computer.
6. Reinstall your operating system. I find that the longer I use an operating system the slower it becomes. Back up your stuff then reinstall and your computer should run faster. Only do this step if you are desperate.

These steps will help however you are using a slow processor which is gonna be a major contributing factor.

While making maps it can be frustratingly difficult to make nice looking curves. With this in mind, I decided to bodge together a program to help with this. I felt that this might be useful to some people so I decided to release it to the community.

Note: I imagine there will be a lot of people that will have problems with this. I'm afraid that this is released as is, if you can't get it to work, then I'm afraid you will have to live without it.



++Tutorial++

Click four times for a curve to be drawn. Move one of the four dots to alter the curve.

Click the pictures of the objects to select which you want. Note: this is just to give a feel for what it will look like. You need to use the append text box to apply the direction and things like that.

Click load to load a picture of your map. You need to trim the picture to the correct dimensions, I like to use paint for this.

Use the combo box to change the density of the objects. You can manually type in a number to use one that isn't already there.

At the very bottom there is an append text box, this is where you type in the settings for the object you have chosen. For instance if you want a drone you have to type in the direction, type, whether it's seeking etc.

Above the append text box are two others. These are X shift and Y shift. With these you can alter the placement of the saved objects. This is incase the objects on my program don't match up with how they should appear.

The curve data will be automatically saved into the clipboard whenever the curve is altered. This is not the data for a full map, you need to connect the curve data up to your own level data.
