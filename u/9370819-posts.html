N repeller/attractor
It attracts/repells N and the effect is stronger the closer you are to it, could be useful for DDA's

Sound Drone
It's a zap drone only that it only chases you if you move near it. As long as you're not moving when it's near you, it won't notice you.

Wailer
Works alongside the sound drone, if it sees you, it will attract sound drones by 'wailing'

No Jump/Walk Tile
When you're on that tile, you cannot jump/walk

Ghost property enemies
Enemies that can go through walls

Timed doors
Doors that open/close on certain intervals

Color switches
When a color switch is activated, all corresponding doors of the same colors are opened while a door of a different color would be closed until the corresponding colored switch is activated, which in turn the previous color would also be closed
(so if a blue switch is activated, only blue doors are opened and if a yellow switch is then activated, yellow doors open while other colored doors including blue doors would be closed)

Numbered switches
Switches that must be activiated in a certain sequence

Levitator
Thing that allows N to levitate when N is above it (N is not allowed to jump, however)
