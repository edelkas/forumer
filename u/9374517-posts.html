The only thing this game is lacking is physics on objects, such as balls that roll, or blocks that fall over when you jump on them. This would enable a developer to create more of a puzzel level, pushing blocks to get somewhere higher or a more difficult level. Jumping up towers that fall over more and more with each jump. I would also like to see, if at all possible, rope physics in the game. This could create swining platforms and along with object physics, would add a whole new level of game play. Just think about what new stratagies could be used. You could push a block into a missle to block it or stop a robot from coming down a passage with a ball.

However, with more features comes more problems such as having to rework the Ai in the game as well as how objects react with each other and a improeved collision detection system. I do believe however, that rope, and object dynamics would be a great feature of the game.
