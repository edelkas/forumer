I have the game too, it's the second best game I have played, I can not even begin to describe how amazing it is. It is a bit short, but it has a hard mode which makes everything a lot more challenging. Since there are alternative ways to beat many collosi, the game gets a some replay value too - not to mention "temple climbing", which you can perform after having beaten the game a few times.

The best game has to be Ico though. It's created by the same people who did SoTC, although it's a few years older. The gameplay of Ico isn't near SoTC, but the story is (although very simple) the most beautiful and inspiring one I've came across in a game, and the atmosphere is fantastic. It even inspired me to add the Ljus level to Within a Deep Forest.
