I found Ned easier to use with an AutoHotKey script running. (I'm a keyboard klutz.)

The script uses the middle mouse button to toggle between tile mode and the object placement mode. The object placement is split in two, upper box (enemies) and lower box (other). The mouse wheel cycles through the objects/ tiles.

The left shift key works normally with tiles, but as backspace (hold to delete) with objects.

Normal exit methods work to end the script (right click or double left click the tray icon). Holding the Windows key and pressing the x key will also kill the script.

Perhaps someone else will find this useful. Mouse drivers that alter normal button functions may break this script.
