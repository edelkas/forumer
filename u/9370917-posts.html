OK do you want to count the r's and n's or do you want to decide wich one appears first? Beacause in your first post you said that you have to determine which appears first.

indexOf() just gives you the position of the first appearal of that character.

If you want to count characters you have to make a loop over the whole String and check every position wheter it is the searched character.

For exampe:

String test = new String("ingredient");
integer position = test.indexOf('n');

Now position will have the value 1. Because the n is at positon 1.

String test = new String("ingredient");
integer nCount = 0;
for (int i=0; i< test.lenght(); i++)
{
  if (test.valueOf(i).equals('n'))
    nCount = nCount+1;
}

Now nCount will have the Value 2 because there are 2 n's in this word.

To shorten your code you can also call:

test.toLowerCase();

then the whole word is lowercase and you don't have to count the upper and lowercase characters and add them later.

Oh and are you sure that you get 0 r's and 3 n's by entering train because this looks more like rain. (r at the 0th position and n at the 3th)
