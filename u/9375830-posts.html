N+ lag over XBLA is horrible. It seems that this has been a known problem from the start and I wonder if it started when Metanet had to reprogram the game for Voice Chat.

For those interested in the development cycle, read this: http://www.gamedev.net/columns/events/gdc2...cle.asp?id=1131

Some relevant quotes from the article include:

Quote
Around comes June and the team is in the final stretch before reaching Alpha status, which is the point where all the features in the game must be complete. This meant general tweaking of the gameplay code as well as adding in voice communications, which the team had completely forgot about. Although setting up VoIP wasn't a huge deal, they have to spend some extra time tweaking the network code because they weren't on a peer-to-peer connection but rather a client-server connection and hadn't thought about that related to VoIP earlier on.

Quote
The network lag was a result of simply too much data being streamed between the client and server, they hadn't implemented any sort of priority system which they realized in hindsight, and so were forced to reduce the state send rate to a mere 5x/sec which is rather slow for a fast-paced action game.

Quote
By September the team is in full bug-fixing mode, mainly focusing on multiplayer issues due to about 20 different combinations of game modes and connection types, many of which were similar but slightly different in how they had to report to the Live service. Also numerous were issues involving disconnects, signing out and session interrupts.
