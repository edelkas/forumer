#403039 5 2008-01-22T04:42:27Z xboxzombie
Next time you run N run the task manager on the side and watch the 'processes' screen (N in particular) That error typically happens when more than 100% of the CPU is trying to be used. (I get it all the time when i run multiple CPU intensive programs like N.) Set n at a higher priority and try not to run any other CPU intensive software.

Also weed out any unnecessary programs you got taking up your spare RAM as that also can trigger the Error. I run 1 Gig on my desktop and it still gets clogged up from time to time. (if your running Vista, This is probably an issue with just 512 Mb)

Last resort, Backup N and your .sol file to a removable drive and take bhz's advise.
