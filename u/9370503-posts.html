t's hard to explain -- there are no sprites as used in other 2D games, but if you consider each segment of each limb of the ninja's body to be a sprite (which is moved and rotated), then yes, we're using sprites. you could theoretically draw the ninja on an snes or other sprite-based system by using several sprites.

really all we're doing is animating a character by splitting them into various segments and animating the position+rotation of each segment -- this happens in many other games, for instance oni, q3a, and most other older 3D games.

these days 3D games use the same idea, but instead of having each segment be an unconnected chunk, they sort of blend the segments together at the joints. in oni the joints are sort of obvious and they hid this by using knee/ elbow/shoulder/etc. pads to cover them
