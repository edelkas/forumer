#25263 2 2004-07-25T22:22:56Z seris
I attached a demo if you want to see it done in 1 life. This level was fairly easy, it only took 2 restarts (mainly because of getting trapped in those doors at the bottom). It was a good first map but there's some things you could improve on. First of all, try not to put as many objects in next time, on slower computers this can really be tedious especially if you die a lot in the level. You should aim for 1-2 lines of the "loading dots" (although I'm not sure if they're the same on all machines). Second, try not to put so many door switches/objects on one button. If N moves past it very fast, only half or less may activate. One more thing, if you've got a theme for the level (casino vault), try to actually make it look like a vault if you can. I understand this can be somewhat difficult, especially for this theme, but after I finished the level, I completely forgot it was supposed to be a heist. Anyway, welcome to map editing with N, I hope to see more of your levels in the future.
