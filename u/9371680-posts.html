If you don't use threads, what are you using then?

The short answer is that i use a single thread that loops with a frequency of 60fps. The game loop consists of 3 steps: update user input (figure out of the user is pressing left, right, where he's aiming and such), update game state (compute the player, bullet and spark positions, do any collision detection stuff) and render the current game state.

The long answer is read this book if you're interested in java game development (or game dev in general). It's an O'Reiley book, but the author provides links to a draft version of the book (very readable).
Killer Game Programming in Java
