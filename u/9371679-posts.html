Sorry if this is in the wrong section, I'm fairly new here so feel free to move it as you see fit.

I'm horribly addicted to N game's awesomeness, but I've noticed a few tiny inconveniencies that it should be possible to fix (I know there are probably a lot of "Make N be able to fly and have machine guns!" suggestions around, so I'll try to stay realistic)

1. It would be less annoying if the frame-by-frame mode wasn't controlled by caps lock. Often, I try out user maps and then come to the site to comment, only to find that I'm typing in all caps. A less important button would be nice.

2. I noticed that sometimes if N lands on a surface at a shallow angle, he "skids" and the jump button doesn't work. This can get really frustrating, especially when you're trying to jump from circle to circle quickly. It would be nice if the jump button still worked even if N is "skidding". (not sure how feasible that is though)

3. In NED, when you are playing a user level and beat it, N just sort of twitches and the message "level complete" shows over and over again. I'm guessing the program gets stuck in a loop or something, so that should be pretty easy to fix.

4. You probably get these a lot, so I'll combine the three. First, NED should definitely have time implemented, so that you can try out your levels more realistically without having to go through the trouble of editing the userlevels.txt file. Second, it would be cool if in NED you could just press "space" instead of having to reset the objects and then pressing play each time you die. Lastly, it would be a lot easier to create levels if you could hide the legend somehow. For example, I memorized that 3 is a mine, 0 is gold, 9 is ninja, o is a door, etc. so for me it would be more convenient to be able to see what I'm doing on the whole screen than to have a legend handy.

5. I don't know if this is already possible, but it would be cool if you could edit any level from the actual game. My friend once challenged me to make a certain level be a DDA, but I couldn't manage to edit it.

6. I'm not sure if this is just my computer or not, but in NED, if I hold down backspace for an extended period of time and delete several objects, the cursor lags behind terribly. This immediately stops if I let go of the backspace button.

That's it for the (relatively) easy-to-fix inconveniences... Now for a few random suggestions that will probably never work!

It would be REALLY cool if there was a type of switch that could change a tile to another type of tile! For example, you could make a trap by making all the floor tiles go blank and then shutting them again with another switch once N falls through, or you could provide an escape out of a trench by making a little platform appear out of a blank tile. This would probably be hard to implement in NED, but I think it would be worth it.

Also, it would be awesome if tiles could be made to move. I know, this might require reprogramming the entire physics engine, but it's just a random idea. You could make elevator tiles, platforms that bring you across pits or through minefields it would be impossible to jump through... *drool*

Finally, I'd like to congratulate Mare and Raigan for their totally awesome work!!! I'm a total noob programmer (I make games like hangman, pearls before swine, and a comic version of pokemon on my ti83+) but I still love programming, and it's great to see how far you can go without being part of a huge corporation (Metanet isn't that big is it? I don't really know...). Your game has provided hundreds (probably thousands) of people with hours of fun, and that's something special. My study period has never been the same! Keep up the good work guys!!!

Anyways, I finally figured out the secret to those stupid STUPID stair things that go up the walls!!!

What you do is this: Instead of wall sliding on the little bits and trying to jump from that position (which can drive you insane) you jump to the top of each section and drop down along the wall. Once you reach the bottom, jump. Use your best judgement as to when to press back towards the wall again, but it's a hundred times easier to do!!!
