Ok, I'll answer the unanswered questions this in reverse:

@ ZZ9: You're correct. There's a Linux version of N in Metanet's download page (It's right next to the Mac .dmg file download)

@ CDotLeach: Ubuntu is a version of Linux, that is becoming ever more popular (Dell will begin shipping computers with either Windows Vista OR Ubuntu Feisty Faun on them). Feisty Fawn is merely the code name for the Ubuntu version. Kinda like Vista is the code name for Window's most recent OS.

@ wipf: There are several things that could be making N run so slowly. Since your running N, I'm assuming that you've got Ubuntu installed on one of your drives. First off, you could not have a powerful enough computer. Your processor could be slow, you might not have enough RAM installed or you could have a slow hard drive. Or it could be software-based. Do you have a swap partition? It's basically the Linux version of Window's Virtual Memory. Designating a swap partition on your hard drive allows it to be used as RAM, but behaves slower than normal RAM because the time that Hard Drives can access data is much slower than the speeds that RAM can access it. You could just need some optimizing on Ubuntu's part. Search on Google or some other search engine for optimization tips. Other than that, you might want to try some Linux support forums, if all of this fails.
