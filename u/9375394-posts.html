Hello fellow Mac gamers,

Like many of you, I played N for a while and became frustrated that it never saved my game. I did a little research on this forum and found the #sharedobjects folder where the .sol file is stored. I saw the randomly-named folders and looked in the most recently-updated one. I did not see a 'localhost' folder, much less a .sol file underneath. Instead I saw something strange. Under the randomly-named folder was another randomly named folder, and another below that, almost as if the Flash player hosting N was stuck in a loop, creating randomly named folders, but never creating the .sol file. I could watch these random folders get created, one after another, as long as the app was running.

On a whim, I moved the N applicatoin from the "Applications" folder to my Desktop. Voila! No more nested random folders! It created one random folder, then localhost, then my .sol file! I played happily for a few days and all was cool.

Until today. No changes, nothing different, but the folder nesting is back. N seems to ignore the old .sol location but get stuck while trying to create a new one. Not sure what I will do with my day now.

Anyone else seen this problem, or know how to fix it?

Does anyone reading this know if this is a bug in Flash or in N?

Thanks, Walter.

Hello again,

For those following along at home, I have gotten it working again for now.

Not sure what the fix actually is, but here's what I did:

1. Backed up my old .sol file.
2. Deleted all randomly-named folders out of #SharedObjects. (Didn't delete #SharedObjects itself.)
3. Emptied Trash
4. Launched N application.

It created a single non-nested folder with a 'localhost' subfolder!

So I quit the app, replaced the .sol file and everything went great on relaunch.

Caution: who knows what other vital information you are deleting when you delete all of those folders. If you use some other Flash app that saves data, back it up.

Still curious whether anyone else is seeing this breed of trouble, and whether anyone is aware of a bug in Flash for mac that could be the cause.

Walter.
