With the release of the new homebrew flash swf player for PSP 1.5, it opens up a new realm of portable entertainment, the possibility for more advanced gameplay, applications, etc. The thing that has me most excited is the possibility of N being playable on the PSP. Now, I'm not about to downgrade to 1.5 just to try this until I'm absolutely sure it will work. Problems that may come up:
SWF: N is an swf, yes, but it is run through an executable, or exe to (I assume) prevent people from stealing it and putting it on 'flash game' websites. In order for N to work properly o the PSP you'd need to change it to an swf.
.sol: The location of the n .sol file may hae to be changed, because the file hierarchy is different within the PSP's memory stick duo.
Action buttons and mouse: I assume that there is a mouse already available in the swf player like in the webbrowser, taking advantage of the analog stick, however it may be in the best interest of gamers to make a version of N for psp that allows you to use the psp's buttons for menus and for movement during gameplay.
Sound: I'm not sure how N's sound is encoded, btu I am sure that mp3 encoded audio is not yet supported in the player/
resolution: perhaps the most important part, the psp's screen is smaller than that on your desktop, so we have two options here: Make a new version of N with the same proportions on a different scale as to get maximum area, or change the setup of the currentversion of N so that it is shaped in the same way the PSP's screen is; this may make the maps seem smaller and might not benefit the gamer.
Features: Things like the level editor and practice/boss modes may have to be removed in favor of space and also uselfulness.

I'm sure there are more, and seeing as this project basically requires that N be completely remade for the PSP, I'm sure we cannot do this without the sanction and support of Metanet and the N community. Still, the ability to play on PSP is something big. N is great for wasting time and has seemingly infinite replay value, as well as being relatively simple when it comes to gameplay (only four keys involved!) so I think it goes without saying that it would be the PERFECT game for PSP, and would probably make me play it 10x more often than I do now.
