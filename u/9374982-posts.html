I've had tons of fun with N, this is a really neat game
So, since N is all about gameplay, which is why it rocks, my suggestions will be about gameplay :

* Let the user choose N's inertia (via a slider). I find N a bit "heavy" for my taste and would like a bit more of "air control" (ie. less inertia, like in Cave Story). Obviously, this is like the practice mode : highscores should only be recorded with default parameters.

Note : this isn't a gravity control, it's the amount of acceleration imparted to N with the left/right movement keys.

* When N stands on top of a Thwump which moves laterally, N doesn't follow... I have to move N manually so he stays on top of the Thwump. I think this is a bug, since the rest of the physics is very nice... when N stands on a moving platfofm, it should follow without player intervention.

* When jumping from a bouncing block, N's jump speed (and height) is rather random, it should be equal to the block's speed + N's default jump speed...

* Jumping sometimes makes me crazy... When you move on an uneven surface, sometimes Jump doesn't work at all. For instance, suppose N runs on a slightly uphill slope, followed by flat terrain ; for maybe 1/10 s after the angle, N "hovers" in the air (I don't know if I'm making myself clear so if you press Jump there, it doesn't work, and you get zapped by the drone you wanted to jump over... Also, when N lands or walks on "round corner" tiles jumping is a bit random.

Suggestion 1: if N's feet don't touch the ground, but they are, say, 1 or 2 pixels above ground, pretend it's OK and allow the jump.

Suggestion 2 : like in many other platform games, if N touches ground and the Jump button is depressed, he will immediately jump again. This would make it a lot easier to do funky ninja aerobatics (like land on a tiny ledge and immediately jump again) and I think it would add fun to the game. This could be a settable option, too.
