Seeing as how the psp can only do control pad as arrow keys and control stick as mouse and X button as left mouse click, this is how you can make it work:

Control Pad = movement left and right, duck down, jump up
Control Stick - move mouse
X button - click this to start levels and do what spacebar normally does and to pause/exit game or go to menu or go to boss mode or kill or replay or restart or other options

Online Scores could be done by clicking on link to send high scores through link button on swf game file [requires internet connection but link button is also on saved to psp file just internet connection would be needed for sending high scores].

The text files and cheat files and manual could be displayed in text and pictures or flash movie in swf.

The level editing could be done in Swf and sent to this website and downloaded through another link button. Another option for Ned level editing program, is to make it a seperate swf file that sent the finished level to this website for download through n game swf, or use it through save game file on psp. It could also just be a temporarily edited level and not be saved.

The recording could be started through a button and could either be sent to website and download temporarily or could be sent to website, converted to mp4, and downloaded to psp video file or it could be saved to the psp video file as an mp4 video file or save as save game file on psp. It could also be a temporary recording and not be saved.

Required that the file size isn't too large - less than 4mb would be good.

If file size is too large, either split editor and game and manuals/training flash videos into seperate swf files or seperate each of the stages [10 stages = 100 levels] or levels into seperate swf files.

You could either play it through psp browser or save it to psp/common, open psp browser, not requiring internet connection, and type in browser - File:/psp/common/ngame.swf [or whatever name of swf file is] to play.

This would make it playable on regular psp's instead of homebrew eboot [another option].
