#112487 6 2005-11-05T02:14:02Z astro
Quote: About NUMA
Numa is an archive of player-created maps for the game N, an addictive platformer somewhat reminiscent of Lode Runner.

Numa provides a place for N map authors to post new maps they have created, so they can provide a simple URL instead of attaching the map as a text file to a forum post or elsewhere. For players, it provides a centralised repository of maps to play, thumbnails of maps so players can get a glimpse of a map before loading it, and the ability to post comments and demo data for maps.
