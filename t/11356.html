#205202 4 2006-07-20T19:24:48Z Xév
It's really fun and easy!

1. First, open up GIMP... If you don't have it, well install it.
2. Make a new image 100x100.
3. Fill the image with black, Edit>Fill with FG color.
4. Choose Filters>Noise>Scatter RBG, and move all the sliders all the way to the right.
5. Repeat Scatter RBG.
6. Choose Layer>New Layer, and repeat steps 3-5.
7. Repeat steps 3-6 two more times.
8. There, now you have 4 broken TV images... Choose Filters>Animations>Playback and then Play/Stop to make sure it works.
9. Ok, Close the playback thing and make a new layer. Make sure Transparency is checked.
10. Find a picture you want to use as the faded image. I think text works the best, if you change it to a light-greenish color.
11. Change the layer mode to Overlay. Ask me if you're not sure how to do this.
12. Choose Layer>Duplicate Layer, three times.
13. Drag the layers around in the layers, chanels, and paths box so there is a picture layer above each broken TV image.
14. Choose an image layer, then go to Layer>Merge Down. Do that for all the other image layers.
15. You are done! Choose Filters>Animation>Playback to see it!
15 1/2. If you want to use it as an avatar, choose Filters>Animation>Optimize for GIF. Save it as a .gif image, then make sure 'Save as Animation' is checked. Don't change anything else. Choose 'Ok.' Then 'Ok' again. You are finished!!!

Ok, so it's not that short.
