Yep. that's the same one that I got, and I've been having the same problem. I'm gonna experiment with a few things. If I find a solution, I'll post it here.

Editing the userlevels from the .dmg file on a mac:
When you first download the .dmg, the name of the downloaded file is n_v1mac.dmg.
Open this file.
An item should appear on the desktop with the default "jump drive" icon and the title n_v1mac.
Open this file.
Create a folder on the desktop and copy all of the files inside of n_v1mac to that folder.
You can now edit the userlevels.
