Please consider that the game is portable, so no progress is lost in the transition.
The progress is actually stored in a .sol file in a separate folder, with all the other .sol files saving progress for other flash games you may have played. So if you want to transfer your progress to another computer, you need to locate that .sol file and copy that (the rest of the game is not needed) - refer to .sol Files for Dummies for more details of how to find it, etc.
But yes, I think transferring your progress to another computer to submit highscores is perfectly fine.
