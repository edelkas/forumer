If you want N cursors, (YOU NEED MICROSOFT VISIAL C++ 6.0)

You must:

have > http://www.davidmear.com/n/poser.swf < running, (it's an N poser...)
Make the pose you want (N HAS TO BE SIZE 40), press PRINT SCREEN,
paste in paint, select a box around the SMALL figure...keep it in that position...
(Don't copy)

go to 'my computer', 'Local disc C', 'WINDOWS', and then 'Cursors'.
Copy any pict, with '.CUR' behind, paste, name it what you want.

Open it with, 'Microsoft Visial C++ 6.0', then go back to paint, copy, then back to 'micro visial C++ etc.' paste, position the figure, then you need the blueish colour in the black box in the paints to the right. paint the colour all the way around the N character. Then set the 'hot spot'.
After that, save it, then go into the controll panel, mouse, pointers,
browse and apply you cursor!
