#54180 2 2005-03-14T23:33:40Z Raigan (guest)
hi,
the basic steps are:

-determine the set of potential seperating axes
-for each axis in the above set:
-calculate penetration
-if(no penetration): return/end -- the two shapes don't collide
-for all penetrations: find the minimum penetration. this is the vector which should be used to project the shapes out of each other.

#54279 4 2005-03-15T20:44:22Z Raigan (guest)
hi,
the "calculate penetration" step, in it's most general form, is identical to the typical circle-circle collision that everyone uses.

you basically find the "halfsize" of each object (analogous the radius of each circle), then you find the distance between the object centers. if the sum of the halfsizes is larger than the distance between the objects, they're overlapping.

the projection math can happen in any space you'd like; in the case of AABBs, as far as the math is concerned, the objects' local space is identical to world space.

raigan
