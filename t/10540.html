I recently read some older threads, incl. the first thread about NUMA. Arachnid said there that the demo format is so easy to read. I think he said "it looks so clear in binary". Given this hint, I have decoded the demo format in about 10 minutes. The result of this experiment is the N Demo Disassembler. It analyzes a demo and produces a simple text file as output.
