#275628 2 2006-12-23T09:52:11Z LittleViking
Vector graphics are generated mathematically, based on paths and colors set by the artist. An example, let's say you want to draw a box. In a traditional graphics program, you would drag the box tool how you like it, and it would fill the area in with pixels. With vector graphics, the program would only have to save the coordinates of the corners. The advantage to vectors is in how well they scale. Imagine zooming in very far on a circle in a traditional program like Photoshop. When you zoom in, the edge of the circle gets more jagged and pixely. A vector program, on the other hand, just has to generate a new circle when you zoom in, and so the edges never get pixely. If you have a circle with radius 50 pixels and zoom 8X, then the program just draws a new circle with radius 400 pixels.

I'm not sure what the best free vector graphics programs are, but you could try Wikipedia's list. The best commercial software is Adobe Illustrator and Corel Draw.

To be completely honest, you can make shapes and gradients. Vector graphics are very limiting. You won't have a blur tool, a smudge tool, lighten and darken tools: You can make shapes, lines, solid colors and gradients. The ideal use for these is simple pictures. Vector graphics are great for things like logos, which need to be scaled up and down all the time. Now, that's not to say that complex pictures can't be done with vector art. They can. It just takes a lot of skill, patience, and mental capacity.

They're also used in Flash for everything from games to websites to programs.

Should you use them? Well, there's no reason to start and no reason not to. It's really up to you. Vector art is a very specialized kind of editing. If you think you'd rather bend curves to create a drawing than use a paintbrush, then give it a try.
