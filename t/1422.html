Just following the map data is a string that is something like this:

"|5^###,###"

That is the code that represents N. The ###,### are the X/Y coordinates of N. Many of you know this already.

So here is my cool/interesting thing for you to try:

Create a new map, clearing it with J. Now place N somewhere on the map (doesn't matter). Edit the N entry as noted above to look something like this:

"|5^###,###,###"

That last ### doesn't matter what value you put in there so long as it is a valid number. Click somewhere off the text windows and press L to load the modified map.

Now maximize the N window. Look in the upper left corner of the screen. See the super-sized N?

Unfortunately, you can't do anything with him.
