2. Only requires a flag, and therfore a single "if" statement. The others will use some memory, yes. But on the other hand, for the ninja:

1. Collision detection with tiles (complicated)
2. Collision detection with objects
3. Gravity
4. Momentum
5. Player input

And you neglect the fact that if there were two players, enemies would then have to either
1. Have an algorithm to decide which player they target, which increases memory consumption
2. Target both players simultaneously, thereby doubling the number of calculations necessary. Ouch.
3. Always target one player, which removes many of the benefits of multi-player.

With two players, there is also likely to be twice as much interaction with objects, which will increase calculations. I maintain that two players will almost double the lag.
