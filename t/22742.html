#440706 2 2008-05-31T08:06:44Z Strife
It sounds like settings aren't being saved; make sure you have write permissions to all of the game files.

Alternatively...
Amusingly enough, the most success in playing N in linux for a number of users here has been running the Windows version with WINE.
apt-cache search wine should bring up brief package information, but then again I'm using Ubuntu 8.04 (Hardy Heron), so I'm searching in the hardy repositories. I don't remember if wine joined the default Ubuntu repositories before then. If you can't find it, make sure you uncomment the "universe" and "multiverse" entries in /etc/apt/sources.list, do sudo aptitude update, and then search again. If that doesn't list it, go to http://www.winehq.org

sudo aptitude install wine
wine [wherever]/n_v14.exe
...although you may want to give the game highest priority:
sudo nice -n 20 wine [wherever]/n_v14.exe

You may be given grief about a particular C++ library (I was back when I tried it for the first time in Ubuntu 5.10). If that's the case, just Google the library name, download it, put it into /usr/lib or wherever the executable is looking for it, and you should be all set.
