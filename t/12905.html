For Windows users only.

Note: This also works with any other object that can possibly be shortcut to.

Thanks to LittleViking001 for finding this out for me.

Ever wanted to open N using the Run command? Well, here's how:

1. Create a Shortcut to your N .exe, and rename the Shortcut your desired input to the Run command.

eg. Mine is named 'n', so in Run, I type in 'n' to open it.

2. Copy (or cut) and paste this Shortcut into the folder C:\WINDOWS .

That's all there is to it.

The Run command is located in Start > Run... , or by pressing the Windows Key + R.
