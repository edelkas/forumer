#20339 1 2008-05-26T16:14:17Z Lioyd_Irving
Hello,

I won't eat lines introducing myself and I'll run directly to the point.

N definitely needs a quicksaving option.

It would allow the player to finish the game without having to become a super1337 N player...
For instance, I'm stuck in the 8th episode...I could finish it, but it would require several days of N-ing.

Problem : I'm a DOOMer, not a Ninja.

A game isn't cool if beating it implies dropping all your other activities.

Think about it. When the player has to redo the same level, over and over, he will find himself giving up, thus never beating it. Which is a shame when you know that some of the levels are so well-designed.

It would seem inconsistent to have that kind of thing in an arcade game like N. That's why I thought about a limited number of saves per level (or per episode), ala Hitman. This would allow the game to be much less frustrating, while still sticking well to the genre. You could, of course, reduce that number or deactivate that command via the options menu.


So, please be nice with the casual N players and think about it.
