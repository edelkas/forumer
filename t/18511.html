#346278 2 2007-07-22T20:32:07Z smartalco
i use a key listener for keys that you would press and not hold, and onClipEvent to detect if keys are pressed upon entering the frame

key listener:
myListener = new Object();
myListener.onKeyDown = function () {
	if(Key.isDown(80)){
  /*code to be executed when specified key is pressed*/
	}
}
myListener.onKeyUp = function () {
	
}

Key.addListener(myListener);
}

just replace the number 80 with the corresponding key code (i forgot where i found these, you will have to do some searching

onClipEvent:
onClipEvent(enterFrame) {
	if(Key.isDown(key.RIGHT)) {
               /*code to be executed*/
        }
}

just replace key.RIGHT with the key you want
