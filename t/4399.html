oh, you mean the copy/paste stuff!! sorry -- i forgot about that feature

you need to be able to figure out which square of the grid contains a given point -- this is something you need anyway for normal tile editing.

then, you just store the two points that the user defined (the mouse-down point and mouse-up point), figure out which squares contain them, and use min/max (or logic) to get the min/max coordinates that describe the rectangle of squares containing those two squares.

so, you describe the user's selection as a rectangle, which can be represented however you like (i.e min+max corners, or center point+size, etc.)
