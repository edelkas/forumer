#177556 3 2006-05-19T01:50:37Z Atilla
Also, make sure that the syntax is correct. Each level should have the format "$Name#Author#Type#data#". If you leave the # off the end, for example (easy to do) the levels after it won't show up correctly. If this doesn't work, check if any of your level titles have unusual punctuation in them (&, #, $...) and remove it.
