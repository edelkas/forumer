#192683 2 2006-06-21T22:09:27Z Twistkill
Those screenshots on the main page are levels in-game. To add userlevels to your userlevels list, you go to this site and use the links on the left hand side to find maps. When you select a map, go to the box that says 1.4 Data. Select All and Copy the text inside that box. Then find the file that says userlevels.txt and follow the instructions in that file to add it to your list.
