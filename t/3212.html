hi,
the rockets in N use some very basic "steering" behaviours, try googling "boids" to get some links, here's a good one: http://www.red3d.com/cwr/boids/

you might find it easier to use vectors instead of angles.. the basic idea is that you track the rocket's position and velocity; every frame, you adjust the velocity so that it moves the position towards a target. to be even more fancy, you can make it aim at the future position of the target (i.e targetpos + targetvel), this makes a big difference.

here's the code directly from N; please give credit to us if you end up using it. possibly it's not going to help much.. it's a bit confusing

---
var p = this.pos;

//"integrate" missile forward
if(this.speed < this.maxspeed)
{
this.curaccel *= this.accelrate;
this.speed += this.curaccel;
}
else
{
this.speed = this.maxspeed;
}

p.x += this.speed*this.mdir.x;
p.y += this.speed*this.mdir.y;

//we want to aim at a point in front of the player; get
//the missileplusmissilevelocity-to-playerposplusplayervelocity vector
var guy = player;//dereference for speed
dx = (2*guy.pos.x - guy.oldpos.x) - (p.x + this.speed*this.mdir.x);
dy = (2*guy.pos.y - guy.oldpos.y) - (p.y + this.speed*this.mdir.y);

//steer missile
//..if we've reached here, dx,dy is the to-player vector, and is non-zero length

var len = Math.sqrt(dx*dx + dy*dy);
dx /= len;
dy /= len;

var dp = this.mdir.x*dx + this.mdir.y*dy;//dotprod of to-player vector and velocity
var pp = -this.mdir.y*dx + this.mdir.x*dy;//dotprod of to-player vector and velocity's righthand normal

var trate = this.turnrate;

if(dp < 0)
{
//player is "behind" missile..
//new, more "rocket-like" behaviour: we can't decellerate, but we CAN turn faster!
//turn faster; dp varies from -1 to 0, so the further behind we are, the faster we turn
//trate += -0.5*dp;
//trate *= 1 + (-dp);
}


//get steering vector (the component of dx,dy perp. tothe missile's current direction)
var tempX = pp*-this.mdir.y;
var tempY = pp*this.mdir.x;

this.mdir.x += tempX*trate;//blend steering vector into current direction
this.mdir.y += tempY*trate;

var len = Math.sqrt(this.mdir.x*this.mdir.x + this.mdir.y*this.mdir.y);
if(len == 0)
{
//note: length should NEVER be zero because we're always adding
//two orthogonal vecotrs, one of which is always non-zero
trace("WARNING!!!! HomingLauncherObject.Update() is having a big problem with null direction vectors..");
return;
}

this.mdir.x /= len;
this.mdir.y /= len;
---
