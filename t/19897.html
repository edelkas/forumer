I love downloading new maps from NUMA but there is one problem with downloading a ton.
When you open userlevels it take forever to compile.

I found a pretty good solution:
copy and past the bigining comment form the userlevels notepad document into a new note pad document. then, rename this file userlevels(but save the old one if you still want those levels!)
Now you have a clean slate to add levels to.

A plus: quicker load times
