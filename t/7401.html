I'll start out with Puchiwara.

-Puchiwara-
Puchiwara is a japanese puzzle/platformer by Miya. It's graphics are simple, but its gameplay rocks. You can find it at http://www.caiman.us/scripts/fw/f1557.html.
Because the game is in japanese, you can't exactly read the menus and stuff (unless you know japanese). Though, i have figured out the menus and controls by messing around. so i will post the controls and menu here.
Main Menu Controls-
Up and Down- Go up and down on menu
Space- Select

On Map Contols-
Left, Right, Up, and Down- Select Location
Space- Select Zone/Level
Shift- Close out of Zone, Open menu

Ingame Controls-
Left and Right- Move around, Push Blocks and Boulders
Up and Down- Go up and down ladders
Space- Jump
Shift- Open Menu

Main Menu-
New Game
Continue
Unknown (Tell me if anyone figures it out, I don't think it does anything.)
Exit Game

On Map-
(After hitting shift to go to menu...)
Save Game
Exit Game
Exit Menu

Ingame-
(After hitting shift to go to menu...)
Restart
Exit Level
Exit Menu

Tell me if i have anything wrong, or tell me if you know the second select on the main menu. I think you will like this game if you like N, I am quite addicted to it.
