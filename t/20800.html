#393561 3 2007-12-26T17:14:43Z Unreality
Similar idea is implemented in version 6c, which is not released yet.

There is no way for map author to restrict users from submitting scores.

The map author can set the map so that only the author can see all the top 20 scores, while other players can only view their own scores.

If the contest host is not the author, then the contest host needs to submit a duplicated map as his map to numa. Of course he should write in the map description about the original map author

If the contest host wants to end the round, he can ask the players to stop submitting new runs (otherwise disqualify), or he can simply remove the exit from the map

Private contest runs can't be visible to other ppl, even if the contest has ended.
By the way, it is not hard at all for the contest host to copy the top 20 runs demo data out.
