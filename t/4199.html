OK, I see your problem.
Let's examine a piece of your code, shall we?

boxA.px = boxA._x;
boxA.py = boxA._y;
boxA.xw = boxA._width / 2;
boxA.yw = boxA._height / 2;

lenA = Math.sqrt( boxA.xw * boxA.xw + boxA.yw * boxA.yw ); // longueur
boxA.dx = boxA.xw / lenA; // v. unit x
boxA.dy = boxA.yw / lenA; // v. unit y

Tell me, why are you using your box half-width and half-height to determine your box rotation?
Let's leave boxA's rotation to 0 and mess around with boxB's rotation.
If you want to make a 45 degree rotation, what do you need?
Your dx and dy will have to be equal to 1, and you will have to normalize the (dx, dy) vector. The vector length is Math.sqrt(1*1+1*1), which is equal to Math.sqrt(2). But you already have a precalculated Math.SQRT2 constant, so you don't have to compute that. After calculating the vector length, you have to divide each of the vector's components by the length, and you get your facing vector
boxB.dx = 1 / Math.SQRT2;
boxB.dy = 1 / Math.SQRT2;

SO, to fix it, you just have to replace the box initialization lines with these:
boxA.xw = boxA._width / 2;
boxA.yw = boxA._height / 2;
boxA.dx = 1;
boxA.dy = 0;
boxB.xw = boxB._width / 2;
boxB.yw = boxB._height / 2;
boxB.dx = 1 / Math.SQRT2;
boxB.dy = 1 / Math.SQRT2;
boxB._rotation = Math.atan2 (boxB.dy, boxB.dx) * 180 / Math.PI;

In these lines, I use a little trigonometry (the Math.atan2() function call) so you can see how the box looks rotated.

Later, if you want, you can make things a bit more dynamic, like I did in the attached files.

#101016 18 2005-09-16T18:49:12Z shoftee

Since it's about MY code, I guess I should answer it, and I will.
...
len = Math.sqrt (deltax * deltax + deltay * deltay);
boxB.dx = deltax / len;
boxB.dy = deltay / len;
boxB._rotation = Math.atan2 (boxB.dy, boxB.dx) * 180 / Math.PI;
...

We have the facing vector (deltax, deltay) .
For the code to work properly, you have to normalize the facing vector. To normalize a vector means to make it 1 unit long. And this is exactly what the first 3 lines do.
If you want 45 degrees rotation, your facing vector has to be (1, 1). (I think )
So, if you want to normalize ANY vector, you have to calculate it's length, and then divide each vector component (x and y) by the length.
So for the vector (1, 1), you have a length of about 1.41 or something of the sort. Then you divide deltax and deltay by len and you get the normalized vector (dx, dy).
The fourth line just rotates the box so you see it rotated. If you remove the last line, both boxes will have 0 degrees rotation, but boxA will still collide with a box that's with 45 degrees rotation.

And the last part of the last line converts the radians returned by atan2 to degrees.

1 radian = 180 / PI degrees.
So to convert to degrees, we just multiply the radians by 180 / Math.PI .

I knew you would ask this!
By now, I told you how to get a rotation from a facing vector. Now I'll tell you how to get a facing vector from rotation.
You have to use sin and cos.

deltax = Math.cos(x * Math.PI / 180);
deltay = Math.sin(x * Math.PI / 180);

, where x is your rotation in degrees.
The vector (deltax, deltay) should now be unit-length, so you woudn't need any of the length calculations. Which makes the boxB initialization lines:

x = 35;

deltay = Math.sin(x * Math.PI / 180);
boxB.dx = deltax;
boxB.dy = deltay;
