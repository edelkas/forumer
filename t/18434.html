Quote: Rock_man ZX, July 17, 2007 11:08 pm
i couldn't find the numa discussion and the way to do that to your maps is probably confusing like the rest of numa
Not exactly. There are just a few things to know about sorting maps:

It all starts with http://numa.notdot.net/browse? -with the question mark.

After that, add any of these:

sort=[rating,created,votes,random] : Sorts the maps according to any of those. Default created.
order=[asc,desc] : Displays the sorted maps from first to last, or last to first. Default desc.
count=# : Change # to the number of maps displayed per page. Default 10.
start=# : Skips # maps from the start. Default 0, adds (count #) per each page you view.
q=value1+value2+...+valuex : Only displays maps with the specified tags. Common tags are "rated", "unrated", "bitesized", "author:AuthorName", and "playable" or "nonplayable". For "author:authorName", replace authorName with the author's name (i.e. "author:gforce20").

Separate those with the ampersand (&).
Good example:

http://numa.notdot.net/browse?sort=votes&order=asc&count=5&start=0&q=rated+author:ska

This sorts according to votes in ascending order, showing 5 per page, skipping no maps from the start, has a rating, and the author is Ska.
