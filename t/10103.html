I can't run demos on the levels I get from Numa. Every demo I get just show the character moving around a bit but doing nothing about finishing the level. And I alread checked if the demo was from the correct level. What should I do?
#181731 2 2006-05-29T07:05:22Z Atilla
You're probably loading the demos incorrectly. Either that or your browser is corrupting the data.

Anyway, try the following:

1. Open N, go to debug mode, and load the level, as normal.
2. Go to NUMA and click in the textbox with the demo.
3. Press Ctrl+A to select all the data. Unless you're using a Mac, in which case I believe it's Cmd+A or somesuch instead.
4. Copy the data with Ctrl+C or the equivalent command for Macs.
5. Switch back to N and select all the data in the demo box by clicking in it and hitting Ctrl+A again.
6. Press Ctrl+V to paste the demo data you copied earlier over the junk data in the box.
7. Click outside the text box.
8. Press 3 to load the demo, Q to begin playback, and P to start watching it. And make sure caps lock is on.

If this doesn't work, look at the data you're pasting and make sure it is a similar format to this:

235:0|33554432|139810|etc|etc|lots|more|numbers|and|vertical|bars

If it isn't, you have a problem. Try using a different web browser.
