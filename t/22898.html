The DDA Editor
[color=CORN FLOWER BLUE]Well, The DDA Editor Idea, actually[/color]

I was looking at NED+ and I thought of a dda editor, which would make making ddas less tedious.

As any dda maker knows, no matter how exciting a dda might be, after the 250,343th time it gets kind of boring. So my idea would make a few changes:
  • First, and most importantly, the dda editor would just show what changed since you last watched it, and only show that bit of dda, unless the maker changes the settings.
  • Secondly, there would be better pixel-procession. I know for a fact that I need to go to the pixel with some of my ddas. Now, I use mousekeys, but I'd like to use other things, and mousekeys is pretty hard to teach someone to set up.
  • Another idea would be the ability to edit launchpads, make glitched doors/tiles easier, and other stuff that's also included in NED+. Also, there could be a way to automatically include NReality mods in there (Actually, this would be good for almost any substitute for ned because it is so confusing how to make them.)
  • Other ideas include placing multiple objects in the same spot. Some makers, when placing bounceblocks or gold delay, want to be able to place ten objects in exactly the same spot easily.
  • And, of course, the idea of faster loading. The program could detect what objects were changed, load them, but keep the others the same.
  • The ability to add an object without reseting
  • Rewinding the dda.
  • Jump to a certain frame (like go directly to frame 1,242 or something.)
  • Having buttons that automatically hold right/left or whatever.
Now, you may be wondering why I don't say "I" in this topic. That's because I'm no good at programing

So I need someone else to do it. If you want to, you can if you want. I bet it'll help out a lot of people.

If you like this idea, post. If you hate this idea, post. If you want to make this program, post. If you think of some more helpful thinks that I didn't, post.

As far as skipping to the newest part goes, you have to watch the whole thing. That tile or door you added at 2345 frames, it might have messed something up at 20 frames, but you don't know it yet. You don't want to watch the whole thing, so start watching at 2340, you die and you don't know why. So you start over 2300, you die again, start over again, and so on. At this point you're better off just watching the whole thing from the begining.

I wouldn't terribly mind the idea of fast forward or rewind, to speed up the viewing process, but you would have to be able to actually see the whole thing for the above reason.

Placing multiple objects quickly? Select your object, hit the mouse X number of times, and you're set.
Pixel precision? Z-snap.

Easier implementation of Nreality mods? This might be a good thing.

Easier ways to make glitched tiles, doors, et cetera? No, that's what makes the good ones stand out. It wouldn't be as special if anyone could do it.

Buttons for hold left or right? Right arrow key, Left arrow key.
