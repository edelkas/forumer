Right. Time for a quick lesson on IP addresses. There are three classes that are normally used, A, B and C (D is for multicast and E is not used). All IP addresses are 32 bits long.

Class A addresses start with 0, followed by 7 bits specifying the network and 24 bits specifying the host.
Class B addresses start with 10, followed by 14 network bits and 16 host bits.
Class C addresses start with 110, followed by 21 network bits and 8 host bits.

The reason that the IP address is split like this is so that you can route data around the Internet more easily. If the address space was flat, ie all 32 bits were for the host, then each router on the Internet would have to store an entry for every single address telling it where to send data for that address. With this system, you for the first 0 bit which tells you what class the address is. Then you use the next 7, 14 or 21 bits to choose where to send the data.

So you can have 2^7 networks each with 2^24 computers attached; 2^14 each with 2^16 computers; and 2^21 each with 2^8 computers. (These numbers are not quite correct as some addresses are "special".)

Now, if I own a huge network of computers, and I am given a class A address, then I get a set of addresses of the form
1 <7 digits unique to my address> <24 bits which are different for each computer>.
Unless I have 2^24 computers, some addresses are going to go to waste. The same goes for class B and class C. This means lots of addresses are left unused. Also bear in mind that a single person can have multiple PCs. Also it is not just PCs but servers and things like mobile phones and other embedded devices that use IPs these days.

Now we get to home networks. You have a set of IP addresses for your local area network (LAN), these can be anything you like as they are not visible to the outside world. Each computer has a different one, but I would imagine the first part is the same for each computer. Your router or broadband modem or whatever you have, has another IP address assigned by your ISP. This is what the outside world sees as your IP. In fact, often the outside world will have no idea about your home network, to all intents and purposes there is just one computer with an IP.
