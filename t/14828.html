Welcome to the forums

That's pretty easy to explain - it checks which penetration vector is smaller, and uses that (as you already said). For most cases that works perfectly, but not for this one. Technically speaking, completely eliminating the problem is impossible. The only solution I can think of is multi-sampling. That's what Mare and Raigan used in N, anyways: multi-sampling and a max-speed limit.

Try it and tell us if it works.
