#204302 50 2006-07-19T05:34:29Z Scott5114
Quote: chasethebase, July 18, 2006 04:49 pm
How do you add the image like on the other levels?
Take a screenshot, crop it, and save to your disk, preferably as a PNG. Don't resize it. Go to the page Special:Upload. Tell it where to find the file on your hard disk, come up with a name for it on-wiki (usually the number of the level is good - e.g. "88-4.png"), and add a description. Once the file is transferred you can get it to appear in an article by passing the name of it as the "image" parameter for the Infobox Level template. It will be resized automatically to fit, and a user can click the image to view the original version.

If you put [[Category:Level screenshots]] in the description field, it'll appear in that category, which I can see functioning as a level gallery of sorts.
