#129950 5 2006-01-05T18:23:26Z The Wazaa
There are actually a couple of verlet integration, or ragdoll, threads here already. Check them, I've put one of my own ragdolls there with comments (in actionscript). Jakobsen's paper is quite good, it gave me a lot of help.

Its hard to make a list of steps when I don't know how good you are at the programming, and also since I'm not that good in other languages ^^. I guess that maybe this would be okay:

* Graphics engine; do something simple so you can draw lines and dots.

* Particle class; make a class that declares all variables that you mentioned, and an array for the constraints.

* In the particle class do a function called main() and one other which makes sure that constraints are satisfyed (or simply put that code in the main() function) this is what Jakobsen explains in his paper.

* The main() function should add a particles x and y position with its x and y speed, and maybe add gravity. Call for the constraint satisfaction should also be done here.

* Register a variable as a particle with all those things.

* Get an array that holds all of the particles.

* In the program main loop do something like this:

for each i in partlist { // this line is "for (var i in parlist) {" in actionscript
partlist[i].main();
}
//code to draw all of them...

Good luck

EDIT: Added some things in the main() function description
