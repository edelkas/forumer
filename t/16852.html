#311517 2 2007-04-09T10:17:23Z George
That's easy to do. And it was implemented a long time ago. In the address bar, replace 'browse' with 'userlevels', and it will automatically download the maps on that page. If you wanted to download a specific author's maps (or a large number of maps in one go), just add '&count=x' (where 'x' is a number of your choice) and it will download that many maps.

An example:
I want to download all the top rated one hundred maps.
http://numa.notdot.net/userlevels?sort=rat...=desc&count=100

Hope this helps.

It also helps to search around sometimes. This was a recent topic discussing a matter similar to this, the seventh latest posted in this subforum.
