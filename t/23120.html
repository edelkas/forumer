When playing N, I couldn't help but think about how cool a fighting game with the same mechanics would be. I know that any kind of fighting would make N severely less awesome, but I think that N's design is perfect for a new kind of game.

How would it be if there were a game like N, except the ninja had a "hit" button that could be used with the directional buttons to hit player 2's ninja in different directions? There would be no need for the surplus of levels and features in N, just N's physics, a "hit" button, a 2nd player, and possibly NEd. If done well, the game could make for fierce duels similar to (or better than) battles in Super Smash Bros.
