#314605 8 2007-04-20T22:15:55Z lord_day
Bits of the map were cool but here is some advice:

1) Firstly, don't make dead-end corridors that you die if you go down. It makes the game guess work, and makes it alot less fun.

2) In some places only half the number of mines were needed. Try to not place uneeded objects as it increases loading time.

3) If posting the level on the forums, post it in a .txt document, not a word document. It makes things easier for everyone!

Hope that helps.
