connecting with mIRC
if you use irc quite a bit, then we suggest using a client to connect such as mIRC. not only is it easier to use, it features some great additions such as the ability to start file servers, transfer files and connect to multiple servers all in one go. folow these simple steps to connect:
type /server irc.phrenzy.org to connect.
you'll probably need to register a nickname for yourself...
to select your nick, type /nick <nickname>
to register it, type /msg nickserv register <password>
now join a channel and start talking to us...
to join a channel, type /join #<channelname>
don't know what channels there are? try /list
