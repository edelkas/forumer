#31197 4 2004-10-09T01:38:37Z Maniac
Don't worry, I've actually discovered why this happens, even though I know nothing about Flash.

In N's script, from the Collision Detection, N is riding the thwump. N is actually colliding with the thwump, so the script moves him upwards to avoid overlap. Result: N rides the thwump. Now, when N gets squished against the ceiling, N can no longer keep moving up. So, he dies.

Sometimes, however, N is closer to a certain side, so the script sends N flying out of the situation. Result: the now universally known Lucidium Effect, where you can get squished between a thwump in DDAs for transportation.

This might have been a bug in the collision script. Try playing the level again to see if it persists.
