Can you further explain #1?
Back before people knew that much about electromagnetic radiation, people thought that light (when I say light, I mean all electromagnetic radiation, not just the visible spectrum), like all other kinds of waves could only travel through a medium, such as air or water. if you put a wireless speaker floating in a vacuum, it won't make any sound since sound requires the vibration of molecules, which means something has to be there. Since people thought that light needed a medium to travel through, but light can move in space- in fact it moves fastest in space- so people invented a fictional medium called the aether, which is a colourless, odourless, massless (I guess), and completely undetectable medium which is located in the "absolute reference frame", meaning it's not relative to anything. It would be nice if we could express our position and speed in an absolute reference frame because then it would be a TRUE inertial reference frame instead of an accelerated one where the acceleration is not very significant, but we can't. Turns out, light CAN move without a medium. Mediums just slow it down. So the aether doesn't exist.

As for #1, sigma notation (that sideways M is the greek letter Sigma) means you take all of the integer values of k (or any letter you prefer- usually k is used) between Q and P inclusive where Q is the number at the bottom of the sigma, and P is the number on the top- in this case 1 and x- and add them together. (so summation of k=1 to 4 of k² would mean 1² + 2² + 3² + 4².) Since x is the number of times, you just add the sequence of number up to x times (1² + 2² + 3² + ... + (x-2)^2 + (x-1)^2 + x²). Since sigma notation is really a recursive definition (since all your doing is taking the previous number and adding k^x to it (for the example in this post, not in the comic). Most recursive formulas can be expressed in a non-recursive way (first restricting the domain to integers) (for example summation of k=1 to k=n of n can be expressed as n*(n+1) / 2.) As far as I know, the only way to figure out the non-recursive version of a recursive function is to write down the first set of terms, look at the pattern, come up with something you think works, then prove it using either induction or strong induction. if you can prove it, you're right. If not, you're probably wrong. Not all recursive functions can be expresses non-recursively though- for example, the fibbonaci sequence. (well, actually it CAN, but it involves using the floor function (rounding down)).

In the summation in the comic, the dominant term is in the denominator, so the summation will converge to a value as x approaches infinity (limit time!). The absolute value is in there to make it a bit trickier. I wonder what the solution to that question is. I have no idea and lack the motivation to figure it out.
