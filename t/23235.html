#455274 9 2008-07-26T23:57:58Z Tapp
I've been working hard on the game (and hardly working on my homework). There is one universal answer to most of your complaints: I'm trying to make a demo of all the features so you guys can give some critique on it, I'll fix up all the little things later.
Lenny: The reason that it has a white backround is because this is the training level, which is supposedly held in a holoshed. I have also realised that game maker is really bad with graphics unless you have pro, since it doesn't allow for transparency. As I said, I'll fix the laser, rocks and player once I've finished the last weapon (which is way too awesome for anybody to see until the project is finished). There will be a menu, just it isn't in yet. Same with saving, for now you can use F5 and F6. The controls for the new things are as follows:
A is the sticky bomb (re-named and re-functioned the blender), which fires one circle for every B circle that you collect.
S is the black hole generator. You must collect A circles for 'Atomisers' in order to use it. In the full game you will start with about 3 'Atomisers'
D is the rocket, which must be collected through R circles. Once again, in the full game you will start with about 10
Space is the laser bullet, and you can hold it down to charge up. Then release space, for a laser that lasts as long as you charged it.
Ship movement is still the arrow keys, though
P circles are so far useless, as the super-special-awesomiser weapon is not made yet.
S circles boost your score
D circles kill you
The dieing is still a bit glitchy, and the rocks vibrate once they reach the bottom, but if you ignore that, I reckon this is going to be a pretty awesome game.
