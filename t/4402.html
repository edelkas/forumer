#90270 3 2005-08-12T18:46:37Z Guest
we've been trying to do this, however we can't seem to find a fast/good method. if anyone knows php/mySQL and would like to suggest something, we'd appreciate it.


the main problem is that the tables themselves aren't sorted, so there's no concept of "who's #0?" or "what # is user ___?".. like, there's no built-in property you can query to get that info.

to get the # of user ___'s score for levelX, all you can do is ask for the records for levelX sorted in order of decreasing score, then loop through them and count how many records you pass before you hit a record with name=___.. this is a horrible solution.

to find out the number of #0 scores for a given person, we have to query each level for the #0 score, then see if the username matches.. obviously this is a terribles/slow solution. it just gets worse for "the number of top20 scores" since we have to get the top 20 for each level, then loop through all of them, counting.


obviously there should be a simple SQL query which will generate the results we want without us having to do all sort of manual looping and counting.. sadly we still haven't figured it out.
