hi,
flash uses it's own special (and annoying) "cookies", called shared objects. the flashplayer and/or the OS controls where the .sol file is saved, which is probably the problem as it's typically buried in the windows directory.

if you search for a thread on shared objects, you should be able to find an example of a path to a .sol, HOWEVER trying to reproduce this will more than likely not work, since it seems to be different for everyone.

we're trying to get proper file-based save/load working, however it's a bit of a challenge since flash was specifically designed to not be able to do this.
