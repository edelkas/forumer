Word, I found the source of the problem: sound. The Flash player apparently has an issue with audio in Linux, but simply turning down the volume to 0 is obviously not enough; you have to make something occupy the audio driver before you start the game so that Flash can't use it. I happen to use KDE, so I trigger a sound event right before starting the game, which makes aRts take control of the audio driver long enough to start N.

This is slightly off-topic, but could help in getting N to work in Linux.

With WineX, (and likely WINE) the Windows version works fairly well, after a bit of work.

Usually, when running on WineX, the keys do not do anything. I discovered this is due to a missing registry key. After adding the key, Windows N is playable in Linux. (The input is still a bit. . .odd, though.)

The correct file to edit is user.reg. This is either in ~/.wine, ~/.transgaming, or ~/.point2play/N, depending on which variety of Wine you used.

Find the [Software\\Microsoft\\Windows\\CurrentVersion\\Explorer\\Shell Folders] section, and add:
"AppData"="C:\\My Documents"
to it.

After doing this, run N. Flash should come up with a message about N trying to store data on the computer; allow it, and it should work.
