Quote: Skyflyer, March 01, 2008 12:23 am
Yes, I am.
Does it matter?

Well, Macs are notorious for having weird problems with saving progress, and the usual solution is different for Windows.

Anyway, the .sol file is created when you run N for the first time. It won't be in the N folder, but rather in some obscure directory where all Flash applications store their info. You need to find this file - it should be called n_v14b_userdata.sol - and back it up. I believe it's in a randomly-named folder in #SharedObjects, on a Mac.

Once you've done that, delete all the random folders from #SharedObjects and empty the trash. Run N to create a fresh .sol file. To get your progress back, close N, find the clean .sol and replace it with the old one.
