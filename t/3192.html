#2876 1 2005-05-16T12:38:10Z astro
Firstly, it's for Windows, so all you Mac'ers can go elsewhere. Face it, you didn't get a Mac so you could run lots of programs. Anyway, this is NLO. You can split up all your user levels into seperate files (they all need to start with "&userdata=") and use NLO to edit them or switch them with the current userlevels.txt for use in N. In other words, you can keep different kinds of levels in seperate text files, which makes it a lot easier to maintain.

Yep, it's Visual Basic (needs VB6 runtimes), and I haven't bothered optimising it or anything, so it can take a few seconds, up to 1 min, to load big (200kb +) files (switching is near-instant). Oh, and you don't need to exit N to switch files, just click refresh list in N.

New version, you don't need waste time loading the files unless you want to edit themwhich really isn't advised, since a real text editor would be faster and gives you more flexibility.
