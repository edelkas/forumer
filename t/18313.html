#341612 4 2007-07-11T03:04:17Z Raigan
You shouldn't need to use any trig at all, you just need to store unit vectors/directions as unit vectors, not as angles. If you're using angles, you'll have to first generate the equivalent unit vectors, which requires sin/cos.. i guess it's the same either way, since (to transform your unit vectors when your object rotates) you'll be using a matrix built out of sin/cos terms.

I really recommend learning basic linear algebra/vector stuff to the point where you understand exactly what's going on in rotation matrices, it's great when you finally "get" it and it stops being weird black magic.
