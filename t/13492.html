Bonjour

1) Ouvre programme N
2) Appuis sur configure
3) Mettre un identifiant et un mot de passe dsirs
4) Appuis sur le bouton create new user
5) aller sur http://numa.notdot.net
6) abonner avec ton identifiant et ton mot de passe
7) apres tu a fini une niveau appuis sur le bouton 'Submit a map'
8) dans le machin ave map name a cote, ecrit le nom de ton niveau, Category N version N1.4 Description une decription de ton niveau et le map data, le data dans le premier plus haut boite en 'debug mode'

Si tu a un probleme ecrit encore...
