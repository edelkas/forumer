#80490 24 2005-07-02T09:39:08Z Guest
I was experimenting with some stuff in c++ and wanted to control the framerate of an animation, so I wrote something to control the framerate. Basically, I used usleep(x) at the end of the animation where x is the number of microseconds between refreshes. One would convert this into the more common frames/second measurement by doing fps=1/x.

so if ms = the ms/f number in the bottom left, then your frames/second = 1/(ms/1000) or 1000/ms.

Granted, few people can read the number and do the calculation before the number changes, but it usually hovers around one number or another.
