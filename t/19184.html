deadly_cookie, in case you haven't noticed: At the top of this forum, there is a large notice that specifically states that any ideas that add warfare, multiplayer, or extra keys are not going to be implemented whatsoever. N is a simplistic game in which the main objective is to simply avoid enemies, collect enough gold to sustain your life, and exit the area via an exit door. Your ideas are much too complicated for a game like N.

Jetpacks - Pretty much cheating half of the levels, and also adds another key to be used.

Duck/crawl - You would obviously move slower, and this would not protect your from floorguards. It really doesn't seem plausible to add in the game.

Rope climbing/swinging - While this will never make it into N, Metanet's upcoming shareware game Robotology is going to revolve around some type of physics system using ropes.

Grenades - This is considered warfare/fighting/competition of some kind.

Kick/punch - Same as above.

Multiplayer - N+ is coming out on the PSP, DS, and Xbox Live Arcade (XBLA) hopefully by the end of this year. It will feature multiplayer maps, so be sure to look out for it!

Teleport platforms - Well, teleporting can already be accomplished via a tutorial that LV has set up... located here.

Particle based water - I do not have any feedback on this, sorry.

Oh, and for future reference, please take a look at some of these:

The FAQs (Which can now be updated by certain members of the community, so check back on them once in a while.)
The N Wiki - A plethora of information and details about several things regarding N and the community are located here.

In addition, you should read up on the Forum Rules... we wouldn't want you to end up suspended for something silly.
