Here is what I would do if I were you.

Create a companion program that would be binded with N so that they both open at the same time. The main program would put instructions into the clipboard for the companion program to carry out. The companion program would monitor the contents of the clipboard. If something new has been put into the clipboard then it checks for an identifier string that the main program would put at the begining of the copied data. If the contents of the clipboard doesnt have the identifying string it ignores the contents of the clipboard. After this identifier string there would be another string that would identify what it is that the main program wants the companion program to do, ie save to disk or read from disk. Finally after the identifying string and instruction string there would be the actual level/demo data. Alternatively if the main program wants the companion to get data from a text file it would just have the identifier and instruction. Once the companion program has got the data from the text file it would put the data into the clipboard along with its own identifier so that the main program knows that the clipboard contents come from the companion.

This is just one way to do it. I suggested it because I know you can save stuff to the clipboard and read from it. If you could send data to other programs directly it would make it even easier.
