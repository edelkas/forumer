#155570 2 2006-03-18T11:01:37Z krusch
You'll need to upload it somewhere, I suggest you get an account on FileLodge, which is pretty reliable.

Then you have to upload the image and get the direct link to it, which will look something like: http://www.filelodge.com/files/room15/386751/image.png

Then go to to where you edit your signature and copy in that direct link between two 'tags'. You can type the tags manually or use the button near where you select font/colour etc.

It'll look something like:

[IMG.]http://www.filelodge.com/files/room15/386751/image.png[/IMG.]

Note: I used the full stops so it wouldn't read that as an actual tag. Don't put the full stops in when you want to display an image.


I hope that all works for you.

#155574 4 2006-03-18T11:38:45Z astro
It cannot be fixed for a number of reasons. Firstly, the Metanet forum administrator's can't change it because they don't have total control over the forum, only Forumer does. Sigs almost always contain text and sometimes images, so they can't just have you set an image as a sig and nothing else.

This means forumer would need to have their own image hosting service. They would have to use lots of bandwith to host all these sig images, which they probably couldn't afford.

Even if they could, they would have to put a restrictive size limit on the images, which would be a big disadvantage for everyone.

It's so easy to find somewhere reliable to host your images online, so Forumer would never this service anyway.
