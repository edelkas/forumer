Hi,
here's a new version of 1.4, just a few little fixes

pc: http://www.harveycartel.org/metanet/n_v14pc.zip

mac: http://www.harveycartel.org/metanet/n_v14mac.sit


We want to get the final version up by the end of the weekend, so please test this version and let us know about any bugs by posting on this thread.


specific fixes:

-progress-importing should work for _everyone_ now
-practise mode works with user levels
-tile-edit graphics alignment problem fixed
-boss-mode key changed to tab/grab-ragdoll key changed from tab to ctrl
-drone snapping problem

we haven't updated the userlevels.txt or any of the docs, but we will for the final release.

thanks,
mare and raigan
