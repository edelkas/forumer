ok, so i changed computers (problem) and put N onto my new one but whatever file the save was in wasnt brought over, my old computer is still set up, does anyone know what i have to transfer over to get my main game progress (and flavors) back?
#345741 2 2007-07-21T07:56:32Z apg
Your progress is saved into a separate file, called 'n_v14b_userdata.sol'. If you're using Windows xP, the .sol can be found from C:\Documents and Settings\[Username]\Application Data\Macromedia\Flash Player\#SharedObjects\[random series of letters and numbers]\localhost. Transfer the file to the corresponding location in your other computer, and everything should be fine.

#356775 4 2007-08-18T18:07:22Z Chase
A word of warning. .SOL files are VERY fragile, so if you misplace it, or run N with it in the wrong place. It'll wipe all your data.
#356789 5 2007-08-18T18:50:06Z usaswim
To replace a new .sol with one with progress on it, you first rename the existing .sol to something else, and copy-paste the progressed .sol into its place and rename it n_v14b_userdata.sol if it isn't already. You can delete the other one if you want, it's useless.
