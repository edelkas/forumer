#133185 2 2006-01-17T16:33:56Z Raigan
the tutorial's correct -- if you don't have any, i _strongly_ recommend getting a pad of graph paper, since drawing these things can be really useful.

i didn't really understand/believe the normal "formula" myself, but try it: using graph paper (so that you can easily count integer coordinates), draw any vector, like (3,-4). now, draw a line of the same length that starts in the same place, but is perpendicular to the first line: the end of the second line will be (4,3) or (-4,-3).

i'd also recommend downloading the example source code that's included in the tutorials and reading through it, you can see normals being used.
