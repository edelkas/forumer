When I first found N, I had Version 1.2. I had gotten quite far n it, beating Episode 9 and 19 without cheating, and unlocking Episode 24, and beating all levels in it except Pitcher Plant.

When I redownloaded Version 1.3, I realized that I would have to beat those levels all over again.

My suggestion for Version 1.4 is that N automatically saves your progress in a file, that can be read in by N so that you can have all your levels unlocked again. This file would have to be compatible with later versions, and would also have to be encrypted so that people couldn't just go around making files so that they could essentially unlock all the episodes by cheating.

This would certainly save some frustration in the future.
#24731 2 2004-07-12T17:51:08Z Guest
there are a couple threads on this already -- basically subsequent versions of N will not erase your progress.


The progress is already saved in a file, a .sol file that is written by the flash shared object we use to store the saved data.

The reason we had to get rid of 1.2's saved data was because it would have interfered with the highscores system.
So since that's essentially done, we shouldn't have to wipe the saved data again.


Anyway we're sorry you had to lose your progress.

good luck!
