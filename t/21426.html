#408319 2 2008-02-10T02:31:01Z LittleViking
The lightbox script is unobtrusive enough that you can apply it from your local machine as long as your browser allows custom javascript and CSS.

In Opera 9:
Save lightbox.js and lightbox.css to your hard drive. (Doesn't matter where you save them to.)

Open lightbox.js and edit these lines:
Quote: Lines 38-39
var loadingImage = 'loading.gif';
var closeButton = 'close.gif';

to

var loadingImage = 'http://i26.tinypic.com/ivllya.gif';
var closeButton = 'http://i30.tinypic.com/112a5vk.gif';
Quote: Line 292
if (anchor.getAttribute("href") && (anchor.getAttribute("rel") == "lightbox")){

to

if (anchor.getAttribute("href").substr(0,13) == "http://static"){
Now open lightbox.css and change:
Quote
#overlay{ background-image: url(overlay.png); }

* html #overlay{
background-color: #333;
back\ground-color: transparent;
background-image: url(blank.gif);
filter: progid:DXImageTransform.Microsoft.AlphaImageLoader(src="overlay.png", sizingMethod="scale");
}

to

#overlay{ background-image: url("http://i30.tinypic.com/15mhf1e.png"); }

* html #overlay{
background-color: #333;
back\ground-color: transparent;
background-image: url(blank.gif);
filter: progid:DXImageTransform.Microsoft.AlphaImageLoader(src="http://i30.tinypic.com/15mhf1e.png", sizingMethod="scale");
}
Then in your browser, open up a Numa map page. Right-click anywhere, go to 'Edit site preferences...', and at the bottom of the Display tab and Scripting tab, select the lightbox files you just edited. Restart your browser, and if everything went well, you now have lightboxes on Numa thumbnails.
