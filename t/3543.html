#72894 4 2005-06-07T00:55:08Z moochai914
yeah, if you want a long description, here it is:

when you've completed the level (or, if you just want a break), then click in the box that says "level data." press ctrl (command)+a to select all, then press ctrl (command)+c to copy it. paste it into a new notebook document. if you're using max osx, then you can also use textedit or simpletext. when you want to load up the level again, copy the code and paste it into the leveldata box and click "load from level box." it should load up again.
