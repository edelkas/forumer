#202041 3 2006-07-13T04:41:09Z jtbandes
Well, my thought is that it would actually be easy to implement. But first, here's some clarification:

Let's say you have three userlevels files: one for the ones that come with the game, one for your favorites, and one for the Legacy levels. Now, each time you wanted to switch between these, you have to rename them. With my idea, going to the userlevels menu option in the game would give you a list with those three files in it: Original userlevels, Favorites, Legacy. From there, you'd click on one of the collections to load those levels, where you would see a screen like the one that is currently implemented in the userlevels.

I'd think that, since the game can already parse the userlevels.txt, it would be easy to do. The game would just look at any .txt files in its directory, and see which ones were userlevels collections (which ones have the "&userdata=" line). It would then grab the name of each collection out of a user-specified line (maybe, for instance, instead of "&userdata=," "&usercollection=Legacy&userdata="), and you'd see an easy-to-understand list of your collections.
