Spoiler: Clauses
Species Clause
A species clause is a restriction on the number of same Pokemon you can use. If a species clause is in play, then you can only use one of each Pokemon in your team. So no teams of 3 Scythers and 3 Arcanines.

Item Clause
An item clause limits the number of same items allowed to be held by the Pokemon. For example if it is in play then you may only have 1 Leftovers item being held by a Pokemon.

Type Clause
A type clause would be used to stop you from using Pokemon of a specific type. Though rarely used, may be put in place by a Leader to make it a slightly fairer match. For example a Fighting Type clause being enforced by the Dark type Gym Leader.

We will allow the usage of Type Clause but to make it fair a few rules were put in place:
You can clause only one type
Pokemon of dual types are not allowed in the Gym. For example if Dark Type Pokemon were claused, then a Houndoom or Tyranitar would not be allowed.

Sleep Clause
Very common clause which stops people from mass Hypnotising entire teams. This limits the opponent to only put one Pokemon to sleep at a time. If affected Pokemon faints, you can put another Pokemon to sleep.

Burn Clause
Hard to actually enforce, but the idea is simple. The opponent can only use Will-o-wisp succesfully on only one Pokemon at a time. If affected Pokemon is fainted, WoW can be used again. Unintentional burn from attacking moves does not count.

Para Clause
Same as the burn clause. The oponent can only use Thunder Wave or Stun Spore succesfully on only one Pokemon at a time. If affected Pokemon is fainted, the moves can be used again. Unintentional paralysis from attacking moves does not count.

Poison Clause
Same as the two above. The oponent can only use Poison Powder, Toxic and Poison Gas successfully on only one Pokemon at a time. If affected Pokemon is fainted, the moves can be used again. Unintentional poison from attacking moves does not count.
