Well. This is due to me wanting to have a power trip somewhere other than the Epic, seeing as it's almost finished. (And only 1 year after what we originally were expecting! ) So, here's my newest map collaboration project...

Common Ground.


Map list.[/color]
Halo.


Rules. [/color]
*All maps must have something in common with the last map posted.
*What this common ground is, is entirely up to you- It can be very trivial, if you want it to be.

Common Ground can be...[/color]
*A style of mapmaking
*A genre. (Race, puzzle)
*A feature of a previous map. (Lines through tileset, edited launchpads)
*Using same enemies in similar ways.
*Using similar feeling
*Whatever- there are many, many more options than this- as long as you can explain what the map has in common, and other people can see this, it's all peachy.

Common ground cannot be...[/color]
*Unrelated to map code. (Title/ Description/ ect)
*Impossible to see without being told what it is
*'Inspired' by similar sources. (Such as, a song- see point one.)
*Anything too small.

On the last point, an example of what would be suitable would be "We both use floorguards to result in undeath", and an unsuitable example would be, "Look, we both use floorguards somewhere in the map, even if that's the only common enemy." Mainly, this is all just common sense.

Que...[/color]
I'd prefer not to have one, to keep the maps flowing quickly... you can 'shotgun' a map to work on, but that'll only last for a few hours, rather than a few days. Basically, there's no formal rule that can allow you to keep a map to yourself, more than hoping other people respect your attempts to reserve it for yourself.

Maps...[/color]
I'd like this thread to go in two directions at one, to keep it moving even further- so, let us begin with Halo. From here, we can have two maps using something in common- and then, from those maps, one each. So, what I'm aiming for is a form like this:

(Map) (Map) (Map) (Map) (Halo) (Map) (Map) (Map) (Map)

Thus, letting people choose between two maps to work on, to give this thread some more pace.

So, anyway, let the games begin!
