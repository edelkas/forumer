#22087 8 2004-04-08T14:50:08Z Guest
Debug mode is (obviously) for testing various things. Creating and testing levels and objects is the biggest part of this, which is why Ned is found in debug mode, and not directly from the main menu.

In debug mode, it's essential to be able to run the program frame by frame, to see exactly how the collision, physics and other systems are running. But you also need to see how the program runs in real time. So capslock toggles between those 'run modes'.
