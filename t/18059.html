The object of this game is simple. A user posts a made-up word and then the user below them posts a definition of that word as well as another made up word.


Example:

Post 1:
---
Gyhungra
=============
Post 2:
---
*A large animal, probably a cross between an alligator and a bear*

Bunvr
=============
Post 3:
etc, etc, etc




And so on and so forth... Get it?
