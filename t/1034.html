I suggested this during the 1.3 beta, and Raigan's response was:

Quote
hey,
the problem with the ghost idea is that it would take twice as much cpu work, since the "replays" are essentially the regular game, with the keyboard replaced by a recorded set of input. so.. it just wouldn't run fast enough.

[snip]

raigan

If you think about it, in something like Mario Kart you can only watch ghosts when there aren't any other racers...only in Time Trial mode. This is because the racers are somewhat randomized, and when you watch your ghost you really don't have the context for their motions. This is similar to N...having your ghost around would be really difficult to interpret because the tiny differences in movement would make the enemies move differently. It could be really confusing to have the ninja ghost move somewhere that you are blocked from because you activated a drone at a slightly different time. There are some levels where this would work nicely, but most of them I think would be too confusing even if it weren't technically undesireable.
