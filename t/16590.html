#311830 12 2007-04-10T11:48:21Z Delgadude
Ok, I recently got a new computer, it has 2gb of RAM (short for random access memory, it's what makes programs on your desktop run faster, open faster, and decides how much stuff can be going on at one time.) I've never had my ms/f (frame rate, in the lower left corner of N game) go over around 10. Before that, I had a 2001 computer, and it only had 64mb of RAM (about 1/16th of what I have now).
Video cards improve how fast your computer loads and displays graphics, which shouldn't be a problem because N doesn't need much graphics to run.
The processing speed also helps make programs run faster, so if you have an older computer you might just have a really slow processor.
If you really want to, you may want to consider buying more RAM, or just a new computer, but both are very expensive.
And to clarify, iTunes doesn't really help N run faster, it just takes up more space and would do the opposite. What might actually work is running a program before running N, just to warm up your computer.

Quote: Delgadude, 2007-04-11T16:56:25Z
Apple (makers of iTunes) wouldn't put in a mechanism that helps N game run faster.

He isn't claiming they would. Any external media player, whether it be iTunes, WMP, Winamp, or whatever, can circumvent compatibility issues that N has with some sound cards and/or sound drivers. I understand this is due to some kind of problem with N telling the card to begin playing a sound, which doesn't arise when other sounds are already being played by another application. It has nothing to do with the manufacturer of any given media player.
