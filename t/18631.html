#349384 6 2007-07-31T17:01:04Z usaswim
http://numa.notdot.net/userlevels?count=1200&q=author:littleviking001

Tells the computer you want it to attach them in a userlevels.txt
How many maps from that user you want. If you want all of them, type a high number, like 2000
This tells the computer you want to search by tag.
This is the author tag default on all maps.
