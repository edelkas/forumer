If anyone else needs help like i did

Quote
Well, If they are on a website, you should...
1. Go to My Controls.
2. Go to Edit Signiture.
3. Put the website with the image in IMG tags. (One at a time.)
4. You should be done!

If your pictures are on a file, then you should...
1. Go to a place like Image Shack.
2. Host your image there.
3. Come back to the Control Panel witha link to the image, and put it in IMG tags.
4. You should be done!

So there! Hope this helps!
