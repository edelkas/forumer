Hello,

I have been playing N for 8 days now ( ) and I have had some ideas on how to maybe make it better.

1) Make the Ned editor a bit easier to use, maybe more GUI. I am pretty tired of pressing keys on my keyboard to do something. Why not have a GUI system?

2) Settings system. You can double click on an object and a settings box will popup. In that box you will be able to control different things. For some of the enemies, you can set speed, delay between shots, .etc This will also be helpful because it can be used to remove the need to pick a direction for the bot or object. Just place the object onto the map, and edit settings. Edit the direction with just a simple click of a checkbox/radio. For the platforms you can select the angle of the platform in addition to the speed to shot the ninja out at. I think this will increase the different types of levels people could make aswell as make DDA levels easier to make and more fun.

3) Define enemy paths. Instead of just making the enemy "hug" the wall, why not be able to define their path? Just click on the boxes you want them to go to and they will follow that path.

4) This one is a suggestion for NUMA. I am not sure if NUMA already has this, and if it does I am sorry.. I guess I didn't notice it. But, how about a link on NUMA's menu which will generate a txt (or zip/archived file with a txt file inside) with all of the maps in NUMA's DataBase. You could also for example, set the settings to what you want to be included in that file. Select the categories you want to include or maybe get all the maps by an author, or even select all the maps with a x or greater/less rating. This way, users don't need to copy and paste tons of snippets of map data. Also, if the user is logged in NUMA will remember their last time of downloading the file and the user can then select to download a file with all the new maps that were added since their last time downloading the file.

The txt file could have all the maps ordered by author/category in it with comments in the file with the category/author that will follow.
ex:
//----Maps by user: robodude666 ------------------------------

$map.....

or

//----Maps in the category: Action ------------------------------

$map.....

C&C are welcome I am sorry if any of these suggestions were already suggested. I couldn't find any of them through search. I will edit this topic if I get any new ideas.
