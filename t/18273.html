LittleViking's N Level Generator
Version 1.0 - July 08, 2007
littleviking001@yahoo.com

The LV Level Generator creates an N level based on random numbers, math, functions and internal logic. The user never has to see these functions to use the program. For most people, this program will be as easy as clicking "Generate" and playing the level that comes out.

The program's creation was motivated by a general desire to put the ideas behind N levels and good map theory to use, and also the lack of a good, existing N level generator and the apparently huge barrier of entry in making one. i.e. "If you don't know Visual Basic, own an expensive development environment, and have a computer Science degree, you can't make a program like this." This program was coded in a week (fervently), using nothing but a plain text editor and a web browser, by basically just dividing the task down to an object-by-object basis. Once the backbone of the program was working, it was just a matter of adding objects over and over until the whole game was covered. (For anyone who has ever coded chess, it was a very similar experience.)

I mentioned earlier that there was an apparent barrier of entry that was stopping people who might have wanted to code an N fan program like this. One of the original visions for this program was to have a final product that was easy modify and add to by people in the community. This vision has held up through the project, and I can confidently say that anyone who wants to modify the program and knows their way around logic a bit, can do so. As an example, I didn't bother to add surface-follow drones. I just didn't feel like coding another object that would have to check and iterate until it found a wall to cling to. I got enough of that from the floor guards. However, if you want them in there, you could find the code I used on the floor guards and build a new function based on it which outputs a drone instead.

The below is quoted from the N_Main.js file.


The one, single reason I chose to write this in Javascript, rather than PHP or a compiled language, is that anyone can open up JS code in notepad, write a function, and run it in a web browser. I'm not trying to say I picked JS so I could write it more easily. What I'm saying is that I chose Javascript so -you- could write more easily. No matter how well I think I know N levels, there's no way I could ever please everybody by myself. So I've tried to make this generator as easy to mod as possible. Basically, you can code a function (read: copy/paste, then edit a function), tell the program it's there, and begin using it right away. I imagine tile code files specifically aimed at making jumper puzzles, object sets aimed at doing survival maps, so on and so on. I have included 23 functions (some tile, some object) that work for all-around action maps, with kind of an avant garde feel. In any case, they should be a good starting point if you choose to add to the generator library. Even if you don't, enjoy the outputs, and thank you for reading.
                            -LittleViking


And with that, I leave it to you. Enjoy the program, let me know what you think of it. And please, if you don't like it... Consider changing it.

If you want to preview the program (or just use it exclusively online) you can see it on The Real N:
http://therealn.com/nlevel/

For a few examples of what it can do, see my latest submissions to Numa. (Note that the first map came before mines and gold were coded in.)
