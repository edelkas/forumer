#14780 1 2007-04-09T19:40:30Z uNcoNditioNal
At the moment, the way we levelpack seems rather crude to me. We still post huge text files to the forums like everybody used to do with single levels before NUMA, so my idea is this: How about a way we could post our levelpacks to NUMA? It would solve several problems in my opinion:
  1. You wouldn't have to go to all the trouble of organizing a .txt file with all the syntax etc.
  2. Your levelpack would get more attention.
  3. It would be easily accesible.
  4. Multiple authors could be sited.
  5. You could use it as storage before it "goes public".
One thing I wouldn't like to see happen is the ability to rate levelpacks. I think it would work a lot better if you could only favourite a levelpack if you wanted. I'm sure it would be a lot of work, but it's something that I'd love to see implemented.

Thanks for taking the time to read this and I'd love to hear your opinions.
