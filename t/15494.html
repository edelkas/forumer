A. Check the editor_manual.txt or .doc. for Section 6: Playing in Debug Mode -- you need to have [caps lock] turned on to run the game in debug mode.

Did you remember to turn caps lock on?

As for the tiles being messed up, that's because the upper box is for the map data and the bottom text box is for demo data. If you start including extra numbers into the map data box, it's going to create problems for your level.
