Also, here is a flame thrower I made in wxSand. It's a bit buggy and some times backfires but you can but a fail safe in with the protect element. Though sometimes you need to replace it.

#wxSand: Owen Piette's Falling Sand Game
#Version 4.4, File subversion 2

#For erasing and such.
element Empty 0 0 0 0 0 0 0 1
#Fire for lighting things.
element Fire 255 180 0 -1 1 0 1.090 1
#Is lightable.
element Torch 255 255 0 0 0 1 0 1
element Burning 255 0 0 0 0 1 1.1 1
neighbor 1 Fire Torch 1.0 Fire Burning
neighbor 1 Burning Torch 1.0 Burning Burning
self 0.07 Fire 1.0 Empty
hotcolor Fire 255 0 0
#For shaping of the flame thrower.
element Gun 128 128 128 0 0 1 0 1
#For the firing end of the flame thrower. May need to be replaced.
element Protect 0 0 255 0 0 1 0 1
#For firing out of the flame thrower.
element Fuel 228 228 0 1 1 0.2 0 1
element BurningFuel 255 0 0 1 1 1 1.1 0
element Flamer 255 0 0 0 0 0 1.1 0
element Flamer2 255 0 0 0 0 0 1.1 0
self 0.042 Flamer 1.0 Empty
self 0.05 Flamer2 1.0 Empty
neighbor 1 Fire Fuel 1.0 Fire BurningFuel
neighbor 1 BurningFuel Fuel 1.0 BurningFuel BurningFuel
explosion BurningFuel Fuel 255 -999
neighbor 1 BurningFuel Empty 1.0 Flamer BurningFuel
explosion BurningFuel Empty 255 -999
neighbor 1 Flamer Empty 1.0 Flamer2 Flamer
explosion Flamer Empty 255 -999
neighbor 1 BurningFuel Protect 1.0 Empty Protect
neighbor 1 Protect BurningFuel 1.0 Protect Empty
pexplosion Protect BurningFuel 1 Empty
pexplosion BurningFuel Protect 1 Empty
neighbor 1 Flamer Protect 1.0 Empty Protect
neighbor 1 Protect Flamer 1.0 Protect Empty
pexplosion Protect Flamer 1 Empty
pexplosion Flamer Protect 1 Empty
neighbor 1 Flamer2 Protect 1.0 Empty Protect
neighbor 1 Protect Flamer2 1.0 Protect Empty
pexplosion Protect Flamer2 1 Empty
pexplosion Flamer2 Protect 1 Empty
#A target for the flame thrower.
element Wall 128 128 128 0 0 1 0.2 1
hotcolor Wall 255 0 0
neighbor 1 BurningFuel Wall 1.0 BurningFuel Empty
hotneighbor 50 BurningFuel Wall
neighbor 1 Flamer2 Empty 1.0 Flamer2 Fire
neighbor 1 Burning Empty 1.0 Burning Fire
self 0.02 BurningFuel 1.0 Empty

Save it in notepad as a new .txt file and load it into version 4.4. You can all use it in whatever mod you want.
