*sigh* Okay...
First off, read your Ned manual before asking any stupid questions here.
If you for some reason are unable to comprehend what it's saying, lemme try:

When you start up N and you see the main menu ("Play Game", "Time Trial", "Story", etc.), press the ~ key. It's the key above the tab button, to the left of the 1 button. Do not hold down shift when pressing this button.
You will now see the debug menu...
"**** DEBUG MENU ****
[M]: mainmenu
[L]: load level (from textbox)
[S]: save level (to clipboard)"
... etc.
Click inside the upper right text box (it will already have text in it). Hold down control (below the shift key, it says "ctrl" on the button) and press the A key (do not hold down shift when pressing the A key). This means you are pressing one button while holding down another, and no other buttons are being pressed. Let go off the Control key (your finger should already be off the A key). Now press the delete button. The delete button on most keyboards is located above the directional arrow buttons toward the right side of the keyboard. It says "delete" on it. This should remove all the text in the upper right text box (labeled "level data").

Now what you do is find the level code of the level you wish to load. The level code usually begins with a whole bunch of numbers. We like these numbers. The numbers are good. Highlight the level code by taking your mouse cursor, placing it to the left of the first bit of the level code, holding down the left mouse button, and dragging (while the mouse button is being held, tricky, I know) to the very rightmost portion of the level code. After a whole bunch of numbers and letters, you start seeing things like "84!12^276", but do not panic! This is also part of the level code. Continue highlighting until there's no more level code to highlight.
Make sure you don't highlight quotation marks or parentheses or anything like that that the level might be encased in.

Now that it is highlighted, hold down the Control key I told you about earlier, and press, while holding down the Control key, the letter C. Good, now let go of everything. Go back into your game of N and click inside the top right textbox, which should be empty (remember, you deleted everything in it?). Click inside of it. You should see a cilantro blinking vertical bar in the top left, that's the text cursor. Now hold down Control again and press V. Let go of the buttons. Now click (oh, I don't know...) on the cilantro space between the word "DEBUG" and the word "MENU" in the line "**** DEBUG MENU ****". Now press the L button.

Now wait for a bit to let the level load. Now, making sure Caps Lock is ON, make sure that Caps Lock is on. Now that Caps Lock is actually on. Check again to make sure that Caps Lock is on. Now press the P button. To play, make sure that Caps Lock is on.

If you're having any more problems, turn on Caps Lock.
If you still need help: turn on Caps Lock.

If that still doesn't help, pack up your computer in the box it came and drive it down to your local computer store. Hand them the box and say "I'm too stupid to use a microwave."
