Blockland is a Multiplayer Lego Building game. There is no better way to describe it. Blockland itself isn't really all that good, it is still fun and all, but there is a very limited amount of bricks.

That is where Return to Blockland (Normally abbreviated as RTB). RTB has more bricks than you could handle, amazing setup, easy gameplay, very customizable (Server and setting-wise, but is also easy to modify), mover(Elevator) and other brick functions, brick save function (very handy), built in IRC chat, and best of all; Deathmatches using actual Lego weapons.

The game takes a little bit of time to get use to, but Blazeraid, Sgt. Poptart, and I have been playing the game long enough to teach you. The game is kind of like building Lego's without using your imagination. You have infinite bricks, and you get to be a Lego dude and walk all over your own and your other friends creations.

We would like to get more people to play the game so we can work on bigger and better creations, and also have someone with decent internet host (I normally host, but I am on dial up, which ends up causing some lag when more bricks are placed. Though the server really doesn't use much, I have hosted 6 people in a server, with very little lag, but it would be better to have someone with faster internet host.)

I don't think I can really explain any better about what is in this game, so I'll just put the links now.

Blockland
Return to Blockland

Installing and Playing Blockland: Just download the self-extracting Rar (8mb) into whatever directory and open Blockland.exe

Installing and Playing Return to Blockland: This is a little different than Installing and Playing Blockland. You have two choices, Download Blockland+RTB Installer (40mb) all in one. This is the best and easiest way. But you can also download the second file on the page, just containing RTB (32mb). You should only download this if you have already downloaded Blockland. After downloading one of those two, you must get the 1.4 to 1.45 update. That can be downloaded here. Then after installing it to your blockland directory and unzipping the update into your blockland directory, you should find a file called "Run RTB.bat". Just Double Click that too open Blockland.exe with the RTB mod.

Now your ready to play Blockland/RTB. Hope to see you ingame. My server is always Retroserver, and the password is waffle. Also, if you wish to talk to other Metanet Blockland players, you can always go on irc.mware.ca #N, or sometimes irc.mware.ca #rtb.

Note: Some people have been having trouble playing the game, If this happens to you, you most likely need to update your Graphics Card/Driver. Also, there is a chance that even after you update RTB you will get a message saying "Update Required!". Juest Close that message and continue doing what you were.
