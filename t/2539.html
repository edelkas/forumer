I found this website for Meqon Game Dynamix Demo. This has a really good 3D rendering engine and it has super physics. It comes with a few samples.

Basic keys are --> Enter, Space, All the arrow keys, ESC, the mouse (to drag/push crap), and keys 1-5.

Just click&hold stuff and drag 'em around with left click. To push, right click. On the maps where you are an auctual dude, right clicking on the lower third of the screen will make you do a ram. Use space to jump.

In my free time I messed around with some keys and found out some massive secrets.
Here:

F5- Normal game speed
F6- Pause game (press F6 again and again if you want to scroll frame by frame)
F7- Nothing that I can see.
F8- Slow motion

F9- make the game take up more processing speed and run alot crappier
F10- Data screening
F11- Motion sensor (red- moving, gray- idle)
F12- Motion sensor lines that are homing to the middle (again, red- moving, gray- idle)

Homing Objects Mouse Trick- Hold an object with holding down left click and then right click. The object will home to where ever the mouse was last. Grab objects on the side that you want to home to the mouse. To make it home again, just click on another object and it will fly over to it (and possibily slam into it depending on how far away it is.)

Have as much fun as I do. Post any more secrets you find (or if you can find out what the heck F7 does.)
