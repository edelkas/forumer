I really like N, and appreciate your efforts to improve it. A comment, however:

Between the beta and the release, the game became slower or more sluggish on my (already slow) computer. This is most noticable for levels that were already processor intensive, i.e. have a lot of enemies. Certain things (like missiles) seem to accent this. One level where there is a noticable difference, for instance, is 22-4, where there are a lot of enemies.

The difference does not seem to be borne out in framerate as displayed by the game; I just tried this level on the release and the beta and as far as I can see there isn't a difference, though it's hard to tell what the real average is. It seems like the game itself is slowing down (and then speeding back up), where before it wasn't, but was just dropping frames. To see the speed dilation effect, 51-4 is a good level to look at, though it doesn't have a correlate in the beta. When I'm in the air in that level, with a missile chasing me, the game becomes unplayable in a way I've never seen N be before on my computer. That level is better when I'm on the ground. If I find a better level to demonstrate the problem, I'll post it.

I'm afraid I can't describe what's going on any better than this, but maybe some other people with slower computers will chime in. I'm guessing whatever this change was had no effect on people with faster computers. For me though it seems to have made the game a lot less playable .

Another request for people with slow computers: could there be an option to run the demos at full speed, like they were previously? They look nicer slowed down (I'm guessing this is so all highscores look the same on all computers), but they also can be grindingly slow. On my computer, it's like 3 real seconds to one game second or slower.

thanks for all your work on N,

#23991 2 2004-06-29T02:13:09Z Guest
hey,
thanks for mentioning this -- we've only got a single pc to test on so it's hard for us to tell what our changes are doing on other systems.

the way the game updates itself at a constant rate can cause problems on slow computers -- specifically, the lag gets larger and larger until.. well, we don't know. a crash, probably.

anyway, we fixed this by saying "if the game is more than 200ms behind schedule, give up trying to catch up and just slow the game down a bit to compensate".

in hindsight, 200ms is a bit small -- it's now 2000ms (2 seconds); if there's this much time between frames, you probably have a huge problem

thanks,
