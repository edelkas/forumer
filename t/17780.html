I do not find the stacks impressive. Why not? Well, firstly, I put things on the desktop precisely so that I don't have to go through a menu or list to find them. Secondly, if you're using Windows, make a folder to store downloaded files (or whatever), then right-click on the taskbar, go to toolbars, and select "New Toolbar". Choose the folder you just made. Instant stack!

It's also slightly ironic that, after the constant accusations of Windows stealing ideas from the Mac OS, they've grabbed the workspaces which have long been a feature of Linux and Unix. It could also be done in XP using the PowerToys software which Microsoft makes freely available to Windows users.

Anyway, most of the features seem to be minor upgrades for things which already exist, and the few which are not don't seem like they would be terribly useful (or are already done by commonly used third-party software) for most people. Slightly better than the last one, but I'd hardly say it "changes everything". My analysis is the same as for Vista: it's probably not worth upgrading unless you're buying a new computer.
