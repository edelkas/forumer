When working on Ned++, I found out that implementing an objects editor is very difficult. My idea was to make a map editor without objects. The N Tile Manager is the result. I wrote it yesterday when I had nothing to do.

The N Tile manager can only be used for tile setting. When loading a map from a file or from the clipboard, the objects are kept in the background and will be appended to the map when saving it again.

I have implemented a new control concept. You can use it with the mouse or with Ned's key kombinations. (Even the Shift is included!)

A short feature list of the current version 0.8 (a preview release):
  • Loads from and saves to clipboard and file (only v1.3 map data).
  • Controls like in Ned or only with the mouse.
  • Copy, cut and paste.
  • Invert and mirror tile areas. (Rotation will be added in the next version, I had not got any time up to now.)
The N Tile Manager has been written in .NET 2.0, you will have to install the M$ .NET framework 2.0 (link on my website) on Windows or Mono (http://www.mono-project.com) or Portable.NET (http://dotgnu.info) on Mac and Linux in order to run it. The NTM has only been tested with the M$ framework up to now.

Note that the current version 0.8 hasn't been tested very much. I cannot absolutely guarantee the correctness of the included code.

Use the installer appended with this post to install the NTM on Windows systems. (I had to archive it in order to upload it here.)
