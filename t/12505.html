#229625 33 2006-09-17T04:02:36Z Atilla
That's because the user can't set each limb seperately at the moment, so there is no need to save the settings for each of them. The sol contains user settings and suchlike, not the actual code for N. It's like claiming no new items can be added because the code used for user levels doesn't yet have a number for them.

I assume that N's code would have something like

if (flavourflag = 5)
{
ninjacolour=FFFFFF;
i=0;
    while (i < NO_OF_CHARACTER_VECTORS)
    {
    vector[i]->colour=ninjacolour;
    i=i+1;
    }
}

(Written in C since I know little about actionscript)

Where vector[0], vector[1] and so on are each of lines that make up the ninja, and vector[]->colour is the colour of that line. To allow the user to alter each limb seperately, you would just have to seperate this single piece of psuedo-code into smaller parts for each limb, and have a colour flag for each limb.
