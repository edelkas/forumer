Are you sure you've pressed the right keys to get things started? Could you send upload the data in a text file so I can see if it's corrupted?

After you finish editing your map, and you want to test it out, press 'Home' and then '~' to get back to the main menu. Then press 'P' to start playing the level. If you die and want to start again, get back to the Ned menu by pressing '~' again, and then 'R' to reset all your objects. That should help you when you want to test a level.
