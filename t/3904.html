#80590 2 2005-07-02T18:49:49Z Maniac
Are you trying to play demos in user mode or in debug mode?

If in user mode, make sure the demo is in the following format:

$Map name#Map author#Map type#Map data#Demo Data#

If you just have the raw demo data and put it into the user mode replay box, it won't work.

If you're in debug mode, you just put the map data into the map data box, load the map, put the demo data into the demo data box, and load it. Then press "play".
