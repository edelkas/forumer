#302862 7 2007-03-06T02:24:51Z ZeroTruths
Check to see that not so many programs are running in the background.
If they are, then close the ones you don't think you're using and try playing N again.

Also, if your computer is naturally slow,as a desperate measure, you can increase N's priority over other programs that are running. Note that this might cause instability in your system such as lag.
*Hit Ctrl-Alt-Del
*Go To The Processes Tab
*Search For and Right-Click on n_1.4.exe
*Goto and Click on Set Priority
*Select Above Normal
*Read and Click the Warning Prompt
Now N should run faster, while the rest of your programs now run at least a bit slower.

I know what this works on Windows XP, but as i don't have access to a Vista computer, I have no idea if this is even possible for Vista...
Hope I helped...
