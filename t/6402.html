#177002 7 2006-05-17T11:13:08Z SlicesOfBread
When you make your level and you already got the data copied, you can save it in userlevels file that stores user levels. To put it in, write $(Level Name)#(User Name)#(Game Type)#(Level Code)
Then if you want to submit it to numa, make an account, and go to 'Submit a map'.
Put only the data in the data box, write the game name on top, chose what type of level it is, and put in a comment or something in teh big box.Press submit and thats all.
