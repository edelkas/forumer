Videogame Re-Creations

Welcome to my very first contest! And first of all thanks for checking this out.

Spoiler: BasicsOkay for this contest is basically self explanitory. You take a videogame any videogame (most likely a platformer) and recreate it however you want to. Try to creatively use N's objects to match enemies and other elements of thge game you choose. For the best results you might want to use N-reality for Image-maps and possibly Drone Mods. If you need help with image maps check out Nexx's tutorial for help - http://metanet.2.forumer.com/index.php?showtopic=21904
Spoiler: Signing UpSign up as soon as possible and tell me what game you would like to do because each person has to do a different game. You can comment or PM me and just say you want to enter and what game you want to do. I will try to keep the list updated as much as I can. Make sure you check the list and latest comments before you tell me what you want to do. If you would like to change your game please tell me so I can change the list and someone else has a chance to sign up for your name.
Spoiler: Due DateAll maps will need to be done by July 15th. You shouldn't need more time then that. I held this contest during the summer so you guys will hopefully have the time to get this done. I would like all of the levels submitted to NUMA but you can send it to me however you want. If they are not in by the date then you can't be part of the competition.
Spoiler: Judges/JudgingI want to have 2 judges and myself, so if you are interested tell me. I want judges that are familiar with Image Maps and are active players and mapmakers of N. You dont need those requirements just if would be nice ^^
Judging
-How playable is it? Is the image terribly distracting, how difficult is it? 30%
-Is it fun? Overall did you enjoy playing the map and how addicted to it are you? 30%
-How much does the map match the game (enemy use, image etc.)? 40%
Spoiler: Prizes1st Place get 3 dedications and a really cool banner
2nd Place gets 2 dedications and a cool banner
3rd Place gets some llama chops and a cool banner
4th Place gets 5 minutes added to their life span
