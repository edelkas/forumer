Due to the number of maps that have gotten abnormally high ratings as of late, I've decided to start this thread. Here are the rules:

1. Don't rate a map down just because it's in this thread. Rate each map only how you think it should be rated.

2. Post only maps that you deem to be grossly overrated, to the point where either it looks as though there has been foul play involved, or a large number of clueless members have rated it in a way that runs totally counter to common sense.

3. As a rule of thumb, posters should only post maps that they believe should be rated at least 1.5 ninjas lower than they are.

4. This works the same way as the Map-Rating Thread; you must rate a map for every map you post and state which map you have rated in your post. That way we can ensure that all these maps get the ratings they deserve.

5. Unlike the Underrated Map Thread, however, you may post your own maps.
