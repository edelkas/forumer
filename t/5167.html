This is just a very simple suggestion, and I think it doesn't really need in-depth explanation: I think it would be very nice to see in NUMA, under the amount of votes for a level, the amount of comments a level has received.

Explanation: I like to read what people have commented on my levels but every time I want to, I have to go through all my levels to see if there were new comments for any of them. It would be really good to be able to see in the list of levels if there are new comments or not, by being able to see how many comments there are.

Would this be hard to implement? Would it be of any use for anyone else than me?
