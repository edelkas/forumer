The ninjas would start in exactly the same spot; they would be like ghosts to eachother. They could be different colors so that the player could tell which was his.

The point would be the same as it is now: to finish with the most time left. Both players would continue playing until they both finish the level. There would be alot of strategy involved in this, because both of the players could unlock the same doors and open same the exit, and get the same gold; but they would have to be thinking the whole time whether it would help them more or the other player. So speed would be important, because you would want to get more gold than the other player (and get it first), but it would also be important to try to plan one step ahead, like tricking the other guy into getting the exit switch when you have a better chance at getting there first.

I guess it would get old if one person kept dying, which caused both people to have to keep starting over. I can't really think of a decent solution for this... but there probably is one.

There is a very small opportunity for ninjas to touch the same bounce block at the same frame because otherwise, the current physics system is able to handle it.
