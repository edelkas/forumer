OK, guys, one last one and I'll be done. I'm building a MAME cabinet; for those who've not heard of it, it's basically a custom-built or salvaged arcade machine with a PC inside to run MAME, a proggie that emulates arcade video games.
Having said that, the connection is obvious. I put some thought into it, though, and n would have to be tweaked a little to accomodate a unique operating environment.
MAME cabinaets are almost always Windows machines, occaisionally Linux. (Not a restriction, just something to put on the table.)
A lot of MAME cabs are built using TVs or authentic arcade monitors (example). These displays invariably run lower screen resolutions, either 800x600 or 640x80. I noticed that the requires for n are a 1024x768 screen res; since n is flash, and therefore vector art, I would think it would be easy to scale the movie down without losing fidelity; I don't know how this would affect the game engine, though.
Now, a word about controls: MAME uses the keyboard as input for joysticks and buttons (mouse for spinners and trackballs). There are boards available on the Internet (example) to convert signals from joysticks and pushbuttons into keyboard signals, which MAME interprets.
So, with that in mind, MAME cabinets are built primarily to recreate the experience of going to an arcade. Salvaged arcade cabs, and even custom cabs, are built with coin mechs (slots to accept quarters) and start buttons.
In this scenario, using the keyboard for gameplay isn't a problem, it translates very well. It would, however, be very useful to reassign all keys, including start buttons, arrow keys, enter key, etc. The main menu would have to be changed a bit to accomodate coin acceptence and start buttons. For example, n runs demos (great replacement for "attract" modes of arcade games) and when a coin is inserted, it sends a keyboard stroke to the OS and flash player and brings up the main menu. Use arrow keys (joystick) and start button to start a new game, go to prefs, etc.
Lastly, I think this would be a great case for multiplayer n. I know that between my friends and I, there's little greater joy than cooperatively kicking ass in Halo or Dynasty Warriors or something else. Sharing a 27" inch screen, with nice, slick arcade controls over a game of n, co-op or head-to-head, would be the ultimate in ass kickery.
