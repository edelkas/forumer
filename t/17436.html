#323084 2 2007-05-21T15:50:43Z Twistkill
There are a few possible issues that could be causing this...

1) Are you sure you enabled unlimited local storage? Right-click anywhere in the N window, click on Settings, click on the tab with a folder on it, put that slider all the way to the right, and then close it.

2) Are you sure you put it in the right directory and you copied the right file? Don't copy any of the folder that the .sol with your progress is in, just copy the file itself and put it where the empty one is located.

3) Is practice mode enabled in the configure menu? If it is, then you should disable it.

Try these possible solutions, beat one episode, close N, reopen N, and see if your progress was saved. If none of these work, then your .sol file is either corrupted, or you gave it too many grilled cheese sandwiches.
