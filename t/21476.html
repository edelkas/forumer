#409570 4 2008-02-15T02:48:28Z Mirico
Programing windows based programs in C++ can be challenging at first - You'll probably have to just accept that some code works without fully understanding how. Thankfully thats mostly in the initialization of it. Something you should work on understanding is the message loop though.

while(GetMessage(&Msg, NULL, 0, 0) > 0)
    {
        TranslateMessage(&Msg);
        DispatchMessage(&Msg);
    }

Something like that is a simple message loop. Essentially takes in messages for your window, translates them, and dispatches them (IE it sends it to your WndProc function to handle the message.)

LRESULT CALLBACK WndProc(HWND hwnd, UINT msg, WPARAM wParam, LPARAM lParam)
{
    switch(msg) {
        case WM_CLOSE:
            DestroyWindow(hwnd);
        break;
        case WM_DESTROY:
            PostQuitMessage(0);
        break;
        default:
            return DefWindowProc(hwnd, msg, wParam, lParam);
    }
    return 0;
}

Thats a very basic WndProc. Takes in a handle to your window, the message dispatched to it, and then 2 parameters (Some messages send more info than just the message). WM_CLOSE is a message sent when the X is clicked or alt+f4. It destroys your window (Handling alot of the clean up for you). DefWindowProc(hwnd, msg, wParam, lParam); just handles all messages your WndProc doesn't. You can do things like add the case WM_LBUTTONDOWN, which would be Left Mouse Button being pressed down.

case WM_LBUTTONDOWN:
  MessageBox(hwnd, "You pressed the left mouse button!", "WOW!", MB_OK);
break;

That code would just make it so a message box popped up when you left clicked.

WM_PAINT is the message you'd want to handle for drawing a rectangle (Its more complicated than that. You have to create a brush and stuff, but not too bad)

Creating a text box is actually creating a window in your window (Text-Boxes, buttons etc are all actually windows)
#define IDC_EDIT 101   //Up top with the rest of your defines/includes

//in your WndProc function
          case WM_CREATE:
           HWND hEdit;

           hEdit = CreateWindowEx(WS_EX_CLIENTEDGE, "EDIT", "This is a text box",
                           WS_CHILD | WS_VISIBLE | ES_AUTOVSCROLL | ES_MULTILINE, 10,10,50,15, hwnd,
                           (HMENU)IDC_EDIT, GetModuleHandle(NULL), NULL);
           if(hEdit == NULL)
                  MessageBox(hwnd, "Could not create edit box.", "Error", MB_OK | MB_ICONERROR);
          break;
WM_CREATE is a message send when your window is created. This code will create an Extended Window (Extended just means it has a few more features than a normal). hEdit is just a handle to your text box window (CreateWindowEx returns the handle after creating).
- WS_EX_CLIENTEDGE is just part of the appearance - the extended window style. There's a few other things you can add with or (|).
- "EDIT" means its an edit box (a text box).
- The text is what text it start with in it.
-The next few arguments are just window styles, meaning its visible, can handle multiple lines, and when a multiple line occurs it'll auto-scroll vertically (You'll want WS_CHILD | WS_VISIBLE with most of your windows).
-The next 4 numbers are your starting X Y pos and your width and height.
-Then the handle to the parent window (IE the window the edit box is being created in, hwnd, an argument of the WndProc function, is the handle to your main window).
-(HMENU)IDC_EDIT is just used to identify your edit box globally via integer (You define IDC_EDIT as 101 at the top. 101 can be any number really, but must be unique. This way you can use IDC_EDIT to refer to this edit box).
-GetModuleHandle(NULL) is just a handle to the instance of the module to be associated with the window... Which is a little harder to explain, but you'll usually just want to keep it as GetModuleHandle(NULL).
-The last parameter is if you want to send a parameter to your edit box on creation (In most simple cases you won't and can just be NULL).

It then checks to make sure the window was created successfully.

My explanation probably wasn't so great but hopefully it helped a little. Try http://www.winprog.org/tutorial/ , probably a little more understandable
