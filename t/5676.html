Hmm, you mean like setting the browser so it accepts cookies?
In that case, for Firefox (can't imagine anyone would use something else):

Find the preferences window (Im using the swedish version, but I think that it should be like Tools->preferences)
In there theres a tab called secrecy (still the swedish so I dont know ) and there you find something about cookies. If you dont want to accept all cookies simply click the exceptions button and type in "http://metanet.2.forumer.com", there you have the options to allow for the session, block it, or allow it completely.

Its about the same with internet explorer:
Tools->preferences (maybe internet-preferences/options) -> secrecy -> places (this might be completely wrong, but for me it is the button to the left)
Type in http://metanet.2.forumer.com and press allow.

Hope that will fix it
