Don't worry, that's a hard one for a lot of people. You're not alone. Here's what you need to do:

Draw out the floorguard. Run in, then jump over the floorguard and flip the switch. Do this as soon as possible, then run as fast as you can and jump as soon as you can. You need the head start in order to outrun them. Jump as soon as you can, leave the floor!

This is a very hard level, don't get discouraged!
