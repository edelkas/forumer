#350471 2 2007-08-03T02:33:33Z Twistkill
The code for this is

[spoiler*=the text to be spoilerified]What it contains[/*spoiler]

And for images:

[spoiler*=[img]image link here[/img]]stuff to be shown[/*spoiler]

(Take out the stars)

You can basically put large or otherwise distracting things in your signature between the spoiler tags so it will be hidden, but it will still have to load. Also, your entire signature, even with all spoilers expanded, which includes images, text/quotes, etc. cannot be wider than 600 pixels and longer than 335 pixels.

#350971 8 2007-08-03T22:48:18Z bonzai
A couple of extra tips:
1) Spoilers within spoilers are already open, so they're rendered almost useless.
2) Quotes inside spoilers don't work, unless you have it coded something like this(minus the periods):
[.spoiler=whatever][.spoiler=][quote=person's name]quoted text[/quote][./spoiler][./spoiler]
