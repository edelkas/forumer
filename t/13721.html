#253168 6 2006-11-11T21:25:18Z Hendor
Getting out of the far left rooms is kinda tricky.
Don't think this has been mentioned, but the idea is to jump half a second early so that you pass the floorguard when it is still moving left when you pass over it. That way you get a bit of extra time to run right. Then, jump, as soon as you leave the tunnel, so it does not catch up. Hope that helps.
