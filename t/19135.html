#359497 4 2007-08-26T05:49:14Z victimBF2
oh... ive done something like this before. ok here are the steps. Create a couple of input text fields. One for Name, Author, Yada Yada Yada. Under each of there "Var:" call it something like Titled or Author. After you did all that, create a button. In its action use this line

on(press){
     System.setClipboard("$"+Title+"#"+Author+"#"+Type+#Map Data+"#");
}

that should copy all of it to your clip board. Where Title is the "Var:" of the input text for the title. And so on and so forth. Since you extract it as a .txt file, after clicking the button, open up a notepad or whatever and press Paste.

If its tough to understand, i can set up a example.
