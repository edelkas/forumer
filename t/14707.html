#13058 1 2006-12-22T00:46:44Z LittleViking
The most common cause of accidental NaNs is pressing L before clicking outside of the level data box. If the game generated a ! at the very end of the level data, the L at the end of the data would get discarded and there wouldn't be any NaN like there would be now. The same goes for the somewhat rare case of leaving a # at the end of level data and trying to load it. Normally it would produce a NaN, but with an exclamation point before it, N just throws it away.

Edit: See the example if you don't understand. Paste the data in N and press L without clicking out of the data box.
