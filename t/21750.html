Over in the suggestions thread, Nexx mentioned a desire for a program which could bulk-move all objects in a map by a specified offset. Nine months (well... a few days anyway) later, the N Object Mover was born. It exists in two forms: a command-line version, which should compile and run on pretty much anything that can run N, and a Windows GUI version, which has a couple extra features. You'll find both executables, as well as all the source, in the attached zip file.
