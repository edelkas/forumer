#380455 2 2007-11-18T05:08:19Z astro
I would use includes. What you do is put all of the header stuff before the text you want in one file (say, header.php), all of the stuff afterwards in another file (or more than one other file), and then create a new php file that looks something like
include "header.php";
echo "this is the other text stuff you want."
include "theotherstuff.php";
This also has the advantage that, by having all the other stuff in one file, you can make a change and then it will instantly be reflected in all the other files (if this is a good thing for what you're trying to do).
