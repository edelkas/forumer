#22293 3 2004-04-15T16:28:38Z Raigan (guest)
hey,
since we've finally come up with a rough schedule, here's what we have planned:

v1.2: "soon" (i.e in 1 or 2 weeks)
N:
-50 more levels
-configurable keys
-various minor tweaks/bugfixes
-oven-less continue system
Ned:
-no more evil textboxes (data will be sent to and from the clipboard directly)
-data "validation" (i.e invalid characters -- like newlines -- will be stripped.. and errors will be generated if you try to load corrupt data)

v1.3: hopefully 1 or 2 weeks after v1.2 (it really depends on how many problems we run into when implementing this..)
-online highscores (the top 10 highest "lifespan remaining" times for each episode)

v1.4: ? (impossible to say when; again, it's more a matter of how long it will take to get things working.. not a _long_ time though)
N:
-play user-made episodes (from files)
-play user-made replays (from files)
-view replays of online highscores
Ned:
-file-based saving/loading of levels and demos
-"episode making tool" for building easy-to-share custom episodes

if a cross-platform standalone flash projector is released (and isn't too expensive), all of the v1.4 features will take about a week to add. without a cross-platform standalone projector.. we have to code it all ourselves in c, which will take a lot longer.


we're going to continue to release new sets of levels every so often.
we're also working on other cilantro things like compressing the demo data even more, etc.. basically we'll try to implement any of the suggestions we read that seem like a good idea. unfortunately, certain things like scrolling, guns, etc.. well, we like all of the ideas, but many will have to wait for our next game ;)

about the tutorials/source: we're hoping to start releasing them with v1.2, and continue to release them in installments every couple of weeks.

raigan
p.s - (to rich) if you look on our site, on the main page there's a "press" link at the botton; we've done a couple interviews (aside fro mthe one mare mentioned) that might be of interest
p.p.s - i'm guessing that by "all three", rich meant:
-new version
-source code
-tutorials
but.. the last two are really a package; the source code by itself is, um.. lets say "very ugly". so part of the process of writing the tutorials is cleaning up the source so that people can use it easily.
