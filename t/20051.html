How?
1. Okay, in this competition, you need to find a map from any map on Numa. At all. And find a demo I made on it. If you got that, read the next paragraph.
2. Demo length needs to be between 100 and 9,582 frames. Any more, or any less, and you need to ask my approval. Anything above 11,111, I will say no to almost surely, so try to find a semi short one.
3. Make a map off of it in which my demo works as an agd. You need to have at least ten peices of gold. You CAN make a dda, but I will probably not like it, so try to stick with playable maps.
4. Link the map with the original demo data on it and submit it to Numa.
5. Make one of the tags "iwuvturtlez"
6. Post a link to the new map on this topic.
7. Wait to be judged.

Judging:
The scoring will be as follows:

How my demo looks in the map: ?/25
How fun it is for me to play: ?/50
Tileset/Overall look: ?/15
Originalty: ?/8
Map name: ?/2
Total: ?/100

Yes, map name. I will not change that.
Also, the originality refers to how different it is to the other maps.
