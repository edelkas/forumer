Hey N level makers.

I got a few questions for you. Have you came up with a file format for storing N levels?

I'm making an N level editor and I'd like to know if such thing exists to make it compatible with the current format. I already implemented one, but it would be better to be compatible with what you have if such thing exists.

The editor I'm working on has many features, some of wihich are:

Editor
  • Drawing tiles by dragging the mouse
  • Copying areas and pasting them
  • Using different pivot points for pasting so you can leave some parts of what is being pasted out
  • Fast copying of all text data with a button, to test in N
  • Auto copying of all data with just changing to another window
  • Showing the border of the level or not, to save screen space
  • Grid and half snap grid, with custom colors
  • Saving comments, author, difficulty, etc in the level file
  • 500 undo/redo levels
  • Opening levels from the shell by double clicking
  • Plus many more things...
