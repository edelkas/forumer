First, I want to get this out of the way

In the N-editor of N 1.5, there should be a manual option to make sure a drone doesnt move. Perhaps the X button? Idk, but something to let you NaN drones quickly and easily.

Now Ive got that out of the way, basically amke any (serious) suggestions about which kinds of drones to feature in the next game. To help, Ill post the ones we can already get.

Drones that are already available

>Zap Drones
>Seeker Drones
>Laser Drones
>Chainguns Drones

Drones that are available from Modding

>Alarm Drone
>Rocky Drone
>Tile Drone
>Force Field Drone
>Text Drone
>Ghost Drone

Personally, I think that these should become available in the N editor somehow, along side the others. Perhaps the gridlines could be moved to the number keys and the enemies moved to the letter keys? Some should remain mods only imo, as theyre too specific and would just clog up the editor without a use most of the time. Imo, the ones to be exempt from the N editor should be the Tile Drone, Text Drone and Ghost Drone, as these really are very specific and can seldom be used with other enemies.

Here are some ideas for new enemies.

>Gauss Drone: Functions exactly the same as a regular Gauss turret (in that it has a crosshair and is slightly inaccurate) This should be added as, with the changes to the N editor, it would be easy to NaN and make it a regular gauss, whilst it can also be set to move around if necessary.
>Rocket Drone: Functions exactly the same as a regular Rocket Turret (in that it fires abhoming projectile) for the same reasons as mentioned, However, it can also be set to either freeze or keep moving whilst a projectile is present.
>Flamethrower Drone: Deadly to the touch like a Zap Drone, but moves at the rate of a Laser Drone. However, it attacks with a flamethrower, which works like a Chaingun Drone without the pre-fire-delay. However, the projectile moves much more slowly, but covers a widespread area (ie, 10 degrees to either side of the actual target. Sends out a burst of flames, which only starts to end once it hits a tile. The flames do not home in or change targets until the previous flame has ended.
>Champion Drone: Moves at a Zap Drone's speed whilst rapidly firing small volleys of chaingun fire whilst moving, when the enemy is in sight. Otherwise a regular Zap Drone. Can be configured to seek.

So this would make the N editor list look like this.

>Gauss Drone
>Rocket Drone
>Zap Drone
>Champion Drone
>Laser Drone
>Chaingun Drone
>Alarm Drone
>Rocky Drone
>Force Field Drone
>Flamethrower Drone

Any more suggestions?
