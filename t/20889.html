#439240 9 2008-05-26T02:33:14Z Atilla
If you've completed levels with practice mode on, you'll need to turn it off and finish them all again, in sequence, starting with the first episode in the column you didn't cheat on (so, for example, if you've cheated all of column 0, you'll need to complete 00, then 01, and so on).
