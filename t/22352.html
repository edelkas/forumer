***Notice: This map can be completed in both versions of N (the regular version and N Reality v6c2), however the demos of each version are NOT exchangable. You will need to make two seperate demos for each version.***

This is somewhat of a new/concept map that I made, which incorporates the use of player_03's tiny ninja mod.

The thing that makes this level different from the other levels that that I've seen using this mod, is that this level IS possible to complete without N Reality v6c2 (meaning you can beat it as the regular sized ninja), unlike the other levels in which you do need to use N Reality v6c2.

The level is not too hard (since it is basically just a concept). Each way of playing the level (as a big or small ninja) has its advantages and its disadvantages:
Spoiler: Advantages of being big:
  • Faster completion for speedrun mode
  • Easier to get door switches
Spoiler: disadvantages of being big:
  • Less gold (It's still possible to get some of it though)
  • Harder to dodge floorguard
  • Less challenge
Spoiler: Advantages of being small:
  • Better completion for highscore/regular mode
  • More gold
  • More challenge
  • Easier to dodge floorguard
Spoiler: Disadvantages of being small:
  • Harder to get door switches
  • Slower completion for speedrun mode
  • Easier to die from chimmneying and high falls
This level was designed so that the path for the normal sized ninja can't be taken by the small ninja, and vice-versa. Try it both ways and you should see the differences.
