Flash is amazing, I love to work with that program, even when I'm not using it for animation. The drawing function of flash is just superb, because you can alter the settings to curve perfectly when you draw, even if you have shaky hands like mine. Also when you draw say a curvy line in Flash, the object down to the last curve is a vector, not just a path overlaid with a brush set (like Illustrator uses)

Also, you can save TONS of different formats in Flash (I use CS3, not MX) you just have to goto File > Export > Export Image (or Export Movie)

Image side you can save the following formats:
.swf
.emf
.wmf
.eps (perfect vector format)
.ai (yahoo for Illustrator)
.dxf
.bmp
.jpeg
.gif (non-animated, goto Export Movie)
.png (lower quality transparency)
