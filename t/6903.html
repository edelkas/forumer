Can some one please tell me how to record demos and save created levels?
#133671 2 2006-01-19T11:58:34Z Maniac
If you're done making a level in Ned, simply copy the level data and paste it into a .txt file. Then save the .txt file. You may then attach it to the forums or put the level data on NUMA.

If you'd like to record a demo, load the level data for the level you want to record a demo for. Then push 1 to start recording a demo, and push P to play the level.
