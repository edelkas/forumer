Quake 3? Puh-lease! More like Doom 3! Quake 3 never had cool lighting effects and pixel shaders. In any case, kkrieger is an awesome little game. It was made a few years ago and was big in the so-called demo scene. Demo programs go back to the days of BASIC and DOS, and basically exist to show off how much a programmer can pull off with a small amount of resources. Back in those days, people would code amazing 3-D animations (keep in mind, they were doing this even before Windows 3.1). These days, the system resources are so advanced, it's more popular to do a program with a small amount of code. In this case, it's only 96 KB compiled. Amazingly small. This entire game is smaller than many of the sig images here.
