I read this definition in one of the N tutorials:

Quote
the dot product of two vectors a and b is given by:

dp = a.x*b.x + a.y*b.y;

Note that the result is a scalar value (a single number).
You can think of it as describing the relative orientation of a and b; a negative dot product means that a and b point away from each other; a positive dot product means they point in the same direction.

the dot product as I understand it:

If you have two vectors (not position vectors), they can be called a and b but they stand for the movement you have to do. eg: a = 5i +6j, and b = 2i + 3j. a + b = (5 + 2)i + (6 + 3)j = 7i + 9j, so from the origin you go 7 across and 9 up.

the dot product I use is used to work out the angle between two vectors. Using a and b again,

a.b = |a|*|b|*cos(x) where x is the angle between the two vectors.

a.b = (5*2) + (6*3) (multiply the i values and the j values and add them together)

|a| = square root of (5^2 + 6^2) (think pythagorus: |a| means the size of a

using these, find out what cosx is, find out what x is.

from your quote,

Quote
a negative dot product means that a and b point away from each other; a positive dot product means they point in the same direction.

this makes sense: if x is > 180 degrees (they point away from each other) cosx will be negative, the same with x < 180 = cosx is positive.
