#325539 3 2007-05-30T00:20:36Z Exüberance
Make sure you didn't have practice mode on for any levels. If you did, you must go back and do them again with practice mode OFF.

Also, I have heard that there is a glitch that if you complete a level in over 90 seconds, the highscores glitch (because it assumes you start with 90 seconds, when you can start with less on any level except the first in an episode because the time is carried over through levels) and you'll have to redo the level.

You can tell if you used practice mode or took over 90 seconds in a level by going into the highscores section and making sure that your time is listed for all episodes in the column. If the episode time is "---" for any episode, redo it.

Again, make sure practice mode is off.
