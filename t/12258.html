#221565 8 2006-08-30T09:16:52Z sweep
This is an interesting idea, but I fear it'd be _very_ hard to do.

DDAs are about precision. Because there is no user input as such, this precision is possible. It's not so much a problem that human error exists, it's human error over time that's the worry. Say, with one mistake you're 5 frames off. Then you're 1 on the next, spot on the next, then 2, 3, 0, 1, 6, 2. By the end of that you've made 20 frames of error from just a few jumps. It builds up, and in a DDA precision is so important.

I think it's possible, but I also think it'd be very hard to make one with loads of close-calls in that was actually reasonably possible to complete.
