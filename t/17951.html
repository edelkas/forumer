#333900 2 2007-06-21T08:20:10Z apg
Quote: Weisslenny0, June 21, 2007 10:47 am
The first is how you can put custom pictures up the top, instead of the default message saying what skin the forum is in.
In the Admin CP, go to Skins & Templates -> HTML Templates -> Manage HTML.

Click on 'Global HTML Elements'. Another list will show up on top of the existing one. In that list, the first section is 'Board Header'. Click on 'Edit Single'. You will see some HTML coding. Find the following piece of code:

HTML
<img src='{ibf.vars.img_url}/logo4.gif' alt='Powered by Invision Power Board' border="0" />
Now, insert the image's URL between the first apostrophes, right after the "img src=". Finally, click on 'Update Templates', and you're done.

Quote: Weisslenny0, June 21, 2007 10:47 am
The second is how you can create custom pictures for the rating image, the 'new topic' image, and those images. I know how to see which ones there are currently, but I'm not too sure how to change it to a custom one.
See Skins & Templates > Images Only.

Each icon is accompanied with HTML code. For example, the standard rating image has this:

HTML
<img src='style_images/<#IMG_DIR#>/pip.gif' border='0' alt='*' />
Just like with the banner, insert the image's URL between the first apostrophes. Scroll down, and press Save Changes.

Quote: Weisslenny0, June 21, 2007 10:47 am
Also, how do you enable "fast reply"?
Forum Control > Manage Forums > Select a forum > Settings. Scroll down, and set 'Turn on the Quick Reply Box?' to 'Yes'.

Hope this helps.

#334840 11 2007-06-23T07:55:04Z apg
Go to Admin CP > System Settings > User Profiles, and insert a 1 to the first textbox. The members will now have to have over 1 posts to change their custom titles.

Note that setting the value to 0 disables the feature, instead of allowing everyone to change their titles.
