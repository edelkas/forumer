#239489 5 2006-10-11T03:33:59Z Tsukatu
This has actually happened to me sometimes when I was running Firefox under winblows.
Basically, the process doesn't close for some reason, and the new instance of firefox sees that there's already one running and tries to pass a New Window operation through the existing process instead of creating a new process on top of the old one (this is good to avoid bogging down your computer).
Press Ctrl+Alt+Del and click on the processes tab. There should be one called "firefox.exe" when you're running Firefox. If the situation you described above happens again, go to the Task Manager and end the "firefox.exe" process that is likely still running. Then try running Firefox again and it should be dandy.
