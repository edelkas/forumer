#339907 9 2007-07-07T14:00:18Z 7!
Stop whining about UAC. If you have administrator rights, it's easy to turn off.

Go to control panel. Switch to classic view. Go to User Accounts. Click Turn User Account Control On or Off. Uncheck the box "Use UAC to help protect your computer." Hit ok.

Go back to control panel. Click Security Center. On the left pane, click Change the Way Security Center Alerts Me. Click Don't notify me and don't display the icon. It says "Not recommended," but I recommend it because it disables those persistent popups about "UAC is turned off. No anti-virus software found," etc.

Basically, a program can be so simplified that an advanced user (which is really an average user IMO) is unable to perform advanced operations. They can only use the computer on a superficial level.

I think this is caused by marketing to lowest common denominator customers. They are marketing towards people who have never used a computer before - they make it so "friendly" that a complete idiot could appear to use the computer correctly.
