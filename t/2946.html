Let a group of statements be a set of statements which are not referenced by any statements under consideration which are outside that set.

Let a stable group of statements be a group for which there is exactly one possible set of truth-values; let an unstable group of statements be one for which there is more than one possible set of truth-values; let a paradoxical group of statements be a group for which there is no possible set of truth-values.

Let a stable statement be one in a stable group or unstable group for which all possibilities leave that statement true, or for which all possibilities leave that statement false; let an unstable statement be one in an unstable group for which some possibilities leave it true, and some leave it false; let a paradoxical statement be one in a paradoxical group.

Statement 1: This group is stable.
Statement 2: This group is unstable.
Statement 3: This group is paradoxical.

What are their truth-values, if any? (yes, there IS a correct answer...)

#62649 16 2005-04-28T23:26:20Z syntax
I like your take on the 'a'.
But you're still only saying it can't be a lie, as otherwise it would be true.
We need another reason...

What if...

Hmm....

Actually, we're assuming that:

"This statement is a lie"

is equivalent to

"The following statement is a lie: this is"

So if we can prove that "this" isn't, then we've proved there's a solution (false).
Quoting good old Descartes, we get the proverbial (and misquoted) "I think therefore I am".

In fact he means "I think therefore the *I* is".
That is, something can only be if it thinks.

Now we just need to disprove that "this" doesn't think.
So, as long as we take "this" (the "statement") as being inanimate, we proven that the answer is indeed false as you said.

However, if you take "statement" as having a mind of its own... the answer is a paradox (as others said).
