#410622 28 2008-02-19T05:09:27Z Templex
This problem is probably due to the fact that N is wrapped in a projector that uses Flash 7, which is PowerPC code. For it to run on Intel Macs, Rosetta has to be used, and more likely than not, some bug in the code translation is causing those crashes. A possible fix would be to obtain N wrapped in a Flash 9 projector, but can't tell you where to get that
