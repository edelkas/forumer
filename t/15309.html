#287111 2 2007-01-18T12:02:00Z Maniac
I can't really answer the first few questions, but I can help with the algorithm.

Basically, O(n) means that this algorithm is a recursive one, and it's on the order of n squared. This means that it calls itself more and more times each time it recurses, eventually approaching some multiple of n squared for whatever input you supply the algorithm.

This means that it's not an incredibly efficient algorithm, but it's a lot better than if it were in logarithmic or polynomial time.

Yes, that's java, but you'd need to add that into a class file and add the main(String args[]) method to the class in order to put it in a program.

Beyond that, it's fuzzy. I haven't studied how Java interacts with other languages very much.

If you wanted variable writing, you'd need to do something like this instead - not very difficult for a programmer of your calibre I assume?

import java.io.BufferedWriter;

public static void writeToFile(String outfile, String content)
{
   try {
      BufferedWriter out = new BufferedWriter(new FileWriter(outfile));
      out.write(content);
      out.close();
      }
   catch (IOException e) {
         //do something with the GUI to tell the user that something bad happened
         System.exit(0);
   }
}
