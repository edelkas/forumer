#467175 8 2008-09-04T23:51:07Z heatwave
Oh, and just for some background information, the versions of n online are all illegal versions. N was never meant to be played through a web browser. The original version of n (v1.1) was first available as a download. the online versions are usually (always?) version 1.3, which is an outdated version.

The legal version that you downloaded from Metanet Software's website is version 1.4, which includes not 30 episodes, but 100. Hope Templex's link works for you. Also, n v1.4 has a built in level editor so you can create your own levels. If you do get n running correctly, press the ~ key while you're viewing the main menu to access the n editor, also known as the neditor.

well... yea. Here's some more background information on the application you just downloaded. It's not really n v1.4. It's a mod of n called NReality, v6c2, and it's not made by the same people who made n v1.4, so it would be out of place on their website. The game itself is esentially the same, (same physics, enemies, etc.) but there are a whole bunch of things that have been added on to it.

For instance, when you click on the [Play Game] button, you see 20 columns of episodes. in n v1.4, there are only 10 columns of episodes. Another addition is the ability to submit highscores for usermade levels found on NUMANUMA. I don't know how familiar you are with NUMA, but you s hould check it out if you haven't heard of it.

So NReality is n v1.4 with a whole lot of extra cool stuff added on. Way more stuff than I could explain here.
