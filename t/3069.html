Sitting around, unpaused, in N 1.4 on level 0-0, I can achieve about 35 ms/frame. Average is probably more like 50-80, but it really depends on how many moving objects there are; levels full of drones are nearly unplayable for me. (N 1.4 is better than 1.3.) The problem appears to occur regardless of frame rate, though.

Occasionally when trying to pause I do see the 'paused' message flicker onscreen and disappear.

Boss mode used to always work for me, when it was triggered by Command.

After changing a few key combinations, I have determined that using the Command key for either normal pause or boss mode works how it should, but either command has the problems I described when on another key such as p or tab. It seems likely that the combination of MacOSX and Flash handles that key differently in some way. Upon testing, p works fine as the jump key. Upon further testing, using Command as my jump key (rather than these tested keys: p, shift, and up-arrow) reduces lag!!! Besides general observation, I have specific evidence: Jumping off a wall in level 0-0 and immediately after that using a sideways arrow key to make the walljump stronger, the ms/f often soared above 100 doing that when using Shift, but never when using Command as my jump key. I suspect that the basic input mechanisms for that key are different somehow, in a way that makes pressing two keys at a time less of a problem, and yet it's not obvious where or how. And neither is it obvious whether this information will help solve the initial problem with Pause.
