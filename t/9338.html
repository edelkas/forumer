#170273 2 2006-05-01T02:53:31Z Silent_witness
Try going to My Computer > Windows > C:\ > Documents and Settings > (whatever folder has the username that you use when logged on and playing N) > Application Data > Macromedia > etc (I would type the rest but some of the stuff in between is different for different computers) until you get to a folder named "localhost". This should have your .sol file in it. Good luck, -st-.

Postscript: If you have to, use the search option in Windows Explorer and search all of your computer (or just your C:\ drive if you wish to be more precise) for "n_v14b_userdata.sol" or any parts of the filename like "n_v14", "userdata", ".sol", etc.
