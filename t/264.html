#23554 6 2004-06-06T22:10:17Z Guest
One problem about running N on a slow machine (I've played most of it on a 700mhz iBook) seems to have to do with the keyboard input. On my machine, when it gets slow (i.e. when I do anything else like listen to mp3s), it seems as if the game itself (i.e. the calculation of where things are) doesn't slow down; enemies move at the same speed. The framerate does suffer, so it looks like things are slower, but I think they're mostly just less smooth, at least on my setup. This is something I can live with, more or less.

What also suffers is the keyboard input; when running slow I think keystrokes get lost if they aren't timed just right. That is, if I hit the jump button at a time when, if the game were running smoothly, it would cause me to jump, it behaves inconsistently. This works out on harder levels to make it difficult to do some of the jumps you need to do.

I think it would help a lot if for slower machines, even when the framerate dropped, the processing of keyboard input didn't drop correspondingly. Given some amount of practice playing on a slow machine, when the framerate drops I usually know where my ninja is even if the screen doesn't, so the playability wouldn't suffer nearly so much if the keyboard stayed up to speed.

Just my take on the speed issue after having played most of N on a relatively slow computer. Of course, given some of the complaints and specs about windows machines, perhaps this is only true of the mac version; it sounds worse there.
