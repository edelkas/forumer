Ok so this is my guide to installing software from a disc image without the disc. I presume that you have daemon tools or equivalent virtual drive software installed.

Ok first you need the disc image, i got mine from command and conquers website since they released the first one for free. Ideally you should download it to your desktop for ease of location.

You can see the 2 command and conquer ISO files on my desktop (you need only pay attention to GDI95.iso)


Ok now that you should have iso file for your software of choice you should right click on daemon tools and move the mouse over Virtual CD/DVD-ROM and then over device 0: (it should have the drive letter in square brackets) so you get this menu


Cick on the highlighted menu selection in the picture and then select your disc image as so.


Click Ok/Open and the start screen of the disc should appear, if not try running it from my computer or browsing the CD for the setup file. As you can see my start screen appeared
