#167107 4 2006-04-20T14:24:53Z The Wazaa
If you at least want something to happen I suggest you call the functions with their right names But your drawings are a bit undersized for the whole thing so I suggest that you enlargen them up and think about how to put them in relation to their registration point and what point on the ragdoll they should be tied to.

I also suggest that you use a set of invisible particles and make your own drawings go after them instead, it's a bit easier that way I guess.

Oh, and if you want to find out how big angle there is, you can use this code:
degree = function(p0, p1) {
this.p0 = p0
this.p1 = p1
this.addAngle = 0
}
degree.prototype.rad = function() {
	var degrees = calcRad(this.p0, this.p1)
	if (degrees < 0) {
  degrees += 2*Math.PI
	} else if (degrees > 2*Math.PI) {
  degrees -= 2*Math.PI
	}
	
	return degrees + this.addAngle
}
degree.prototype.deg = function() {
	degrees = calcRad(this.p0, this.p1) / Math.PI * 180
	if (degrees < 0) {
  degrees += 360
	} else if (degrees > 360) {
  degrees -= 360
	}
	
	return degrees + (this.addAngle *180 / Math.PI)
	
}

calcRad = function(p1, p2) {
	var dx = p2.x - p1.x
	var dy = p2.y - p1.y
	degrees = Math.atan2(dy, dx)
	return degrees 
}

//Example of usage:
var deg1 = new degree(p1, p0)
var deg2 = new degree(p1, p2)

var deg = deg1.rad() - deg2.rad()
Good luck with it

#167482 7 2006-04-21T13:57:27Z The Wazaa
I would make a simple solution that looks something like this:
setMcToPoint = function(mc, p0, p1)
{
   mc.x = p0.x
   mc.y = p0.y
   var tempdeg = new degree(p0, p1)
   mc._rotation = tempdeg.deg(); /*Might be tempdeg.rad() don't remember which is used in Flash*/
}
Or at least something similar, and call this function with the movieclip that you want to call with certain points as parameters. I've not tested this so you might have to do some tweaking. You also have to use the piece of code that I wrote in a previous post with the degree class somewhere. Although you might remove the line:
this.addAngle = 0
That was something I was experimenting with for my angular constraint but never used and never removed either.

Hope this works
