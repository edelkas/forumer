Hey LoD, I have 1 question about the program...
How do you read the contents of an image file and manage it?
This is the code for the main form which loads the image (in Visual Basic .NET, CLR 2.0):
    Friend frmImageDisplay As New frmImage() 'reference needed for GDI+ actions
    Friend imgImageSrc As Image = Nothing 'the image for the GDI+ actions

    Private Sub btnLoadClipboard_Click(ByVal sender As System.Object, ByVal e As System.EventArgs) Handles btnLoadClipboard.Click
        If Clipboard.GetImage() Is Nothing Then Exit Sub 'no image found in clipboard
        imgImageSrc = Clipboard.GetImage()
        frmImageDisplay.NewPicture()
        CreateStretchMap()
    End Sub

    Private Sub btnLoadFile_Click(ByVal sender As System.Object, ByVal e As System.EventArgs) Handles btnLoadFile.Click
        ResetDialog(dlgOpenImage)
        dlgOpenImage.ShowDialog()
        If dlgOpenImage.FileName = "" Then Exit Sub
        imgImageSrc = Image.FromFile(dlgOpenImage.FileName)
        frmImageDisplay.NewPicture()
        CreateStretchMap()
    End Sub
For the picture viewer (frmImage):
    Friend frmMainControl As frmMain
    Friend GraphicsAvailable As Boolean = False

    Friend Sub NewPicture()
        If picImage.Image IsNot Nothing Then
            Me.Size = picImage.Size + New Size(20, 50)
            rectSelected = New Rectangle(New Point(0, 0), picImage.Size)
            GraphicsAvailable = True
        Else
            GraphicsAvailable = False
        End If
    End Sub

    Private Sub picImage_Paint(ByVal sender As System.Object, ByVal e As System.Windows.Forms.PaintEventArgs) Handles picImage.Paint
        e.Graphics.Clear(Color.White)
        If frmMainControl.imgImageSrc Is Nothing Then Exit Sub
        picImage.Size = frmMainControl.imgImageSrc.Size
        e.Graphics.DrawImage(frmMainControl.imgImageSrc, New PointF(0, 0))
        e.Graphics.DrawRectangle(Pens.Black, rectSelected)
    End Sub
I don't want to offer the whole source code, it has some sensible parts (for the automated detection of generated maps on NUMA). However, I hope that I could help you with this. (If you want, I can explain it, too.)
