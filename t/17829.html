#331094 4 2007-06-14T05:59:20Z LittleViking
Here's one way to do it. Excuse me for stretching the page. Imagine that the red layer is the bottom one that you want to show through (even though it's on the top).

You put the layer that you want the text to show on top of the text layer, and then go to Layer > Create Clipping Mask. (It says Release Clipping Mask in the image because it's already turned on.) Anywhere you move the text, the red will show through just like looking through a hole. This won't work for every situation, granted, but maybe it'll do what you need. I'm going to keep looking for a true text mask.

Edit: Nope, it looks like Photoshop doesn't support editable text on a mask. If you need to edit the text, this is probably the best you'll do. If you don't need to edit the text once it's down, then there are ways you can put it on a mask. I'll detail that if this clipping mask method doesn't work for you.

#331098 5 2007-06-14T06:18:51Z rocket_thumped
It's called clipping masks, if I'm understanding your question correctly.

1. Put the text you want on a new layer.

2. Make that layer invisible.

3. Create a new layer, then apply image. image>apply image (I think)

4. Then press ctrl+alt+g.

5. Make the text layer visible.

6. Move around the clipping masked layer until you get the desired effect.
