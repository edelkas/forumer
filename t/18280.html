Did you follow the "Stop n Swop" thing? There were rumors that you could carry over BK1 save files to BK2. There was a screen on BK1 after you finish the game that says "Stop n Swop" and there are items that you can collect (if you have a cheat device) that will show up on this screen.

Rumors went around for a long time about the truth about this odd feature.
Nintendo finally came out with a press release explaining this unused feature. They said they had planned to exploit an otherwise useless part of the system's memory to hold data for a quick cartridge swap.

The feature was removed from Banjo Tooie because research showed that using this part of the system's volatile memory was dangerous to use. And they feared people would tear up their cartridges swapping them so fast.

Look it up somewhere, it was pretty interesting. Like solving a computer mystery.
