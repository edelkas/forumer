#248243 7 2006-10-31T06:07:18Z BuddyLee
Here's what I do. Create a folder dedicated to map packs. Inside this folder, create a folder for each Map pack. And inside THAT folder, copy n_v14.exe in, as well as the userlevels.txt for the map pack.

i.e.:
"C:/N/Userlevels/The Legacy/" contains n_v14.exe and userlevels.txt

repeat for each map pack you need. Since n is only about 1.6 MB, it is easy to manipulate.

Run the .exe in the map pack folder to use those userlevels.
