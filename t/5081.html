#116905 21 2005-11-22T00:51:13Z Raigan
hi,
the answer to all of these questions could be "we don't know for sure", however i'll try to go into a bit more detail:

1) we're planning on having _something_ done for GDC2006 (march), however this is likely to be an alpha version or some similar "very early" version. the first release of the game should be a month or two after that.

2) this should be a couple months after the new game is released, it will depend on how the release goes.

3) the source code for all of the in-game parts (the physics, the enemies, the replays -- everything but the other stuff like menus, highscores, etc.) will be released along with tutorialC, near the time the new game is released.

4) some exciting news: an upcoming issue of PC Gamer UK (we're not sure which, we'll let you know when we find out) has a feature about the games they're most looking forward to in 2006, and one of the editors asked us to give them a sneak-peek inside "TNG"!

we couldn't give him any concrete details, since at the moment we're still working on technology to see what we can and can't do; we just explained the main ideas we wanted to try and inspirations we were drawing from, with the warning that it's likely the game will change considerably as we develop it and see which ideas actually work in practise.

i don't want to ruin the surprise since he was nice enough to get us in there (alongside games like quake4), but i'll try to say something.

one reason that we haven't posted here about it, and will likely not post much until it's almost ready to be tested, is that if it's anything like N, it will change a lot as we develop it, so anything definite that we say at this point will almost certainly be wrong/misleading. also, we don't want to do what every other developer does and put undue pressure on ourselves by hyping up a game that doesn't yet exist, only to run into problems and keep pushing back the release date. from soldat (and 1.4) we learnt to never announce a new release until it's _done_

anyway, some very vague info about the new game:

-it won't be made with flash
-it will be 2D
-the graphics won't look the same as N, however you should be able to tell that it's "our style"
-it will have physics-based movement
-we're trying to make it as different from N as possible

i'm afraid that's all we can say for now, however the tests we've done so far seem promising.

5) it won't be more than $20. we will definitely release more freeware in the future, however since makings games is what we really love doing, we've decided to try to do it as a business. we're not greedy, we just want to be able to devote all of our time to making games -- we're hoping that each game we release will make enough money to fund the next one.


thanks,
raigan and mare
