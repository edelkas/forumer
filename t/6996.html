#136426 5 2006-01-27T19:23:43Z The Wazaa
I think he means every time setInterval('function', 'interval') runs the function, which is a lot better than onClipEvent(enterFrame).

About your friction:
In what way do you store the position of the balls? Do you use the built-in _x, or have you created a variable called x for them? If you use _x the data type is too inaccurate and since Flash rounds that number downwards the ball will start moving. Make a variable called x (for example ball.x) and do every calculation with that. When you want to set the balls position you just:
ball._x = ball.x
ball._y = ball.y

Hope that will fix it, I don't see any problems with your code anyway.

Good luck - The Wazaa
