NB: This is hacking like the O'Reilly series of books, like Google Hacking.
Also, the forum system shortens the URLs, so hover over them to see them in full.

I discovered that you can combine all kinds of filters with NUMA to get exactly what you want, if you manuall append them onto the end of the url. I'm not sure how good I am at describing this, so here's an example:
http://numa.notdot.net/browse?sort=created...egory=4&count=5
That will display 5 of nevermore's race maps, in descending order from when they where created. If you add the favorites variable on, you can see 5 of nevermore's race maps in my favorites: http://numa.notdot.net/browse?sort=created...5&favorites=551
I've only got one, but you can see how it would work.

You can also use this to export userlevel.txt files, just change the browse? part into userlevels?, like: http://numa.notdot.net/userlevels?sort=rat...=desc&count=100 (the top 100 maps).

All the variables that you can use (as far as I know) are:
favorites
order (asc/desc)
sort (created/lastupdated/rating/votes/random)
author
count
name
category (0[all]/1[action]/2[puzzle]/3[test level]/4[race]/5[survival]/6[incomplete]/7[dda])

Hopefully y'all get that, if not, ask for clarification.
