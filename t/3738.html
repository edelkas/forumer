#76978 11 2005-06-21T10:33:53Z iangb
2 things.

1) JeR(K) - you took your map data without resetting your map. The ninja should start on top of the bounce block, right?
So everyone else - put the ninja one square above the bounce block (go into edit mode)before playing the demo. Unless JeR(K) fixes the map data.

2) I think that it is because the floorguard algorithm checks every tile that the floorguard can go to, to see if the ninja is there (if it is there, then the floorguard moves as far as possible in that direction). As at the end of the demo, the ninja is on the same tile as the one the floorguard is on, so it is not detected, because the floorguard doesn't check it's own tile (programming that adjustment in would be possible, but I can see why M&R thought there was no need in the first place). If, at the end of the demo, you move a little bit to the left, onto the other tile, then the floorguard reacts.

Solved!
