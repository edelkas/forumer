#149722 2 2006-02-28T17:28:49Z AV_Ultima
Download N v1.4 again, and take everything out of the zipped file, including the Userlevels.txt, that has all the userlevels. Ill explain how to get more below:

1)Go to numa.notdot.net
2)Find a map you like
3)When you click the map there should be somthing called data 1.4
4)Select all the data you see in the box next to it, then copy
5)Go to your userlevels.txt file
6)Paste the 1.4 data you got from the map below the line that says

***ALL LEVEL DATA MUST BE ENTERED BELOW THIS LINE********************

It doesnt have to be with a certain caregory(show below), it should do it automaticly, so put it any where, below the above line.


------DDA------

7)When your done with that, start up N v1.4
8)On the main menu it should say "Userlevels" click it
9)Wait while it parsites the data
10)A list should come up, click any of the names you see to play the level

Glad i could help.
