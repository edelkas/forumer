MotherLode Secured (Alarm Drone)
http://nmaps.net/134406

Restart NReality (a mod of N, download @ n.infunity.com) to retrieve this new update of Alarm Drone

Alarm Drone:
6^x,y,Path,0,132,direction
Alarm Seeker Drone:
6^x,y,Path,1,132,direction
Optional Parameter
^speed,chase_speed,laserMinRadius,laserMaxRadius,radiusUp,radiusDown,neverDown,alwaysMove

laserMinRadius, the min radius of the laser, default 30
laserMaxRadius, the max radius of the laser, default 400
radiusUp, the increase rate of the radius, default 1
radiusDown, the decrease rate of the radius, default 2
neverDown, if it is set to 1 then the laser will never decrease in size
alwaysMove, if it is set to 1 then the drone will move even when they see you, like the seeker alarm drone in this map

If both of the radiusUp & radiusDown are set to negative, then the laser radius will decrease when it see you and increase when it doesn't see you

specialOff : Lock the radius, so no more size change in laser radius
specialOn : allowed size change for laser radius
