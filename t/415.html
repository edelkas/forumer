9^24,36,0,0,1,[1],0,-1,0 is a normal door, in the upper left hand corner.
9^60,60,0,0,1,[2],1,-1,0 is a locked door, in the upper left hand corner, directly below the normal door.
9^60,84,0,1,1,[3],0,-1,0 is a trap door, in the upper left hand corner, directly below the locked door.

So, it seems that the only thing that determines what type of door it is, is the fourth number after the coordinates, which I've bracketed above.

Consider the following:

9^24,36,0,[0],1,1,0,-1,0
9^60,60,0,[0],1,2,1,-1,0
9^60,84,0,[1],1,3,0,-1,0
These are the three as above, and the following three are trap doors in the same square as the above one.
9^60,84,1,[1],1,3,0,0,-1 This is a trap door facing up, with the trigger in the same position as the others. The only non-coordinate numbers that changed are the first, the sixth and the last, which leads me to believe that the last two numbers are the door's facing.
9^60,84,0,[1],1,3,0,0,0 This is a Trap Door facing to the right, same trigger position, Same square, but now the first, sixth, and last numbers have all set to zero. What's strange about this, is that the second number changes depending solely upon the door's facing.
9^60,84,1,[1],1,3,0,0,0 And finally, This is a Trap Door facing downward, and instead of the last two numbers changing, the first changes, which leads me to believe that the second, sixth, and last numbers determine the door's facing.

So, A 0, -1, 0 would be a left facing door
a 1, 0, -1 is an upward facing door,
a 0, 0, 0 is a right facing door,
and a 1, 0, 0 is a downward facing door.

With this in mind, only the fifth number is really unaccounted for, and it may have something to do with the trigger. Also, the numbers in the "facing" rows may also have embedded meanings depending on where the trigger lies. More on this later when I get some more info.

Oh, absolutely. When you go into debug mode (~ at the main scren), press E to edit the map manually (not editing code). Once there, you can hit either delete or insert to place tiles or objects, respectively. To place doors, enter the Insert menu and then hit i, o, or p to place the kind of door that you want to place.
