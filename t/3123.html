#65011 6 2005-05-11T23:24:32Z brickman
Let me explain how the level data works on tilesets:

Every tile on the screen, whether used or empty, is contained in the code. It has a code of several digits for each valid tile type (aka anything you can do with the tileset only), and reads the code for each tile in succession. even if only the first three tiles have something, the code is the same length as if every space had something.
Now, you are both proposing to add more tiles to this. The problem here is, that would require more numbers in the data box, WHETHER LEVELS USED THEM OR NOT. That means that not only would they have to rework the code, but every single existing level would be broken. Every one of thousands upon thousands. Now do you get it?

Its a bit different with items, of course, but we're talking about the tileset.
