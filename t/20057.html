#377530 4 2007-11-07T15:07:02Z Raigan
you should be able to just proceed as usual for each contact, i.e apply impulses or whatever you're doing at each contact point, ignoring all of the others. of course, this isn't totally correct, but that's the solution most people use: just solve the constraints one-by-one rather than trying to figure out how they all interact with each other.

#377703 6 2007-11-08T16:10:47Z Raigan
It's sort of the same thing: if you try to solve all the contacts at once, you end up with a system of equations which encodes how each contact affects the others. One way to solve such a system is Gauss-Seidel relaxation, where you solve each row of the matrix individually -- this is identical to simply solving each contact individually.

So in a way Box2D/etc. _are_ solving all the contacts at once, they're just using an iterative method to find the solution.
