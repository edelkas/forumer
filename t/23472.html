Small Room (Tile Drone)
http://nmaps.net/134539

Restart NReality (a mod of N, download @ n.infunity.com) to retrieve this new update of Tile Drone

Tile Drone:
6^x,y,Path,0,122,direction
Tile Seeker Drone:
6^x,y,Path,1,122,direction
Optional Parameter
^speed,chase_speed,tiles

tiles is the text string for the tile pattern, it is just like the map data, the tile drone will loop thr the string to lay the tiles. default is "1"

specialOff : stop the drone for laying tiles
specialOn : start the drone for laying tiles
