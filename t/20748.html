#391675 3 2007-12-21T00:17:04Z George
Those 'meaningless symbols' are different algorithms you can set to your drones. 'Surface follow' algorithms allow your drone to follow a tile surface; basically it makes the drone complete circuits around a set of tiles. However, if it doesn't have any surface to follow, it will just go around in circles. The other three drones are fairly self explanatory. Do some experimenting in Ned to get a better feel for it.
#392283 4 2007-12-22T11:59:46Z Tapp
A represents dumb anti-clockwise. This makes it turn counter-clockwise whenever it hits a wall. Q is a bit more complicated. It makes the drone turn counter-clockwise when there is no wall in that direction. If you want a drone starting on a corner that uses this, make sure to point it 90 degrees clockwise of the direction that is desired. W is like A, except each time it alternates. Finally is S, which is like W but it picks a random direction. If a drone is in a corner (L or U shaped) is turns out the other side and back in the same direction respectively. If a drone had walls on all sides, it just stops moving permanently.
