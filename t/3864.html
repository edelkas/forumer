#84610 7 2005-07-19T09:52:39Z Maniac
You have to manually change the code. Place a laser/chaingun drone where you would like your turret to be located. Then, don't do anything else. Save your map, and return to the debug menu.

Highlight the code until you reach the point that looks like this:

6^324,324,2,0,2,3

Or some other number as the last number. Manually select the 3 or other number and type NaN in it's place. Or NAN will work too, as it will freak out and adjust it back to NaN.

And load the map again. The drone will now be immobile, but it will still shoot at you.
