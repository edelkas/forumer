Hi together!

I'm currently working on an external editor for N Levels.
I think it'll be much easier to create the levels there instead of making them in the N app. I hope you think so too

Until now I've coded the app to this functions:
  • Modifiyng tiles of the level
  • Preview the current selected tile
  • Saving the level to a file (in own created fileformat)
  • Loading the level from a file (in own created fileformat)
  • Show / Hide Grid
  • Change Grid Color
  • Change Grid Snapsize
That's it for now. There's no support for the objects until now but I'm working on this point too.
