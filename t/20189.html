#390312 8 2007-12-17T19:07:08Z Dead_N
First of all, NaNs should never be created.
Heres how it is created by some careless mapmakers:
You copy a level data code, you open Ned and CLICK on the level data box so that the CURSOR goes there, then you paste the code. Remember, the CURSOR is still in the box. OK, you press the 'L' key to load, the cursor is still in the box, so when you press L, along with loading, the letter 'L' is inserted into the box, so when the level stops loading, it has a new character, 'L', but a NaN comes instead of it, it stands for 'Not A Number', because 'L' is not a number, and it screws the whole code up. So, to avoid it, just do what LittleViking said, CLICK OUTSIDE the box AFTER pasting the code and BEFORE pressing 'L'

Hope thats everything
