#7825 1 2006-04-02T20:13:47Z Lazylump
After being disappointed with Ned, and finding no improvements in Ned++ (Sry guys, but there just were no new features), I decided to make my own map editor.

The whole point of this project was to combine roles which I think should be included in a single program, including tiles, objects, saving and testing.

iMapv0.6.5.zip

Please excuse the tacky name, but I am just not very creative.

Please use/evaluate/find fault with/whatever and post feedback. I am particularly interested in people finding bugs and code errors!

Instructions:

Right-clicking selects a tile. Subsequent clicks of the tile buttons or numbers on the keyboard will change this tile, as will using wsaq to rotate.

Once this tile is selected, left-clicking will deselect it, but also open the editor for 'paint' mode (The editor also starts in paint mode by default). The tile in the paint window can be changed using the keyboard or tile buttons, and left-clicking again will paste this data into whichever tile you are hovering over. Rotation can be chosen by means of the wsaq keys (As Ned users will be familiar with) and will be displayed by the grey arrow in the buttons window.

In the data window, there are several features including:

Test level in N.
Load from multiple sources.
Save to your harddrive.
Invert tiles.
Fill/empty all tiles
Create new map (Blank or solid).
Open several maps at once and scroll between them using the arrow buttons at the base of the window.

Note: I am doing my GCSEs in a few weeks, so I may not have time to do any updates for a while. When I have time, I may also make this open-source for all VB6 programmers out there.

Note: I also haven't got around to doing object placement, so please no people shouting at me over it. I will do it when I get time.
