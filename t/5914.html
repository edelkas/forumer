I don't think it will have much effect, but crazy noobs might. It isn't a lot greater incentive, but it is an incentive. The reason given for this scheme is that it would give you something to strive towards - that is, people will want that percentage, which only you can see, to be as high as possible. Rating others poorly is one way to help achieve that. It could also result in a more subtle form of low rating, such as "This map deserves a 4.5... but that would put it above my maps. I'll give it a 3.5 instead".

In any event, I don't see much point. If you want a slightly more accurate rating than the current one, ask Arachnid to put the actual average rating as a floating point number on the map page. It should be easy to do. You could also add a "number of results" display to the search function, and allow searches for maps above/below a certain rating, which would let you get a general idea of how many good maps there are.
