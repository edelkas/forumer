#430178 2 2008-04-20T12:29:43Z Zres
Zer0, please understand that making a game isn't that simple. You need to learn a programming language, and start from there. Some examples of languages are C++, Java, Actionsript, etc. It might take you a very long time to learn any of those, and might cost you some money doing so. Even Game Maker needs you to understand everything about it to make a game in a few weeks or so.

Once you learn a programming language, you have to start with the bare bones of the game (movement, physics, the basic concept of the game). It will take you a while to write that down in the language. Once you're done with that, you can add in levels, sprites, and animations into the game, while going over the programming code again*.

After you've done all of that, congrats. You have just made a basic game. Emphasis on basic. I have no idea how making an online game works, so sorry. Learning how to make games takes much patience and willingness to learn; a lot of people go to school for making games. So, in conclusion, if you want to make a game, make sure you absolutely want to. You need the patience.

*I'm not sure if this is correct. Someone tell me if it's not.
