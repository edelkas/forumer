I prefer ubuntu to Windows, but I keep windows around because there are some programs that I want to run that don't do so well with an emulator - mostly games - although with WINE and DOSbox I can convert about 50% of my games to linux.

I don't want to get a mac because I am not willing to spend the money/do not have it. That... and I can do pretty much whatever a mac user can do using free, open source programs. It's rumored that linux is hard to use if you're not a hardcore computer user, but with ubuntu this is simply false. I haven't needed to do anything highly technical to get what I want out of my OS.

The reason these arguments over operating systems are dumb is that the average computer user does pretty much the same thing no matter what operating system they use. Most people want internet, word-processing, spreadsheets, slideshows, and maybe a few games. For people who do other stuff, stuff that's beyond what the average computer user does, it actually makes sense to have a preference, but it's dumb to say that any one operating system crushes another in all categories. My friend's dad makes icons for microsoft, but he uses a mac. From what I've heard, pro image-makers tend to use mac software. My dad, on the other hand, writes software. You know, software that he can actually sell (runs native in windows, if you haven't figured that out yet). And for him it's certainly advantageous to use windows as his OS of choice. I use linux (mostly) because it's free and I only sort of have a job so I can't really pay for software. I also like to know what I'm putting on my computer, and I like to be able to adjust it to fit my purposes. Ubuntu lets me do all of this, so it's the best OS for me. If you want a server or supercomputer, it's sure as hell better to run linux than anything else.

Also, I'm thinking about changing distributions. I want something that takes up little disk space, is open source and customizable, and is designed primarily for speed on old, crappy toshiba laptops. GNOME desktop is preferable, but I'm open to KDE as well. Any linux fanboys out there that could help me?
