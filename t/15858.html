#348072 54 2007-07-27T21:04:47Z DemonzLunchBreak
Here's a pretty simple one to mess around with. Just try changing one little piece at a time, to see what it does.
startshape WHEE

rule WHEE{
ZOID{}
}

rule ZOID{
TRIANGLE{}
ZOID{y 1 s .99}
}

rule ZOID .02{
ZOID{r 45}
ZOID{r -45}
}

rule ZOID{
ZOID{ hue .5 sat 1 b 1}
}
Here's a slightly more complex one:
startshape BRETT

rule BRETT{
TREE{}
TREEE{}
}

rule TREE{
SQUARE{}
TREE{y 1 s .99 r 1}
}

rule TREE .03{
TREE{r 30}
TREE{r -30}
}

rule TREE{
TREE{hue 3 sat 1 b 1}
}

rule TREEE{
SQUARE{}
TREEE{y 1 s .99 r -1}
}

rule TREEE .03{
TREEE{r 30}
TREEE{r -30}
}

rule TREEE{
TREEE{hue 3 sat 1 b 1}
}
