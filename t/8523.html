Hi, guys. I switched from Visual Basic 5 to Visual Basic .NET 2005 some months ago. The N Tile Inverter is the first .NET application I published. It inverts a tileset (if you dunno what I mean check the program out). It includes a well-tested, convienent, and nice-looking installer and uninstaller.

On Windows, you will have to install the .NET framework 2.0 in order to run the application (probably, you have an older version of .NET installed and will have to update). Linux and BSD users should try DotGNU or Mono. These are alternatives to the proprietary Microsoft .NET framework. MacOS X users are also able to run N Tile Inverter by using the Shared Source Common Language Infrastructure from Microsoft.

More information about N Tile Inverter and the download can be found at my homepage.

Edit: This project is small and simple. I'm just working on a bigger thing which has nothing to do with N. You will find a hint to it somewhere on my homepage.

Edit: I just noticed that the installer provided at my homepage cannot be used by Mac and Linux users. Use the download below instead. For Windows users, I recommend the installer at my homepage instead of this download.
