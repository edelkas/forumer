#84207 5 2005-07-17T14:27:06Z LoD
You can create your own userlevels test file.
Open Notepad, and write:

&userdata=

$[levelname]#[authorname]#[level type]#[level data]#

Replace everything in [ ], e.g. replace [authorname] by [Ngaged]. [level type] can be everything in userlevels, but should be one of the categories which NUMA uses: Action, DDA, Incomplete, Puzzle, Race, Survival, Test Level. [level data] is the data that comes out of the upper box in Ned.


This way it should work. (Which means it works fine at my PC.)

But remember: Backup the standard userlevels.txt file before you save this one. The name must be exactly "userlevels.txt" and it must be in the same folder as n_v14.exe.
