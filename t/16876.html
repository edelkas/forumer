#14795 1 2007-04-10T23:14:50Z LittleViking
If you've noticed serious lag on forum topics in the past few months, I have a way to stop it.

The lag, if you've never experienced it, causes your whole browser to freeze up for a few seconds after loading any forum topic. This lag time is the browser processing Javascript for the spoiler, align, hr, and strikethrough tags. If you can live without these features, it's possible to block the script altogether.

Instead of seeing:
SpoilerHidden text
you'll basically see:
|spoiler|Hidden text|/spoiler|

The code for these functions is called from the following file:
http://metanet.2.forumer.com/index.php?act=Attach&type=post&id=301000
To block it in Firefox with Adblock, go to Tools > Adblock Plus... > Add filter... > and paste the URL here.
In Opera 9, go to Tools > Preferences... > Advanced tab > Content > Blocked content... > Add... > and paste the URL.
In IE 7, go Tools > Internet Options > Security tab > Restricted sites > Sites > paste the URL.
