Ok, many of you guys by now have seen NUMA's new tag system. However, if they are to serve their purpose, I suppose they would need some uniformity. For example, if one tag says 'KRA', and another says 'Keep the Rocket Alive,' I doubt they'll show the same results when clicked. For the sake of organization, I say we brainstorm some ideas for uniform tags for certain types of maps before we get too deep into this business.

Ideas?

Edit: What about difficulty tags? We would need a scale... Hmm.

Edit 2: Just had an idea. For collabs, you could add tags for each author. For example, epigone and I make a collab map. I could add the tag 'author:epigone' to the map, so there would be tags for each of the authors.

I'm just cock full o' ideas this morning.
