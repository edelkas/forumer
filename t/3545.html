Maybe this reply will help you...
// Flash MX 2004 strict data type enforced

// Create a key listener.
// Let's pretend your instance name is mcBox

var oKey:Object = new Object();
oKey.onKeyDown = function( Void ):Void {

if( Key.getCode() == Key.RIGHT )  mcBox._x++; // mcBox._x += 1;
if( Key.getCode() == Key.LEFT ) mcBox._x--; // mcBox._x -= 1;
if( Key.getCode() == Key.UP ) mcBox._y--; // mcBox._y -= 1;
if( Key.getCode() == Key.DOWN ) mcBox._y++; // mcBox._y += 1;

}

Key.addListener( oKey );

If you want to implement a jump mechanism do something like this
...
var nIncrement:Number = 2;

if( Key.getCode() == Key.UP ) mcBox._y -= nIncrement;
...

If you want to apply some sort of gravitational force you can try something like this.
_root.onEnterFrame = function( Void ):Void{
mcBox._y += .5;
}
// This will always move mcBox down .5 pixels every frame loop
// hence creating a gravitational illusion.
Of course you can make it more realistic if you apply basic physics movement.

Actionscript is not hard. So don't be discourage to learn it. Once you know actionscript, then you'd pretty much know two programming languages...JavaScript and Actionscript...with slight differences.
