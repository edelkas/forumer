#306098 5 2007-03-18T16:11:38Z jtbandes
Quote: Toshosoft, March 17, 2007 09:30 am
You could try setInterval() if you're really picky about the rate. You just make a function which checks for key-presses and call it every I-don't-know-how-many milliseconds. Check it up in the reference.
That's what I do, because it seems like the best way to have control over the game's performance. Take note, however, that if you leave the framerate at 12 with this technique, it'll still be a little jerky. So I set the framerate to 30. And now for a short guide on how to do what TS said.

(All this is the Actionscript for the first frame. You should only need one frame in most cases.)

Create a timer that runs the frame() function every several milliseconds (I use 10).
var frametimer = setInterval(frame, 10);
Then, make the frame() function.
function frame() {
  if (Key.isDown(Key.UP)) {
    _root.you._y--;
  } else if (Key.isDown(Key.DOWN)) {
    _root.you._y++;
  }
  
  if (Key.isDown(Key.LEFT)) {
    _root.you._x--;
  } else if (Key.isDown(Key.RIGHT)) {
    _root.you._x++;
  }
  
  updateAfterEvent();
}
That's a very simple function to take the keyboard input and move around an object with the instance name "you". The updateAfterEvent(); refreshes the screen, so each time this function is run (every 10ms or so, depending on your computer's speed), the screen is redrawn and you get smooth movement.
