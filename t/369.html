If ever there was a game that cried out for the subtleties of the directional pad, this would be it. It's a challenge to learn how to control N with the arrows, of course, hence the appeal, but I think it could be added without detracting from the purity of the experience.

(I've noticed arrows tend to be better for simpler games and a directional pad better for more complicated ones: Jumper and Solar Jetman being two examples of the approaches. The latter would have been an exercise in frustration with a keyboard, and the former is far too precise a platformer to really lend itself to the Sidewinder or another pad.)

Again, it's not a necessity, but it would be nice to have the option.
#23760 2 2004-06-17T05:47:18Z Rich
Your only real option is to look for a program called Joy2Key. It will allow you to map Joystick/Gamepad button presses to keyboard keys.

Native support for a joystick in N is unlikely since Flash doesn't support input from devices aside from the keyboard and mouse.

The only way I could see this happening is if Macromedia added this to their next iteration of Flash or if you could somehow reference a DLL from a stand alone projector.

Is there a note about this in the readme? I can see this question coming up repeatedly.
