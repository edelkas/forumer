1. Copy the Level Code in the "Map Data"
2. Open the game (N: The Way of the Ninja)
3. Hit the "~" key (under Escape)
4. Paste the Level Code into the upper box
5. Press "L"
6. Make sure CAPS LOCK IS ON and press "P"
7. Play the game and read the manuel nextime
