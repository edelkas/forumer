#431328 2 2008-04-24T19:16:55Z Pikman
Do you mean attach the text file? If that's what you're talking about, I can help you.
First, get to the Reply screen or the Edit post screen, where you type what you want to post. Look for a bar that says "File Attachments" below the big field of text. There's a "Choose file" button that you can click, and it lets you browse your computer for the file you want. Because you're a member, the maximum size of uploaded files is 500 KB. Then, when you're all set with the post, click "Add Reply" (or "Submit Modified Post"). You cannot do this using Fast Reply, though.
Hope that helped! Also, you could put the data on pastebin.
