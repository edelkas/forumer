#394866 2 2007-12-31T00:18:50Z Pheidippides
This involves either locked doors or, more preferably, NaN'ing the drone. You should read LV's Tutorial about it to learn more, but for this specific situation, here's what to do:

1) Immediately after you add the laser drone, go back to the debug menu.
2) Click inside the level data box, at the very end of the data.
3) Hit the L key to load the level without clicking out of the level data box.

This creates an error in the code that makes the drone stay put. LV goes into great detail about all sorts of code editing, and his tutorial even explains why this editing does what it does. You should definitely check it out, and good luck with those ideas.
#394868 3 2007-12-31T00:23:16Z Atilla
This can be done in one of two ways.

1. Put a locked door on every side of the drone. When they are unlocked, it should remain stationary.

2. Edit the level code manually. The easiest way to do this is to put the drone in, then - without adding any other objects - return to the Ned menu and hit a random letter. This will change the part of the code which describes the drone's path algorithm to "NaN" (Not a Number), which makes it stand still. You can also go through your data and change the last number in the drone's code to "NaN" by hand. There's a basic overview here.
