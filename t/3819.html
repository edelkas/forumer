I wanted some N art levels carrying my signature. But I'm really bad at drawing but good at programming so I created the N Art Maker.

The system is as following:
1. Load a picture (from file or clipboard). BMP,GIF,JPG and WMF are accepted.
2. The picture is converted into a monochrome bitmap (2 bit, i.e. only black and white).
3. An N level is built based on the monochrome bitmap. You can choose between 1/4 snap and 1/2 snap and between gold or mines. For every black point in the bitmap, an object (gold or mine) is set in the bitmap. In my next post you see a level created based on my avatar.

The current version is 1.2.1, which is available since 24 Jan 2005. It adds a clipboard feature, allowing you to store your NAM art to the clipboard for a direct check in Ned. If you would like to use this feature, you should download 1.2.1.

You can download the N Art Maker from my website. When doing so, please take some minutes of your sumptuous time to read my personal appeal to all users of N Art Maker. (Never fear, I won't ask for donations.)

Version history
  • 1.0.0 - initial release
  • 1.1.0 - redesign of the interface, stretches pics to the correct size
  • 1.1.1 - allows to change the brightness of the NAM art
  • 1.2.0 - optimization of the interface for small monitors
  • 1.2.1 - fixed problem with clipboard

#110441 70 2005-10-25T17:30:24Z LoD
OK guys. If NAM is not working let your system search for these files in the system32 folder:

kernel32.dll
ntdll.dll
user32.dll
gdi32.dll
advapi32.dll
rpcrt4.dll
ole32.dll
msvcrt.dll
msvbvm50.dll

They should all come with your system except the last two. The second last is copied when you install a C++ program using an installer (for example most computer games). The last is the VisualBasic VM, similar to the Java Virtual Machine. It is required to run VB progs.

If you don't find this file in the system32 folder, try to get it from a friend (the Windows versions must be equal, even the same service packs need to be installed). I'm not allowed to give them to you.

You could also search for a program written in VB which comes with an Installer.

@the mac guys: Perhaps someone can port the VB code to C++. I'm sure there are C++ compilers for Mac.

more arguments:

1. PCs get broken, yes. But you can throw broken components away and buy new ones. I don't know if this is possible with Macs.
2. On PCs, you can choose your OS. If Windows is not good enough for you (and Windows is not good enough for you), you may switch to Linux.
(Which would result in the same problem: You get not as much software as for Windows.)

#114941 77 2005-11-14T17:19:42Z LoD
Do every step described at the main panel, from the top (loading a picture) to the bottom (saving the map).
After having done one of the steps, the next one should be unlocked.

Explanation of the single steps
1. Load a picture. As you said, you have already done that.
2. Select a region of the picture to convert. There are 2 options: The easier one is to convert the entire picture. A bit more difficult is the second option, which allows you to select a part of the picture manually. When selecting this option, a message box appears explaining something about the progress. Then, specify the part of the picture which should be converted by clicking at the upper left and at the lower right point of the suggested triangle.
3. "Objects snap at..." If you don't know what snap means, start Ned, go to the edit mode, then to the object editor, and then try pressing [X] and [C] while looking at the text below the cursor. - 1/2 snap means a lighter N art, because less objects can be placed.
After this step, the StretchViewer shows your selection at the correct size, which means that one pixel in this picture represents one object in the N art.
4. Select the darkness of the map. A higher value means that even brighter parts of the picture are converted to N objects, and not to blank space. Therefore, a higher value makes the N art look darker.
5. Build object map. Just click the button.
After this step, the ObjectViewer shows a preview of how many objects will be placed and where they will be located. The dark gray color represents an object, the lighter gray color stands for blank space.
6. Now you may choose the objects which will be placed. "Gold" and "Mines" are quite obvious. If you chose 1/2 snap in step 3, the option "colored" is also enabled. This means that red pixels will be replaced with mines, yellow pixels with gold, and blue pixels with zap drones.
The colors in the object map will change depending on which object to place and where.
7. Build the real map. This may take some time.
8. Select a version of N. With "1.3", you get the bare level code. When choosing "1.4", it is formatted like that: $levelname#authorname#type#data# You surely know this format from the userlevels.txt or from NUMA.
9. Type in level infos. Only for the 1.4 format.
10. Save the map. Quite obvious, but it seems like the clipboard option does not work. I dunno why. And another remark: If you choose userlevels.txt, don't select the original userlevels.txt file which comes with N, or any other existing userlevels file. These files will be overwritten. You should save the level to a new userlevels file and then use my N Map Archiver to integrate this userlevels.txt file into an existing userlevels.txt file.

@ all who have problems with "comdlg32.ocx":

Search in the Explorer for this file: "C:\Windows\system32\comdlg32.ocx" (or "C:\Windows\system\comdlg32.ocx" on Win9x and WinME). Then look for information about the version of this file. I have 6.0.84.18. If you have a version 4.x.x.x or below or if this file even does not exist, try the following steps:

Download the file http://activex.microsoft.com/controls/vb5/comdlg32.cab. Extract this archive, right-click on the inf file in the Explorer, and choose "Install". Now, reboot your system and retry to start Ned++.

If Ned++ does not run properly, search the ocx file again in your system(32) folder. If you find it, look for the version. If it's not 5.1.43.19, something went wrong during the installation process.
