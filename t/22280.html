#19945 1 2008-04-15T07:19:20Z LittleViking
Right now, when you search for maps, every tag you enter has to be on the map for it to show up. A lot of the time, this is good, and it makes sense. If I search "action puzzle," I don't want to get all the non-action puzzles and none-puzzle action maps - only the intersection of the two.

But there are times when I want to get maps with any of the tags I list, not neccessarily all the tags I list. Maybe I'm looking for jumpers, so I search for "tile-jumper, mine-jumper, gold-jumper." As it is, I would probably get 0 results. But with an OR option, I could get a listing of all three together.

One of the most powerful applications of this would be creating an "author watch list" like everybody keeps talking about. If you want to watch all maps from atob, littleviking001, Kablizzy and Yahoozy, you could just bookmark a search of "author:astheoceansblue author:littleviking001 author:Kablizzy author:Yahoozy_Guacamole" with the OR switched on.
