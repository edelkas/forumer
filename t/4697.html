#96864 3 2005-09-03T09:37:10Z Atilla
You can play them in the user levels menu, too. Paste the v1.4+ level data in the box on the left, just below the bit that says

Replay data:

When you beat a user level... (and so on)


(you know, $Champion of Clutter MkII#Atilla#Shameless Plug#110203981...etc etc#), then paste the replay data, then a #. So you should have

$Level name#Author#level type#level data (you know, all those numbers and stuff)#replay data (more weird numbers)#

Then press the 'Watch replay' button.
