My suggestions.

1. Ned should have a drag and drop txt box.
You should be able to drag and drop userlevels.txt files into Ned's text box. The first level will load, and you can play or edit as you wish. Then, you push the arrow button to move to the next level.

2. More integration with NUMA.
I know you guys are aiming for more integration with NUMA, so I hope you're talking about pressing an 'upload' button or such, but don't take away the Submit a Map at NUMA. That is the one I would use, because my level design computer isn't hooked up to the internet.

3. On the 'H' command.
I use Mac's command+h keyboard shortcut alot, and if I forget to save, it loads a full map. This is very discouraging. Please change that or make it so command+h doesn't effect it.

4. More universitality with Ned
You should be able to press ~ at any time and edit the level: whether it be a Userlevel, or an in-game level. That way, in the N help section, you can submit demos of in-game levels. You can also practice the hard parts of the level without the tedium of the beginning parts.

5. More flexibility with demos.
Why is the demo for debug mode different from the demo in the UserLevels? And why do in-game level demos not exist? All demos should be the same. Personally I prefer the frame rate first type.

6. Doors and quarter-snapping
Doors have to be able to quarter snap. (When you press 'c' on the edit page). You can't know how frustrated I have been with this, especially in race levels.

7.Customized Icon
That would be nice.

8. Selectable objects
Objects should be treated just as tilesets - you should be able to select them, copy them, and delete them. A similar idea involving gold delay is that you can select a square, and push a few keys that indicate the number of seconds of gold delay. Another similar idea: Easy edit trampolines - along with the trampoline placement (step one of one) there would be a mark to where the ninja would be propelled, that snaps to locations that are normal, but you can make excessive or minimalist tramps more easily.

[b] 9. Overlappable Tilesets [B]
I think a solution to problem of non variance in tilesets is not a vector editor, instead, there should be multiple layers of tiles, allowing for way more cool shapes, and helping race flow, and great for N art. This would slow the loading time, but not the reloading time.

10. The Epic?
This one is rather tenative - maybe there should be an in-game set of all the Epic levels, like under the 'play game' menu.
