Hahaha
Sorry

When writing for strings, it's generally a good idea to write the whole thing with one sharp (G major) or two sharps (D major).
Why? A violin has a G string and a D string, a viola has a G string and a D string (an octave lower), a cello has a G string and a D string (again, another octave lower), and a double bass (if you're using this) has that same G string, and a D string a fourth lower than that.
Trust me on this one; it's hard for a stringed instrument to even play three flats, let-alone 5.
