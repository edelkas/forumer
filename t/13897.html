<teacher mode>
An sol files is just like a large array. Kind of like an ini file. It contains a bunch of different types of variables, which each have there own value. You can simply create a string type variable and call it 'quicksave' or w/e and then store the level data in string format (what else?) in there. Then when NED starts, check to see whether the value is null or "" or w/e, or if it contains level data. If it is valid, load it, else replace the errors with NaN's and load.
