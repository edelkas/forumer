#132510 4 2006-01-15T01:35:44Z Atilla
Sounds like you have NaNs.

What's an NaN? It stands for Not a Number. What happens is that the user - that's you - pastes the level data into the appropriate text box, then presses L to load. Unfortunately, since the cursor is still in the text box, this also puts an 'L' on the end of the level data. Since N only deals with numbers and some punctuation, it is designated as Not a Number. When the level is loaded, this NaN is then intepreted as some random, undeletable object in a silly position. The solution is simply to click outside the text box before pressing anything. You can probably rescue your old level data by going through and deleting all NaNs, but since you've already remade it there is no need. Just be careful in the future.
