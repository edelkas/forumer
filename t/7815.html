Not quite. You missed a few important bits.

EITHER (Ned)
1)Go to numa copy map data.
2)Go to ned(~) paste in top box.
2.5) CLICK OUTSIDE THE BOX, then press L
3)Find comment to that same map with demo data and copy it.
4)Go back to ned and paste that in bottom box.
5)CLICK OUTSIDE THE BOX, make sure caps lock is ON
6)Press 3, then Q, then P.

OR (Userlevels)

1) Go to NUMA, copy '1.4+ map data'
2)In N, go to the userlevels menu. Paste the userlevels data in the textbox.
3)In NUMA, copy the appropriate demo data
4)In N, paste the demo data into the same textbox, immediately after the '1.4+ map data'. Add a # to the end of it all
5)Click the 'watch replay' button.
