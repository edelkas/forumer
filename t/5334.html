#110372 2 2005-10-25T09:39:31Z astro
Do a search for "n_v14b_userdata.sol". This is where the data is stored, and on a windows computer it is usually in a directory like:
C:\WINDOWS\Application Data\Macromedia\Flash Player\#SharedObjects\ALF474WP\localhost
(if you're using Windows 95, 98, ME), or:
C:\Documents & Settings\username\Application Data\Macromedia\Flash Player\#SharedObjects\TSV434WQ\localhost
