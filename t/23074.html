#450474 3 2008-07-03T15:20:16Z heatwave
Quote: gloomp, July 03, 2008 12:40 pm
NUMA only excepts maps raw, not in userlevels ($MAPNAME#AUTHOR#TYPE#MAPDATA#) format.
Which is confusing because when you copy/paste level data from NUMA into the Neditor, there's more than just the raw data. Gloomp is right though. When you create a map in the Neditor, the only thing you need to paste into the box on the submission page is the code that appears in the upper box from the neditor. Nothing else. If you take that code and paste it into a word document or something, This is what you should see:

11A0000000001LGK111NA0>MG00G000000021111114|5^234,300!7^228,324,3!9^198,300,1,0,10,13,1,0,-1!9^276,300,0,1,10,12,0,0,0

Note: This is an extremely abbreviated version of the code for a map.

The code in red represents the tileset of the map. if you copy/paste only that portion of the code into the Neditor, you would only get the tileset. No objects. All of the tileset data must appear before the | character.

The vertical separator in orange is the | character that you're having trouble with. Make sure that there is only one of these throughout the data.

The code in blue represents the objects you've placed in your level. If you have a ninja in your level, the first number after the | will be a 5. All object data must appear after the | character.

Hope that helps!
