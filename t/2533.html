#55196 9 2005-03-21T18:09:47Z Guest
hi,
ARGH!!!

well, we were afraid of this.

the problem is: the only way to get access to the filesystem (which is the most important feature of 1.4) is via a 3rd party projector which adds extra functionality to the normal flashplayer.

however, all 3 projectors which we've tried have also slowed things down noticeably. these candidates were the BEST ones -- many were totally unplayable

don't despair, we have an alternate working solution.. sadly, it's not as elegant as just allowing N to read/write files itself. we're going to have to pull the filesystem stuff out of N and into a seperate app, which will run in a 3rd party projector. N will run in the standard flashplayer, so it will be identical to 1.3c performance-wise. or.. possibly better

reading/writing files will happen via passing messages between N and the seperate "filesys app" (flash has a feature which lets all the flashplayers running on a computer pass messages to each other). this way, N runs fast, but still has access to files. the down side is, it may be slightly more awkward to use, due to focus changing back and forth between the two programs. we'll do our best to make this as transparent as possible..

thanks,
raigan
