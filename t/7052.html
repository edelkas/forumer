This doesn't really belong here, but I think it's very cool, and might be of use to some of you, so here it is.

I own a homebrew capable DS (required:Passme and storage device (I use GBAMP v2)), and I have a wireless router and a PC. That means I can use this little program.

Basically the program is set up on both the PC and on the DS and keypresses on the DS are sent to the PC and translated into keyboard presses. I've set it up so that I can (in debug mode): start recording a demo, press caps lock, go back to the EDIT MODE from playing a map, press P to play the map, reload the map...... basically I can do all the things I need to start recording a demo, playing a demo, and when I die I can go back to the EDIT MODE and reload the map, press caps lock twice to remove any looping sounds (such as the sound of a flying rocket), and start playing again.

It's taken a while to get used to, and I'm not 100% comfortable with it yet, but it still rocks and I thought you all deserved to know.



ps. The way I have it set up is as follows:

Shoulder button L: "`" (go back to EDIT MODE)
Shoulder button R: "r" (reload map)
A : "spacebar" (for jumping)
B : "TAB" (for manouvering around the menus (I can't assign buttons to the arrow keys for some reason))
Y : "Caps Lock" (for pausing and stopping looping sounds)
X : "p" (to play the map)
Select : "Ctrl" (Boss mode)
Start : "1" (record demo)
