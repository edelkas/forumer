Spoiler: Some glitch help'(f)' means I found it out myself.

Transdoor: (f)
If you have a trapdoor and a lockeddoor over eachother. You can close the trapdoor, then open the lockeddoor and make
so that you can go through.

Doubledoor:
If you have a ndoor with a lockeddoor ontop of eachother (the lockeddoor has to be on the same square as the lockeddoor
opener key). You jump on the lockeddoor opener and you cannot get through untill you move away.

Brick door:
If you want drones to go into a brick, simple. Put the trapdoor ontop of the brick (vertical) with the key in the brick.
The code will look like this:
9^372,348,0,1,15,13,0,0,0
Change the 3rd number after the '^' into a NaN. Drones will be able to pass right into the wall.

Teleports: (f)
In your trampoline code you will see that the two last numbers are a:
,0,-1
,0,1
,1,0
or a
,-1,0

Change the one to a higher number if it is in the positives, change it to a lower number if it is in the negatives.
