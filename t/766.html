Well I know that this has probably been stated in the past many times before, but I do think multiplayer would be a neat concept to look into for N.

I know that the current level sets couldn't be altered in order to make em multiplayer friendly since it would require a lot of work that is not needed. What I do think would be good is to design a specific multiplayer mode with it's very own set of levels that people can enjoy playing with each other.

Maybe have each level have 2 or more paths that you can take (each one closing off to make sure only one player takes each path) which would ensure that more of the level gets traveled on. Also since it's multiplayer, the ninja's would then have to work together to ensur both of their safety, since one wrong move can send a robot or block crashing down on the others forehead.

I guess one issue for implementing multiplayer that could arrise would be whether the game should be LAN based or fully online. If it were LAN based then it shouldn't strain the server even in the slightest but if it was made online then you will probably start seeing problems of lag or the servers getting slow from too many connections requesting data at the same time. If made for online multiplayer then it allows you to have more people to play with but still it has some drawbacks since most likely people will experience a bit of lag.

Another thing that has to be taken into consideration would be in creating a way for people to get a group of people to play with. Having 3 people or more would pose a challenge without some sort of lobby where people can chat and organize games. Having players able to make their own specific game rooms that other can join in would be nice. But also they would need a kick feature if a certain player is insulting, sabotaging, or just plain irritating you.

I guess to make the game even more challenging would be to make it so that the players only win if every one of them makes it to the door. If one player dies then you all fail. I think that would be pretty fun. I guess that would also eliminate glory hogs who would try to kill you and get to the door so he could be the only one to finish the level since he would need the other players in order to finish the level. Maybe have switches that 2 or more people have to hit at the same time in order for a door to open (making the game really be co-op.)

Anyways I do know that multiplayer would be difficult to implement into the game at this time but I do think it would be an interesting and fun feature to further look into.

If multiplayer is a possibility then I will start sketching out some idea's that I could use someday.

I'm sorry if I rambled on a cilantro too much.
