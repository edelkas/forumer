The basic idea behind this is door switches that (possibly only) zap drones toggle. This could be used so N would have to "herd" zap drones to areas he can't get to (too many enemies/etc), or you could set up "timed" doors where a zap drone in a closed area hits the switches, but has to cover a long path first. Survival maps could use this so that if the play survives for a while, they can actually beat the level (and thus they could be put episodes).

I think this could be a *highly* useful idea.
