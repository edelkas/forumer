This program generates the object code for a spirograph in N. It requires the input of at least 5 values, one of which determines the object. Some examples of spirographs in N are here.

I don't have the proper licsenses to make a real EXE from Liberty BASIC, but my friend does. I e-mailed him about it and he may or may not give me an actual program of it. Anyway, here's the source code:

xc=300
yc=300
steps=0.01
10 PROMPT "Enter radius of fixed circle (1-99)"; R
20 PROMPT "Enter radius of moving circle (1-99)"; r
30 PROMPT "Enter offset point (1-99)"; O
31 PROMPT "Enter length (1-20)"; endpoint
32 PROMPT "Enter object code number (See the Readme file)"; object
40 CONFIRM "Debug?"+chr$(13)+"Click yes if your previous spirograph"+chr$(13)+"was cut off the screen.";var$
50 IF var$="yes" THEN 150
55 PRINT "Working... (program copyright Gforce20 xanaman@gmail.com)"
60 FOR t=1 TO endpoint STEP steps
70 x =(R+r)*cos(t)-(r+O)*cos(((R+r)/r)*t)
80 y =(R+r)*sin(t)-(r+O)*sin(((R+r)/r)*t)
90 lvl$=lvl$+str$(object)+"^"+str$(x+xc)+","+str$(y+yc)+"!"
100 NEXT
110 length=len(lvl$)-1
120 level$=left$(lvl$,length)
125 CLS
130 PRINT level$
140 END
150 PROMPT "Enter center point X-coordinate (default 300)"; xc
160 PROMPT "Enter center point Y-coordinate (default 300)"; yc
170 PROMPT "Enter step value"+chr$(13)+"higher value is lower quality (default 0.01)"; steps
175 IF steps=0 THEN NOTICE "Cannot step 0; infinite loop" : GOTO 170
180 CONFIRM "Change all values to integers? (default No)"; int$
190 IF int$="yes" THEN 215
200 GOTO 60
210 IF var$="yes" THEN 150
215 PRINT "Working in debug mode... (program copyright Gforce20 xanaman@gmail.com)"
220 FOR t=1 TO endpoint STEP steps
230 x =(R+r)*cos(t)-(r+O)*cos(((R+r)/r)*t)
240 y =(R+r)*sin(t)-(r+O)*sin(((R+r)/r)*t)
250 lvl$=lvl$+"10^"+str$(int(x+xc))+","+str$(int(y+yc))+"!"
260 NEXT
270 length=len(lvl$)-1
280 level$=left$(lvl$,length)
285 CLS
290 PRINT level$
300 END

Download Liberty BASIC from www.libertybasic.com and run the code to use it. Readme is in attached file. READ IT.

You should calculate (R+r), (r+O), and (R+r/r) and store them as variables, and then call the variable inside your loop. That way, you only have to calculate them once instead of doing it every time you run the loop. It'll save you three additions and a division for every iteration.
