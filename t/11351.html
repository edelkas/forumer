#318179 14 2007-05-04T19:54:01Z the splodin' chipmunk
I don't see exactly what your problem is. If it's screwed up on the userlevels and it's your first posted level it's alway screwed up.

An NaN will usually occur in the code of the last object you place down, unless it's a ninja who is always the first in the object code section of the level code.

If you don't want something screwed up, what I always do is put a thwump directly inside an outer wall, that way the NaN only affects the thwump, as long as it's the last thing you placed, and the thwump's not part of the level.
