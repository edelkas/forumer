This script allows you to define macros for commands. For example, I might type:

/define k kick %0-

And then I could simply do:

/k nick reason

to kick someone. Or, for a simple "fish" script,

/define fish me slaps %0 around a bit with a fish %1-

/fish jtbandes because he feels like it.

And that would send:

/me slaps jtbandes around a bit with a fish because he feels like it.

Get it?

http://pastebin.com/f1d191b08

Take that and save it as "define.pl", then load it as a script in XChat.
Note to windows users: if the script does not work, as in it says something about register(), delete every instance of "Xchat::" (without quotes) in the file.

From the help:
Usage: DEFINE [-t] <cmd1> <cmd2> [<format> ...], defines cmd1 as a macro for cmd2.
    The -t option creates a temporary command that will be destroyed
       when X-Chat quits, or when the define script is unloaded.
       All other command definitions are saved and reloaded
       when X-Chat starts up again.
    cmd1 and cmd2 MUST NOT include leading slashes.
    Format syntax: %n  Inserts the nth argument (first argument is 0)
           %x-y Inserts the arguments from x to y, inclusive
           %x-  Inserts arguments from x to the end of the input
           %-y  Inserts arguments up to and including y
           \%  A literal % character
    All other text in the format string will be taken literally. Be careful!
    Defined commands are saved in the file definedcommands.txt in the same folder
       as X-Chat. Deleting this file will clear all of your defined commands.
    The UNDEFINE and DEFINEDCMDS commands are also available.
       See /help undefine and /help definedcmds, respectively.
