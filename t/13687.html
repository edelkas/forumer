#252220 3 2006-11-09T21:21:44Z LittleViking
What I do is set N to a lower processor priority. That way, if there are other programs running, N will slow down and the others won't.

If you want to do that, press ctrl+alt+del, go to the Processes tab, right-click n_v14.exe, and Set Priority>Below Normal.
