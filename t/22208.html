So... when you go back to the editing menu with the "level data" and "demo data" boxes, you can see the exit door, but the exit key dissapears?
Try this:
go into editing mode.
place a door inside the level.
place the key anywhere inside the outer rim of tiles.
go back to the editing menu (also known as the debug menu) by pressing the ~ button
If/when the exit key dissapears, go back into editing mode and press the letter T.
a line should appear from the exit door to the exit key. If it points off of the screen, then the code for the placement of the key is messed up.
