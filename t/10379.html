#189249 13 2006-06-14T10:23:00Z LoD
The userlevels.txt file should have a format like this:

&userdata=

$[B]name[/B]#[B]author[/B]#[B]category[/B]#[B]data[/B]#

$[B]name[/B]#[B]author[/B]#[B]category[/B]#[B]data[/B]#

$[B]name[/B]#[B]author[/B]#[B]category[/B]#[B]data[/B]#

$[B]name[/B]#[B]author[/B]#[B]category[/B]#[B]data[/B]#

[B]...[/B]

Replace the bold words with the specific data. (One line is one level.) Comments are allowed between the lines, if they don't include a "$".

If this does not help, upload the file to a file hoster and post a link here. I have special tools to test NMA's behavior with the file.
