Map Combination Contest

The Map Combination Contest is a different kind of tournament: every week, the contestants will make a map based only upon certain elements. They choose their own elements for each week, but no element may be used twice. This leads to many different combinations of styles.

There must be exactly 7 or 8 contestants for this to work.

Since there are three categories of elements and 8 elements in each of those categories, the maps will be quite hard to make well. This is intentional- it shows just how well you can make maps with such restricted themes.

The categories are Tiles, Genres, and Enemies. Since some tiles work together, you may use each group twice. There are only 5 major genres, so Action and Puzzle are repeated, and you may choose the 8th. There are 8 enemies, so that works out quite nicely.

There will be only seven rounds because the 8th would only have one contestant. Hence in each element category there will be one unused element.

Quote For Emphasis: You choose your OWN 3 ELEMENTS each week. I do not dictate them.

Judging:

Tile usage w/10
Relevance to genre x/10
Enemy usage y/10
Fun to play z/10

Total: ?/50

The attached text file shows you the elements. Contestants please keep a copy of it so you can track what you've used.
