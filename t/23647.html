I wanna be the guy (Jump Settings)
http://nmaps.net/136251

This is the third room of I wanna be the guy
Watch the video http://www.youtube.com/watch?v=uvL3Vxn1g-8 here you can find out the third room

Restart NReality (a mod of N, download @ n.infunity.com) to retrieve this new update of Jump Settings

noWallJump, default 0, set to 1 to disable wall jump
noWallSlide, default 0, set to 1 to disable wall slide
maxJumpCount, default 1, set to 2 to enable double jump (i.e. you can jump in air), set to 3 to enable triple jump and so on, set to 0 to disable floor jump (you can still wall jump, to disable wall jump too set noWallJump to 1)
jumpResetYSpeed, default 0, set to 1 to reset coordinate Y speed when jumping, please test this newly added attribute, cause I don't know how to explain it. (Test it with double jump and you will get the idea)

The mod in this map:
|||||noWallJump,1;noWallSlide,1;maxJumpCount,2;maxspeedAir,2
