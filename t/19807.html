#17601 1 2007-10-19T11:11:13Z ska
Today you should back up your sol file to a memory stick, iPod, CD etc. (something other than your computer in case of accidental progress deletion.) Make sure you copy not cut the .sol file. If you don't know how to locate your .sol file simply search for .sol, making sure you've checked hidden files and folders or alternatively:
Quote
Edrial=both Macs and Windows use the same .sol file. their formats are no different and are compatible.

Windows .sol location: C:\Documents and Settings\(Username)\Application Data\Macromedia\Flash Player\#Shared Objects\ usually a one way street from there...
*Note: Application Data will probably be a hidden folder

not sure if this is exact because i don't have a Mac....
Mac .sol location: Home > Library > Peferences > Macromedia > Flash Player > #Shared Objects\ usually a one way street from there...


just put the .sol in that location. replace the current .sol if necessary. always keep a back-up.
Put this in high scores because I know most of the people who have this problem are high scorers. OK, Good Luck and make sure you back-up regularly, it might be a pain in the ass to do it now but imagine the excruciating pain in the ass if you don't and you lose it all! This has been a public service announcement.
