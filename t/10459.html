Point of this program: If anyone has ever used N on a Read/Write portable storage device you will have noticed that when you go to another computer you have to start your game all over again, unless you remember to copy your savegame and then copy it back when you get to the new computer.
This launcher makes it so that all you have to do is run the launcher and that is all and your progress will become portable.

Check it out:
EDIT: Link removed until I get the bugs worked out, someone already lost their savegames.

To use:

Step 1: Put the launcher in the same directory as N
Step 2: Run the launcher
Step 3: Hit the "Launch N-Game" button to run N
Step 4: Play game
Step 5: When done playing N, quit N
Step 6: Hit the "Close Launcher" button to complete the save game transfer and cleanup.
