Anyways! In custom pathing and coordinate pathing, while this functionality is basically already offered, a huge hassle saver I'm sure people would like:

Another "direction" for Custom path, and somehow implemented into coordinate:

Reverse.

Two foreseeable ways of doing this: just plain old "reverse" which retraces all the steps but backwards, or reverse with a variable of how MANY steps to retrace.

For example, for the former, a custom path of LLRUDLRUURDUURRLUB (with B being backwards) would be the exact same as LLRUDLRUURDUURRLUDRLLDDULDDLRUDLRR. Notice that where the B was in the first example, there is now the same thing as before, except mirrored, both in order and in direction (which serves to retrace its steps).

As for the latter, which is more functional, you could have something like ULULULULURRRRDDDDB7, which would be the same thing as ULULULULURRRRDDDDUUUULLL, which as you can see replaces "B7" with the last seven steps, backwards. You could even add stuff after that!

Clearly this would be a low priority as all it would do is make it easier to use rather than implement brand new functionality, but if it's pretty simple, or as a long-term goal, it would be nice to see implemented. I'm not sure how the custom code would look for the coordinates though, I'm not too familiar with that code.
