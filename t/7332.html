#139926 3 2006-02-05T20:32:18Z iangb
You've probably copied the wrong level data. Try re-putting the data into userlevels.txt. Also, try reloading the userlevels.txt data in debug mode again and see if it shows the same level.

When you initailly go into debug mode, the map data there is the map data of the 'computer playing' level. You probably copied that instead of the correct data. Remember - if you leave debug mode and go back into it, the level data will change!
