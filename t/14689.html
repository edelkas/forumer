#312932 14 2007-04-14T00:46:56Z jtbandes
*resurrect*

I was bored, and poked around Fan Programs to find something to port to Mac.
Here it is, Tile Inverter made into a Mac app with Applescript!

Icon:

Spoiler: In case you're interested, here's the code.
-- Initial variables
set mapdata to ""
set authordata to ""
set objectdata to ""

-- A small function I found on the internet to replace text in a string
to searchReplace(thisText, searchTerm, replacement)
    set AppleScript's text item delimiters to searchTerm
    set thisText to thisText's text items
    set AppleScript's text item delimiters to replacement
    set thisText to "" & thisText
    set AppleScript's text item delimiters to {""}
    return thisText
end searchReplace

-- A function that swaps all instances of one char with another...
-- Useful for inverting tilesets
to swapChars(thisText, char1, char2)
    set thisText to searchReplace(thisText, char1, "X")
    set thisText to searchReplace(thisText, char2, char1)
    set thisText to searchReplace(thisText, "X", char2)
    return thisText
end swapChars

-- It's a good idea to actually figure out what we're inverting
display dialog "Paste map data here:" default answer mapdata
set mapdata to text returned of the result

-- Chop the author info ($Title#Author#Category#) off the data (and store it), if it exists
set hashPos to offset of "#" in mapdata
repeat while (hashPos is not equal to length of mapdata) and (hashPos is not equal to 0)
    set authordata to authordata & text 1 thru hashPos of mapdata
    set mapdata to text (hashPos + 1) thru (length of mapdata) of mapdata
    set hashPos to offset of "#" in mapdata
end repeat

-- Chop the object info (|...) off the data (and store it), if it exists
set pipePos to offset of "|" in mapdata
if pipePos is not equal to 0 then
    set objectdata to text pipePos thru (length of mapdata) of mapdata
    set mapdata to text 1 thru (pipePos - 1) of mapdata
end if

-- Invert!
set mapdata to swapChars(mapdata, "1", "0")
set mapdata to swapChars(mapdata, "2", "4")
set mapdata to swapChars(mapdata, "3", "5")
set mapdata to swapChars(mapdata, "F", "L")
set mapdata to swapChars(mapdata, "G", "M")
set mapdata to swapChars(mapdata, "H", "J")
set mapdata to swapChars(mapdata, "I", "K")
set mapdata to swapChars(mapdata, ">", "D")
set mapdata to swapChars(mapdata, "?", "E")
set mapdata to swapChars(mapdata, "@", "B")
set mapdata to swapChars(mapdata, "A", "C")
set mapdata to swapChars(mapdata, "6", "<")
set mapdata to swapChars(mapdata, "9", ";")
set mapdata to swapChars(mapdata, "8", ":")
set mapdata to swapChars(mapdata, "7", "=")
set mapdata to swapChars(mapdata, "Q", "O")
set mapdata to swapChars(mapdata, "N", "P")

-- Let's not be greedy and keep it all to ourselves.
set mapdata to authordata & mapdata & objectdata
display dialog "Inverted map data:" default answer mapdata 
    buttons ["Copy", "OK"] default button 1
-- Provide a nice way to copy it to the clipboard.
if button returned of the result is "Copy" then
    set the clipboard to mapdata
end if
