This is a brand new idea, Ive spend about for an hour to find a similar contest. Nope, I luckily didnt find anything. I will check this contest nearly every day so just post every question here. Now, straight to the point.

The example map is ready!

The Rules

1. Make a map and submit it to NUMA. Link the page here please.
2. The only allowed enemies (mines are counted) that you can add into the map are zap drones (all kind), floor guards and thwumps. You dont have to use every of them and there is no limit for those enemies. Other objects (doors etc.) can be used normally.
3. Actions, puzzles and races are allowed.
4. No manual editing!
5. 2 maps per person! Only the map with the highest score is counted in the end so no one cant get the all prizes.
6. No old maps!
7. No more maps!

Judging

Two judges only because this contest wont be very popular: me and max_ride
The final scores contains both scores added together. Accurate and simple system.

Criterias:

-Playability (flow etc.) ?/15
-Fun ?/15
-Outlook (tileset, object placement..) ?/10

Total is 40.

Prizes

The prizes arent valuable. Still I hope that you submit maps and have fun when doing them. Signature tags are all made by me.

Winner: Signature tag and a dedication (and honor and glory too ).
The 2nd: Signature tag.
The 3rd: Signature tag.
