#376913 2 2007-11-04T17:49:09Z 3v!1
First load the level (you know that, I'm just making sure).

To start recording a demo, press 1 before you play. Once you die/finish the level, go back to the Ned menu and copy from the box below the level data. For userlevels this is automatic and you don't need to press anything, just copy the data. It'll contain both the map data and the demo data in the demo box. I'll explain this later.

To replay a demo, paste the data into the second box (under the map data box), then press 3, then Q. Wait for the map to finish reloading, then press P. The demo should play.

For the purposes of Userlevels playback, the strings that can go in the box there contain both the map data and the demo data on the same line. Even if you don't have the map in question in your Userlevels file, you can paste a demo from someone else's Userlevels in here and it'll load the map. Don't try pasting normal demos in there, they don't work.

So, the demo data that's posted on NUMA can't be used in the User Levels section, you have to open the debugger and use that?  And to post demo data yourself on NUMA, you have to use the debugger, and get the demo data from that, instead of what shows up on the User Levels menu after you beat the level?  After I play a User Level, and copy the replay data from that menu, NUMA doesn't let me post that there.
Remember, userlevels data is shown in this format: $Level name#Author#Map Type#Level Data#Demo Data#, so both formats can be interchanged, depending on the viewing method you'd like to use.

With regards to levels from NUMA, if you want to view a demo in debug mode, all you have to do is copy the level data into the top textbox, load in the map, copy the demo data into the bottom textbox, and watch. If you want to view a demo in the userlevels menu, make sure the data is in this format: $Level name#Author#Map Type#Level Data#Demo Data#. In other words, copy the level data from '1.4+ Map Data' to a text document, and then paste the demo data directly after it, with no spaces. Then paste it into the lower left textbox in the userlevels menu to watch.

If you want to copy one of the demos you made in the userlevels menu, all you have to do is remove the level data and copy the demo data alone to NUMA (e.g. 375:183729|123...).
