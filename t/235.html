hey,
like i said, this has been a HUGE learning process for us, and the next release of N will have the user-data file in the same directory as the game; also, this user data object should henceforth be transferrable from version to version (although this capability only exists in theory since we haven't got an implemented working version yet).

if your saved games have suddenly dissapeared, this is because:

1) you moved or renamed the .exe, or the path of the .exe (all the directories up from the exe to the root/hard drive). if you change thing to how they were, the saved data should "come back".

2) you have shared objects disabled. when the game is running, right click and go to options/preferences (i forget exactly what the menu item's called) -- there will be a slider which will let you specify how much space the game is allowed to use on your harddrive. if this is set to "0", then the user data won't be saved.


we're sorry about the few irksome things which have been in N; as i said, this was our first game and as such was a huge learning experience -- mostly learning by making mistakes

but it's great that our users have given us so much helpful feedback, since it lets us not only make N better, but also makes sure that our next games won't repeat these mistakes.

raigan
