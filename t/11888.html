#215113 4 2006-08-13T17:01:15Z Raigan
cool!

if you do want to make the laser "hit" the surface of the world, you should be able to use the raycasting code from the tutorial. if you're not using a grid you'll have to change it around slightly, but the basic idea is the same.. just intersect the ray with the edges of the shape and use the earliest intersection.

you could even use the same approach for the collision of the bullets: you can either intersect the linesegment that represents the bullet's movement each frame, or (simpler) when the bullet is first fired, calculate the time of intersection and remember it (you'll still have to collide it vs moving objects each frame).
