#5666 1 2005-12-14T02:18:12Z Virtual Cyberspace
Stacking gold is used in many DDA maps, but is frustrating to get the right amount, or to delete it. So something that would be useful (but not necessarily necessary) is pieces of gold having an extra flag in the map data, defaulting to 1, that is how many pieces of gold it counts as. From there it would act just like a normal gold stack. However, adding an extra flag to gold would mean maps would take longer to load, so it would probably need a new object that looks the same (or very similar) that works like a gold stack.

#123016 7 2005-12-15T00:04:32Z Teh Dude
When creating N maps, it is possible to place gold on top of other gold to form a stack. However, once you have placed it, it is impossible to tell how many bits of gold are in the stack. The suggestion is that you should be able to place gold then set how many pieces are in that stack. So I would place the gold then type the number "10" if I want there to be 10 pieces in that position.

The original poster has called this number a flag. This is perhaps misleading as generally a flag is a boolean variable.
