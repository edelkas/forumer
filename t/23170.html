Ceiling Guard

http://nmaps.net/131265

Restart NReality (a mod of N, download @ n.infunity.com) to retrieve this new update of Ceiling Guard

Floor Guard : 4^x,y,1
Ceiling Guard : 4^x,y,1^ 1

you can append speed as optional parameter, like
4^x,y,1^ 1,20

If you want to set floor guard speed, you can make it like
4^x,y,1^ 0,20

btw please delete the space between ^ and 1, cause if I put "^" and "1" together in forum, it will display as special character 4^x,y,1,20
