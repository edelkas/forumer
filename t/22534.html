Welcome to MetaFlow

MetaFlow is a project aimed at the whole community, be you talented at image designing or not, this should, in theory, appeal to everybody. I hope you enjoy it almost as much as I did while thinking of the idea.

The main principle behind MetaFlow is that each user submits a 256x256 pixel image, which depicts themselves, each image will, in turn, get a place on the MetaFlow. MetaFlow itself is a cover flow style presentation of these images, similar to Apple's Cover Flow. Where each image will have it's user's name underneath, with the centre image being a MetaFlow starter image, created by me.

So I hope you enjoy the fun, and remember, make sure that the image is you.

Before we begin, I would like to post the necessary rules.
  • The image size must be 256x256px
  • Your entry for the MetaFlow must be sent via PM, Email, or IM to me. I will do the compiling at the end.
  • The order I receive the images in will be the order in the MetaFlow that they will sit. Like this: 864213579 and so on.
  • Each image is also required to have some form of border, do not forget this rule
