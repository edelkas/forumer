hey, haven't posted in a long time, but i do play the game everyday.

i use flash, the program in which this game is made, and after figuring out how the user levels are loaded in the game, i thought it could use better things that are in-built in flash, such as xml parsing. so the userlevels.txt file would would be userlevels.xml and would increase the speed of loading user levels in the game itself.

example userlevels.xml

<levels>

<level_1>
<title>title goes here</title>
<author>author name goes here</author>
<type>game type goes here</type>
<level_data>level data goes here</level_data>
</level_1>

<level_2>
<title>title goes here</title>
<author>author name goes here</author>
<type>game type goes here</type>
<level_data>level data goes here</level_data>
</level_2>

</levels>

this is very useful, and flash would be able to parse this very quickly. currently, the version we have uses symbols, and so they need to be parsed, and i believe there would be a lot of code behind it. so if you guys use xml parsing it would be faster. hope this helps, and i really hope you guys understand my point and what i wrote.

Edit: Here comes the DTD for this one.
<!ELEMENT userlevels (level)+>

<!ATTLIST level

    category CDATA #REQUIRED
>
