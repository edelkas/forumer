Pass the Map

The point of this competition is to demo the map the fastest. I know there are many competitions out there right now that are like this, but I am adding a new twist to this one. The twist is that if you demo the map the fastest, you get to make the map for the next round. The advantage of getting to make the map is that you get immunity that week. The only other problems that if you dont make the map in the time given youre automatically eliminated.

Rules:

1) All demos are user level demos.
2) All maps must be over 110 tiles.
3) You must make the map in one week.
4) You will have one week to demo the map.
5) Slowest demo is eliminated.
6) If there is a tie, I will choose the map.
7) If the map made isnt good I will choose another.
8) If I choose another map the person loses their immunity.
9) The map doesnt have to be amazing but it has to be sufficient.
10) Sometimes I will throw twists into the round.
11) Have fun!

Prizes:
1st: Sig and dedication.
2nd: Dedication.
3rd: Congrats.
