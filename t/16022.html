#342127 9 2007-07-12T15:19:15Z Teh Dude
I have returned merely to set you on the path to enlightenment.

symlinks obviously will not work as n requires the 32bit versions of the files. You must find the .deb package containing the missing files. Once downloaded, you can use dpkg -x to extract the files. You must then copy them across to the lib32 folder.

Finding the packages can be a little tricky. You can use the search engine at http://packages.ubuntu.com/ to get them. Choose http://packages.ubuntu.com/ then "Search the contents of packages" and enter the filename. Make sure to choose the right version of Ubuntu too (e.g. Edgy or Feisty).

You may have to repeat this process as n tells you that more files are missing.

It does work though.
