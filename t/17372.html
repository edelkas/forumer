#321774 2 2007-05-16T22:20:03Z LittleViking
The first thing I would try is booting into Safe Mode. Restart your computer, and when the Windows loading screen first shows up, press F8 a few times. If you were fast enough, it should take you to a menu which will let you boot intio safe mode. Safe Mode starts Windows with as few programs and themes as possible, so the malware you have shouldn't start up with Safe Mode. Once you're in there, you can run Avast again and should be able to remove it.
