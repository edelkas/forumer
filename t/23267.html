#455732 7 2008-07-29T05:17:46Z Hendor
Yay, a puzzle.

<solve>

IBF stands for Instant Backup File. I believe it's the format that forumer uses to store typed data en route to further storage. See the following code for the Username and Password boxes:

User Name: <input type="text" class="forminput" size="10" name="UserName" onfocus="this.value=''" value="{ibf.lang.qli_name}" />
Password: <input type='password' class='forminput' size='10' name='PassWord' onfocus="this.value=''" value='ibfrules' />

As you can see, each line begins with the text "<input", which starts a field where the user can enter data. You can probably figure out nearly everything else except the "value=" right near the end of each line. It is an attribute, modifying the <input> tag. In this case, it is indicating the default value of the field. The default value here would be nothing, a blank box. This is also what you would want the field to show after you submit your password. Rather than simply state this in the code, I believe forumer is referring to a stylesheet titled "ipfrules" pertaining to the rules that should be followed when using an Instant Backup File. I'm sure Little Viking could help us out here.

</solve>

Sorry to disrupt your fanciful thoughts of a bored programmer.
