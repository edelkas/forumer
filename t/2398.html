I had an idea, and I was wondering if anyone else thinks this would be fun. It's a map-making competition where each week (just a guess, could be more or less) there is some guideline that the competitors have to follow. This could be anywhere from very vague to as specific as using a set tileset.

The model could be everyone gets 5 days to make one map, and then there's 2 days of voting on the forum for the best map. The winner gets some pride, and then it starts over for the next week.

If anyone else thinks this might be fun, I've got an idea for the first one. Please post if you are interested or have suggestions for how to make it work better.


GUIDELINE FOR MAPS DUE FRI MARCH 11th:
I'm going to call the maps scatter maps, because I think I saw that term once and can't think of anything better.
There are very few of these maps on NUMA, so it should be a good stretch for us map makers.
Some prime examples from the game: 7-0, the bottom of 23-4, 29-2, 33-1, the top of 37-2, the middle of 45-4, 48-0, 51-3, 53-4, 59-3.
Some OK examples that suffer from symmetry: 7-1, 18-4, 38-4, 42-4, 58-3

Things to strive for:
- Open space to jump
- Infinite paths for getting the exit switch and the gold
- Flow
- Consistency in style - any part of the level should feel like the rest

Things to avoid:
-Symmetry
-Enclosed spaces
-Lots of enemies - The challenge comes from finding a good route

If this isn't a good idea let me know yours so we can use it.
