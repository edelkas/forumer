Let me try...

If you are trying to make the level you should read the read me. If you you don't have it because someone gave it to you without it try this.

1. Press the ~ button, usually located near the top left of your keyboard
2. press the 'R' key
3. Press the 'P' key
4. Make sure caps lock is switched ON or you will play in Frame By Frame Mode.

Did this answer your question? If not, read on.

If you mean reset all the data you will need to erase your .sol file. This can be done in two ways.
1. Re-image your computer.
2. Run a search for .sol as the file name, assuming you are running windows, make sure you check 'looking in hidden files and folders' and 'system files' otherwise you probably won't find it.
a. Select the file that says: n_v14b_userdata.sol
b. Delete it.

I suggest doing the latter but...

WARNING! This will permanently erase all N data and preferences, If you are having problems unlocking a certain episode. Try beating the previous episode in the column with practice mode switched OFF in the configure menu.

Did this help? If not, fend for yourself!!
