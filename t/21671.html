In this game, you change one letter of the word given above so that it has a different meaning.
An example: Dog becomes Fog.

Note that numbers, symbols and anything else except alphabetical letters (from A-Z) are not allowed.
When it seems impossible to continue, start again with a new word, but do not repeat previous words.
Please use words found in a standard English dictionary.

Quote
Nexx: This might be more interesting if you could choose to add or remove a letter instead of always changing one.

Rules:
In each post, you may do one of the following:
- Add one letter
- Remove one letter
- Change one letter
- Rearrange the letters to form a new word
