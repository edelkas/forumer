#180242 5 2006-05-25T10:33:24Z Atilla
Open debug mode (Ned). Paste the level data into the imaginitively named "Level data" box, and load the level (L). Then paste the replay data into the replay box (check the level's page on NUMA. If there's no replays, ask at the forums), load it by pressing 3, hit Q to initiate playback, then P to start watching. And make sure caps lock is on.

Alternately, paste the replay and level data into the replay box in the userlevels menu using the syntax "$Levelname#Author#Category#leveldata#demodata#". If you're not sure what I mean, follow the St Atilla's College link in my sig and look at the .txt file attached to the first post.
