Just a few things I noticed might be nice for Ned.

1) When using lots of doors, it gets really difficult to keep track of which switched opens which door. It would be nice if the switches and doors were numbered/color coded.
2) This is also about the doors, if there are more than one on top, it would be nice to be able to maybe mouse over them and get a tooltip with a list of their numbers (from first layer to last)

e.g. (supposed to look like a rectangle containing the door numbers hehe):
__
|1|
|2|
|3|
|4|
---

3) I like the UI in Ned, it is very fast when you get used to it. However, it would be nice if the key were draggable, and able to be moved outside of the level area (for higher resolutions) so it's not in the way.
4) Would be really nice if it were possible to have one locked door that could be opened by two separate switches (that is, if you hit one of the switches the door will open, but it doesn't matter which).
5) Also would be nice if it were possible to be able to have a switch that closes a trap door, and one that can re-open it.

That's all for now. Thanks ^^.
