#21234 1 2008-08-25T05:14:33Z The Kitchen Sink
All right, currently Ned isn't cutting it for many, especially for NReality. No alternate Ned programs out there support NReality as of yet and even so, there are a lot of things that could be done better. Unfortunately I have no coding skillz, otherwise I would have just done it myself. So instead, I've created a wishlist for things that should be done if one were to be made (and I hope it were to be made). I realize that quite a few of these are already done on existing alternate Neds, but still. Without further ado:

Copy+Paste:
  • Ctrl+Click a tile section to add/remove it from the paste (This way the copied things don't have to be rectangular, and can have holes in them)
  • (Customize-ably) Transparent preview of paste area
Objects:
  • Feature a Copy+Paste like with tiles (only activated on mouse drag)
  • Make the Copy+Paste toggle-able between overwriting and layering
  • Give the Copy+Paste the ability to also have half-snap, 1/4 snap, and no snap
  • Allow the "Copy Box" to be filled with a type of object, at a set interval, like 1/2 snap, full snap, etc (with a pop up dialog box to determine what object and the snap)
  • Be able to change the load order of objects in their property box (with simple "bring to front" and "push to back" options)
  • Toggle between whether the object you're placing down will come last in the code, or first (after the ninja, that is) by default
  • Easily create thwumps that go backwards when you touch their back
  • Easily create jump pads with a custom angle and force
  • Possibly be able to draw lines between two different coordinates with customizable set interval, with the option of either centering or biasing towards Point A/Point B if the interval doesn't fit perfectly
Tiles:
  • Inversion of "copy box" area (so that anything empty becomes full, and vice versa) directly, or as the copy
  • Rotation of "copy box" area directly (if it perfectly fits), or as the copy (either way)
  • Flip of "copy box" area directly, or as the copy
  • Possibly permanent shift of "copy box" area (so that 3s become 7s, 7s become 3s, etc) directly, or as the copy
Control:
  • Full snap
  • Offset existing snaps as an option
  • Fully customizable Hotkeys
  • Possibly be able to assign a group of objects/tiles to a Hotkey for quick access for future maps
  • Display coordinates for mouse in the bottom right
  • When in "no snap" mode, (customizable) color code on the mouse coordinates display whether or not you're on a 1/4 snap or half-snap pixel
  • Undo/Redo (with customizable cache, default large)
NReality:
  • Full support
  • GUI
  • (Toggle-able) door switches drawing color-coded lines to objects it either Triggers or SpecialTriggers, individually (like it does with locked/trap doors in Ned, but with color for NReality-specific implementations)
  • Right-click an object to open context menu; have "NReality Properties" in context menu, for easy modification. Those would be filled with the various properties, by default greyed out, displaying the default number, check a box next to it to activate
  • Toggle for the names of said properties, between the variable names and pretty names (for example, the difference between "chase_speed" and "Chase Speed"
  • Easy GUI "custom path" and "coordinate path" making
  • Floorguards have WASD on placement for which direction, like drones do in Ned
  • Possibly save presets of various modifications (like moon gravity or rotating laser that doesn't rotate facing down)
Grids:
  • Key toggle-able grids just like in Ned (some of the rarely used grid possibly to be removed?)
  • Option of having a certain grid by default always up
Other:
  • At its core, as much like Ned as possible
  • Another mode to combine tile and object placing, and be able to Copy+Paste both at the same time
  • Quick metadata edit
  • Saving of map data, directly to userlevels.txt (as well as the clipboard)
  • Possibly could publish it to NUMA with a prompt for the relevant details to be filled out. I've seen things like that before, without any affiliation with the website itself.
If I left anything out you'd like to suggest for me to put in here, say so. If you disagree with anything I've put here, say so. If you just feel like commenting, do so. Etc. I'll update this if I have good reason. Anyways, hope this is helpful. Peace.
