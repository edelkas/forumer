#190658 2 2006-06-17T08:26:46Z astro
It's the first number in the replay data, e.g. 853:xxxx|xxxxx|xxxx|xxxx...

If it's 1.4 Userlevels style, it'll start off with the name/author/category, then the map data, then the replay data. Either way, look for the number, followed by a colon and then all the following numbers.
