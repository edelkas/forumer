#125316 5 2005-12-20T21:40:13Z Sucker
Kirby has pointed that out already, iangb. Anyway, with code editing:
Put the drone as last object in your map, go to debug and place the cursor behind your data. Then press L, this will reload the level and cause a NaN, wich will let the drone be unable to move. This works with every drone. If you want to make much drones this way, watch out for the code for a drone, and put the cursor behind that one. The code starts wit 6^.
