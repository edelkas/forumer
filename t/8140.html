#153272 2 2006-03-10T00:40:14Z Raigan
if you download the slides from the tutorials page ("beyond hittest"), they have some extra info which might help make things click.

specifically, the "check for overlap" step can be thought of as a generalization of basic circle-vs-circle collision

if([distance between objects] < [sum of object radii]) then objects are colliding.

the only difference being that you check multiple axes, and at each axis you calculate "distance between objects" and each object's radius by projecting things onto the axis.
