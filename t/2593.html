No, that doesn't work because the Flash player doesn't stop using sound, the volume is just 0.

However, I did find a workaround, something along the lines of tying up the sound device with another program. XMMS did not work for me, and since I am using Fluxbox WM I cannot easily tag a sound event to N, unlike KDE. But I found that if I use my browser (for verbosity, Mozilla FIrefox 1.01 with Flash plugin installed) to access a Flash page with sound (such as the menu for homestarrunner.com) I was able to then start N and play without the lag experienced previously. This may have something to do with the Flash projector and plugin both using the same libraries or something, but it works. Obviously this won't work for everyone, but maybe it will work for someone else as well, which is why I am posting all this.
