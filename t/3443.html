#71316 2 2005-05-31T20:58:51Z shoftee
OK... basicly collision multisampling is used when small objects move too fast. So first of all you need to know how fast your objects could ever move . But you (probably) already know that .
What you need to do is:

1. For each step, check if the current particle moves faster than a certain limit.
2. If it does, you divide the big step into smaller ones and calculate where the object would be after each smaller step.
3. check if there is a collision for the new position of the object.

Without this, if the object moves too fast, it might miss a collision, or in other words, it might just step "over" another object and carry on.
The problem with multisampling is, that you have to limit the number of smaller steps. So technically if an object moves fast enough no time-unexpensive algorithm can "save" it. But if you make some adjustments (like max-speed limits), you wouldn't have such a problem.

#71532 4 2005-06-01T20:13:08Z shoftee
No, that's not the way.
If you do it like that, after it collides it be twice as slower.

OK, you have the variables:

numdiv -> the number of smaller steps
i -> obvios
v -> the object's position (Vector2)
v2 -> the object's possible position (Vector2)
step -> the velocity vector (Vector2)
sstep -> the smaller velocity vector (Vector2)
( please read through the code and the explanation after it it's not complete, and if you just put it in there without looking at it you'll learn nothing )

var numdiv = 4;
var i;
var v = new Vector2(20, 20); // for example
var v2 = new Vector2();
var maxspeed = 10;
var step = new Vector2 (10, 10); // for example...
var sstep = new Vector2(0, 0);
if (step.len () > maxspeed) {
 sstep.x = step.x / numdiv;
 sstep.y = step.y / numdiv;
 v2 = v;
 for (i = 0; i < numdiv; i ++) {
  v2.x += sstep.x;
  v2.y += sstep.y;
  // here you do collision-check for object at position v2,
  // that means you check as if the object was at position v2
  // I'm doing a trace on where the object will be
  trace (v2.x + ", " + v2.y);
 }
}
Now, let me explain what exactly I am doing here. First I declare all the variables (duh). I'm using the Metanet Vector2 object .
After that, you check if the speed is too big. 10 * 10 + 10 * 10 = 200. Square root of 200 is approx. 14.14 (14.142135623731 to be exact ) > 10 so it enters the if.
Then you calculate the multisampling step. Since the big step is (10, 10) and numdiv is 4, so the smaller step is (2.5, 2.5).
Then it enters the for loop. For every i from 0 to 3 inclusive, it calculates the position and checks for collision.
When/If you find a collision be sure to break out of the main for loop .
