I'm not so sure it works, apg. Not for me anyway. It would probably be better to run it in debug mode.

1. Press ~ to enter debug mode.
2. Copy all that level data into the top textbox, and click outside the box.
3. Press 'L' to load the data.
4. Copy the demo data into the lower textbox, and click outside the box.
5. Press '3' to load the demo data.
6. Press 'Q' to start the demo.
7. Press 'P' to watch the demo.
