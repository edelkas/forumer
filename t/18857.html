#16686 1 2007-08-12T00:00:33Z kydo
As we all know, when we pick out maps in userlevels mode, we wouldn't know if the map that we're about to click is an N-Art or an Action map. This really bugs me as whenever I mistakenly click on an N-Art, I either have to wait for a long time for it to load and exit when it finishes, or quit and re-open the application, then wait for the maps to load.

So I've thought about the "Main Tags" system, wherein when you submit maps, there would be a highlighted tag field to input the map type (it's basically like the one with the old NUMA). You can't type anything in this particular field, but a drop-down box appears when you click it. There, you will select the map types (Action, Puzzle, etc.). You need to select a map type, or else the map won't be submitted.

For example, I want to submit a race map. I start out by inputting the name of the map, map data, etc.
Then from the drop-down box, I select "Race". This is essential.

I click submit, and there! When I download the map, the "type" field is no longer empty.

So... anyone up for it?
