#341569 2 2007-07-11T01:06:53Z Twistkill
Ooh, that's terrible.

Unfortunately, there have been a recent influx of Mac users with this same problem. You can try one of these 2 things:

(I don't know the equivalent of the Windows right-click) anywhere in the N window -> Settings -> Tab with the folder on it, make sure the slider is all the way to the right, then close and reopen N. Beat an episode and close N, then reopen it. If your progress was saved, then it's working correctly.

Also, make sure that the N .sol file is in place. There's a very handy guide for N .sol files, where your progress is stored, located here. It's Pinned and in this same section, as well.

Reply back if you're still experiencing problems.
