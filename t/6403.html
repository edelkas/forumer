#126151 2 2005-12-23T04:50:16Z Ixi
That's not really how open source works. A lot of games and programs have had their source code released--for example, Quake. But you don't hear about the game community being flooded with bad Quake clones. Modifying someone else's source code is a pretty tough task; the unsuccessful attempts wither into obscurity, leaving only a handful of really successful spinoffs. And those spinoffs succeed usually because they're different enough from the original game that they're worth playing for their own sake.

Besides, not everyone is going to directly modify the source code to come up with a new game. I, for one, am interested in looking at the physics and the game engine code, but if I used it, it would be to create my own original game.

So you're right in saying that the world only needs one N. And in the weeks after the source is released, you might see a couple of pathetic clones, but just ignore those and they'll die very quickly. But keep an eye out for the good ones.
