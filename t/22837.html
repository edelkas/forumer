I haven't seen any other threads for setting up collaborations (open invitation ones, anyway), so I figure I may as well start it. If this is in the wrong place, feel free to move it (mods).

Putting it simply, I've made quite a few maps on my own, and would like to try working with someone to make a map. (I figure that the resulting map will likely be better than one made "on my own", so to speak; two heads are better than one and all that.) I figure we'd mostly work together through pm, modifying each others work until the map is perfected. (First, admittedly, we'd have to figure out rough basics for the map, but that's for later.)

Anyway, long story short, I'm looking for a mapmaker to collaborate with, and would rather do open appeal than pm-ing a small horde of people into irritation until one accepts. However, I'm also plotting to set this up as a mapmaker matchmaker service of sorts for collaborations, so I'm going to lay out those rules below:-

Rule 1: If you want to be on the list of available people, please include (in bold) the words "Willing To Collaborate : X: TYPE". X in this case is the number of people you want in the collaboration (so 2 for a partnership, 3 for a trio, etc.) TYPE is whatever category the intended map you want to do is going to be (so action, race, puzzle, etc.) This is mostly so that I can find you easier (and so can other people). You'll then be put on the seeking part of the collaboration list.
Rule 2: If there's someone you want to collaborate with who has posted, include (in bold) the words "Want To Collaborate With UserX" where UserX is whoever you want to collaborate with. They will then be removed from the list of active collaborators. (I'll probably do this with a strikethrough and the other collaborators in brackets on the engaged part of current collaborators.)
Rule 3: When you've finished collaborating, it would be nice if you post to say that you're done. If you want to do another collaboration, just add "Willing To Collaborate : X" like in Rule 1. If you don't, put "Finished Collaborating" in bold. If you want to put up a link to the map or post it as a text file as well, feel free. I'll also move you to the "Completed Collaboration" part of the listing.
Rule 4: When posting to collaborate with someone, you'll be operating on a first come first served method. This is mostly for reasons of fairness.
Rule 5: Rather than trap people, if it goes a week without anyone in the collaboration pm-ing each other, then you can assume that the collaboration is "off", and you can post here to be put back onto the active searchers list.

Also, just so I don't break my own rules: Willing To Collaborate: 2: action.

Finally, a mini pledge: I'm going to try and keep this updating regularly. I'm aiming for a minimum of once per every two days.

Since we seem to be building up a list of people looking to collaborate without any having actually found partners, I'm going to add a new bit. If you've put yourself up as looking for a collaborator and then someone else comes along, feel free to post saying that you're going to collaborate with them instead.
