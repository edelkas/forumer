#166162 6 2006-04-18T13:52:04Z Raigan
oh, i see -- flash doesn't really have support for "skinning" or skeletal animation, but at the same time it sort of does since it supports a hierarchy.

for each rigid "chunk", you just need to make sure that the origin of the chunk is the pivot point you want the graphics to rotate around, and you can build the graphics that way.

this is how we authored the animations: once all the chunks are setup, you can select multiple chunks and set a pivot point -- for instance, we would select all of the upper body chunks, set the pivot to the waist, and rotate the upper body around it.
