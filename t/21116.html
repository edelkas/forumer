Spoiler: Rules, Please Read Before EnteringThese are some rules you must follow for your map to be judged.
1. All maps must contain an image
2. All maps must be submitted to NUMA
3. All maps must contain some kinda of tileset
4. All maps must have a MWIC tag on NUMA
5. All maps must be linked to this thread
6. All maps must have only one author
7. All authors must post a link in this thread to their image
8. Have fun
9. Don't submit an inappropriate image with the map

Does the image fit and look good / 15
Does the image influence the map or change anything about the map / 20
Does the image make the map more fun, and is the map fun / 15
Is it not too easy or hard, difficulty / 7
Gameplay, is it good, good flow, etc. / 12
