#32663 4 2004-10-19T05:19:38Z LittleViking
You are just telling him how to save demos and levels from Ned. I think he means the main game save file.

I could never find a way to do it automatically, but you can still copy the file manually. Search for "*.sol" files with hidden files included in the search, and you should find a "n_v13b_userdata.sol".
Copy it to your thumbdrive,
take it to the other computer,
open and close N (to create a save file on the other computer),
search for "*.sol" files again,
and finally, replace the file with the one from your thumbdrive.

Hope that helps.
