I'm proposing a compromise in light of the very few but very adamant people who think that Nreality and NUMA should not be associated with each other.

As of now, when you click the Maps tab in the navigation bar on NUMA you get the following tag options:
+playable +action +puzzle +race +dda +n-art

Here's my idea:

+playable +action +puzzle +race +dda +tileset +n-art +nreality +imagemap
-playable -action -puzzle -race -dda -tileset -n-art -nreality -imagemap

As you can see, it would include BOTH tags for the more common tags. People would then be able to view common map types without having to type in the map type in the search box. People could include the maps types they want and do not want to see.

This is poll only, because I don't want people bickering back and forth about Nreality and NUMA. Just voice your opinion with a simple vote please.

#453039 18 2008-07-15T17:30:25Z southpaw
As far as I'm concerned, checkboxes are a bad idea.

It used to be that you had to choose what type of map (action, puzzle, survival, DDA, etc.) your submission was before you could continue. When I first started out on NUMA, that was confusing to me. I had no idea what an action map or a puzzle map or a race map should look and play like, so I had no idea what to choose.

If anything, Nreality tags, if added automatically, should be added via basic code at the end of the map. Or for imagemaps, maybe a check on the URL so as to make sure that it is a valid URL. I don't know how hard these would be, but for those just beginning N and NUMA there shouldn't be something that they can choose for themselves. Rather Nreality should be something that is a part of NUMA, but not to the extent that anybody could check a little Nreality checkbox when they have no idea what Nreality is.

Code recognition and URL verification is the best way to ensure that all player/drone mods and image maps are accounted for. As far as difficulty in the coding process, I have no idea how hard it would be. But to me this seems like the best way to prevent abuse of people checking the Nreality checkbox (such as those trying to make statements about Nreality and NUMA) but allows Nreality maps to be easily found with the tag suggestion from the first post.
