Floor Guardian (Floor Guard Upgrade)
http://nmaps.net/136671

Restart NReality (a mod of N, download @ n.infunity.com) to retrieve this new update of Floor Guard upgrade

Guards:

4^x,y,1^type,speed,alwaysChase

Floor Guard : 4^x,y,1^0
Ceiling Guard : 4^x,y,1
Left Wall Guard : 4^x,y,1
Right Wall Guard : 4^x,y,1

alwaysChase: default 0, set it to 1 if you want it able to always chase the ninja

Examples in this map:
floor guard:
!4^36,234,1^,,1
ceiling guard
!4^756,186,1,,1
