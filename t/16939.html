#314241 7 2007-04-19T12:52:22Z Loller
Yo.
Auf deutscher keyboard, die tasten sind anders. guck hier
~ = ^
Insert = einfgen (einfg)
Home = Pos1
Pgdown = bild v
pgup= bild ^
was schei mit deutscher keyboard ist, ist das man kann nicht [ und ] benutzen, weil man Alt Gr
drucken muss, die der N-game gar nicht versteht, also man kann gar nicht "One-Way Platforms" oder "Exits"
nutzen. Voll schei
der beste dass du machen kannst ist das: wechselt den keyboard-einstellungen auf US. dann kanst du alle funktionen nutzen.
so ist das gemacht:

Start -> systemsteurung -> Datums-, Zeit-, Sprach-, und Regionaleinstellungen -> Weitere sprachen hinzufgen -> auf Details... clicken -> Auf Hinzufgen clicken -> English (USA) Auswhlen -> Auf OK clicken -> Englisch (USA) aus der liste doppelclicken -> bernehmen clicken -> OK clicken
