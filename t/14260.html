To be specific, you want to add the level data to your userlevels file, in the n folder. The easiest way is just to add it to the end of the existing file, although you may want to preserve the integrity of the original file by renaming it, copying its header into a new file (forgive me, I don't want to look up what the header is...) and then copying the data into that file from the text boxes in ned/debug mode.
