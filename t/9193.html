what makes a computer run "fast"?
It depends what you are doing.
Okay if you are running a modern 3D game, you'll want at least 1 gig of ram and a 256 (minimum) MB graphics card that's less then 2 generations old. NVidia 7600, or ATI x1700.

For a game like N though, it's not exactly how fast your processor is (though this is important), it depends that your machine is running as efficiently as possible. This means; no spyware, viruses and malware running in the background. Any program running that takes CPU cycles will interrupt the flash projector(player).
Having dual-core/Hyper threading is awesome when running flash games, as your desktop stays responsive and you don't get (as many anyways) hiccups in the game.

Hard drive: The more space the merrier, but having a bigger harddrive will NOT increase the performance of your games. Having a faster spinning harddrive will. But only on hard disk access, like when loading a level or resources while playing.
Having a bigger cache on the hard drive will help tremendously. It's not uncommon to have a 16MB cache on the newest hard drives and 8MB is pretty much the standard now.

Same thing with memory, sure having more is nice, but having faster running memory (DDR is standard and 400 MHz is pretty much standard now) will help alot more as you access your memory all the time.

Anyways, hope this helps
#193980 28 2006-06-24T18:59:13Z Templex
For the case of improving N performance...
If N is software-rendered, which I think it is, then the major factors are your CPU clock speed, memory if you have very little (512MB or lower), and of course things that bog the CPU down such as malware, spyware, viruses, adware, and worms. Your graphics card doesn't matter much, since as I said, N is most likely software-rendered. And hard drive space doesn't matter either for performance, because N is loaded from the hard drive only once, and the parts used are copied to memory, therefore the hard drive is not used while you're playing N, but only when you: 1. open it, or 2. load a map (possibly)
