each archive has _2_ different executables; please let us know which runs "better" (most smoothly, most CPU-friendly, etc.. please let us know if there is any significant difference between the two)


Prominent new features include:

-completely revamped network code; previous bugs prevented highscores form being automatically uploaded a lot of the time. now, you shouldn't have to use the "submit" button as much

-related to the above, the submit button now works a lot better

-combined highscore+timetrial mode, which will hopefully make things a lot more user-friendly for speedrunners

-mainmenu demos are now properly random/shuffled

-150 new levels, including 50 new user-made levels

-the ability to skip levels while in practise mode


Absent from this release are a few very important features, specifically:

-filesystem support
-support for custom/user levels and replays
-improved Ned

However, we haven't cut those features, they simply aren't yet finished.

We spent two weeks trying to get filesystem stuff working. We did get it working 4 different ways, however none of our solutions were good. The purpose of getting access to reading/writing files was to make it EASIER for users than the current textbox-based input/output. All of our solutions were far more difficult and awkward, for instance the user would have to run a seperate program when they wanted to save/load..

Unfortunately, instead of giving up when it was clear that it wasn't going to work, we kept trying different work-arounds and thus wasted much of our time (well.. it was only a waste in hindsight since we eventually had to accept that it just wasn't going to happen). Thus, some of the most important features of 1.4 are still unfinished.


We intend to get user levels (including some amount of integration with NUMA) and Ned improvements finished ASAP, hopefully by the end of the weekend.

Another feature which we intend to include is the ability to save/load your progress as text; this is meant to help people who play N on multiple computers, as well as enabling "backing up" of save data, since (sadly) .sol files are so easily messed up.


Anyway, we're releasing this version now because (a) we need beta testing to make sure the changes we've made thus far are good, and ( we didn't want you to have to wait forever.


Regarding the user levels: choosing these was _very_ difficult for us, because there are something like 5000 maps in NUMA, and a lot of them are very good. We attempted to represent as many different styles and authors as possible, while still making sure the episodes were playable.

Sadly, we couldn't include DDAs for technical reasons. However, when we get user maps working, N will "ship" with a selection of our favorite user-made maps which didn't make it into episode-mode.

Regarding the new "level skip in practise mode": this feature is controversial for us, since a lot of the reward of beating a level in N comes from unlocking the next level. While we didn't want to ruin this, we _did_ want to let less-skilled users see later levels, especially from the user-made column: the user-made levels are so hard that it's conceivable that many users might never get past the first user-episode. Of course, cheating disqualifies you from highscores and personal bests until you beat the levels "for real".


We've also fixed several small bugs and annoyances.


Anyway, please let us know what you think.

thanks,
mare and raigan
