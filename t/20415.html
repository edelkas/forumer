this is for absolute beginners, never seen an HTML guide in their life.

for this you'll need

1. patience
2. basic text editor such as notepad, word will not work
3. a picture editor such as photoshop, if you don't have that download Gimp
(this will be for making the background and buttons and such)

ok lets go on in!

first open notepad (start, all programs, accessories, notepad)

oh yes i forgot, HTML stands for Hyper Text Markup Language, they say that in all the books so i thought it was important, i have never said Hyper Text Markup Language in my life though, just say HTML.

to start the code type <HTML> this says it will be a web page then his enter (return) and type </HTML> the / says that its the end of the web page. next, inside the two tags you just put, write <HEAD></HEAD> this doesn't do much yet but the head tags will hold java script and such. inside the 2 HEAD tags put <TITLE></TITLE> then write inside them "my cool web page". this is what it says on the top of your browser. so it should look something like this

<HTML>
<HEAD>
<TITLE>
my cool web page
</TITLE>
</HEAD>
</HTML>
you don't have to do the spaces, it just organizes it better.

next, between the </HEAD> and </HTML> tags write <BODY> and </BODY> this is where the actual page goes. inside those 2 tags write "hello world" (this is a thing that all newbies have to write if their programing)



thar ye go

now save the notepad file in a file named "website" name the file "index" (index is how web providers know which page to put up as your homepage)



now right click on that file and select "rename" rename it to index.html.

it should now have an internet explorer look to it instead of the notepad icon. open that file. and it should look like this




now open that and it *should* look like this



now if your sitting there saying "aw man this is so stinkin' easy" then good, because as long as you remember this stuff you're set
~~~~~~~~~~

but now lets say you want to add a picture, first save the pic you want to add

how 'bout this one


ok right click 'save as' name it "pic1.jpg". (without the"'s) save it to the same place as your index file. if you don't do that then the page won't know where to find the picture.

now change the name to index.txt again and add this in between the BODY tags, where ever you want it.

<IMG src="pic1.jpg"> thats it!

well not completely

<IMG src="pic1.jpg" width="100" height="100">

the width and height tags are in pixels, if you want it to scale bring it into gimp (or photoshop) and scale it down and see how many pixels that is. (if there's an easier way tell me)

so say you want it bigger than that, <IMG src="pic1.jpg" width="300" height="250">

taa daa, not too hard is it?
~~~~~~~~

now adding links is just like pics, but instead of <IMG src> you put
<A href="html://numa.notdot.net"> [/CODE]then inside you have to put the text, so put "numa", it will look like this

<A href="html://numa.notdot.net"> numa </A>

so now you got yourself a link to anywhere you want, oh noez but wait! what about links in your own site?!?! just do the same thing but <A href="index.html">back home! </A>

there easy

html is weird in a couple of ways

1. it doesn't make more than one space without a special code (i'll tell you later)
2. it doesn't make breaks in pages (like when you hit enter (return)) without special code (i'll tell you later)
3. um well there's another way to do the enter thing, like to make paragraphs (i couldn't come up with how thats weird)

ok so to make more than one space you type   so even if you make 1 trillion spaces, it will only make one space unless you write   1 trillion times.

to make the break you write <BR> that makes it do the same thing enter (return) does. to go more than one space down type <BR><BR>

another way to separate paragraphs without typing <BR> 100 times is to write <P> </P> thats a paragraph, it will automatically separate anything between those tags and make them paragraphs.
~~~~~~~

now this is where the photoshop/gimp comes in the background.

now depending on what you want ie. just a plain color background, a tiled background, or one picture. you will use almost the same code

now go up to the <BODY> tag and change it to <BODY bgcolor="blue">

that changes the background color to, you guessed it, blue!

now do the same thing but instead of typing bgcolor just type bg

<BODY bg="picture.jpg">that makes it a picture for the background (change picture to whatever you want it to be)

tutorial #2
Javascript

I enjoy javascript for a couple of reasons, first its easy, second it loads with the text instead of it being another aplication that has to load by itself, plus if you do it right it adds good functionality to your site.

I am now going to brainwash you, if you know java but not javascript and think "hey their going to be exactly like java" I want you to take a book and bash your head many times over saying, "their not the same". well mostly because their not. the only similarities between java and javascript it the J-A-V-A bit. *exhale of relief* now, doesent that feel good?

onward.

if you didn't understand the part where i said "java loads with the text" this is what it means.

JavaScript is 100% text, just like HTML is. Therefore it loads quickly from the server to your computer. JavaScript runs on your computer and does not have to download any additional applications to do it's job.

(i just copied and pasted that bit.)

BEWARE overusing of javascript in a way that does not add functionality to your site will just annoy visitors, don't just use this stuff to be cute, its not!

now lets learn the code.

<html>
<head>
<title>My first javascript</title>
</head>
<body>
<h1>Our First Script</h1>
<p>Today is
</body>
</html>

(i didn't explain it in the last tutorial but the <h1> tag means its heading sized one)

now your looking at this and you think "hey an unfinished tag!" well that was done on purpous you'll be adding more. now i advise you to not just copy and paste this but to type it yourself, this will forever burn this stuff into your mind.

to start off javascript you first have to tell the browser that your using javascript

so after "today is" write <script Language="JavaScript">

then write "var today = new date()"
without the"'s

document.write(today)

this tells the browser to write the date and time

then end it with </script>

it should look exactly like this

<html>
<head>
<title>Our First Script</title>
</head>
<body>
<center>
<h1>Our First Script</h1>
</center>
<p>Today is
<script Language="JavaScript">
var today = new Date()
document.write(today)
</script>
</body>
</html>

if it doesent, change it.

if a person doesent have a new enough browser, it wont display javascript. so to not show javascript to old browsers simply write

<script language="JavaScript"><!--

(code)

//--></SCRIPT>
