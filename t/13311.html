Welcome to the N Wiki Level Article Project (aka the NWLA), where our mission is to create an article for each level of N in the N Wiki. First of all, let me state the overall goal of creating these level articles:

We want not only to provide information on each of the levels in the game, but to essentially recreate the N Episode Help Site and Thread (NEHS and NEHT) here in wiki format, so any player that needs help with a level can simply be referred to that level's article.

We will be splitting into two groups. One group will be doing screenshots, and the other, walkthroughs. Pick whichever one you want to be in. I will be creating the basic framework for most of the level articles. But if you're doing an article that hasn't been created yet, just type in {{subst:Level}}, and then once it's been created you can add the screenshot or walkthrough you wanted to post.

pokemaniac1342
RincewindSW

Guidelines for Walkthrough Group
  • Please use walkthroughs from the NEHS, NEHT, or AEW whenever possible, simply because it makes your job easier and get things done quicker.
  • Please use a semiformal style when writing your walkthroughs.
  • Specify the subject matter of each walkthrough (i.e., completion, gold, speed, highscore).
  • Try not to be overly biased or refer to yourself within the walkthrough.
  • When copying from the NEHS, NEHT, or AEW, please site your source (look here for an example).
  • Feel free to edit any walkthroughs you've copied from the NEHS, NEHT, or AEW whenever necessary to comply with these guidelines and maintain the consistency of the other level articles.
  • If you'd like to add a screenshot with arrows and other indicators added as a visual aid for your walkthough, feel free to do so, but don't put it where primary screenshots normally go. The reasons for this are that (1) walkthroughs are not the only purpose of the level articles and (2) there may be more than one walkthrough for one level article, which would make things considerably more complicated.

Guidelines for Screenshot Group
  • Follow these instructions, courtesy of Scott5114:
    Take a screenshot, crop it, and save to your disk, preferably as a PNG. Don't resize it. Go to the page Special:Upload. Tell it where to find the file on your hard disk, come up with a name for it on-wiki (usually the number of the level is good - e.g. "88-4.png"), and add a description. Once the file is transferred you can get it to appear in an article by passing the name of it as the "image" parameter for the Infobox Level template. It will be resized automatically to fit, and a user can click the image to view the original version. If you put [[Category:Level screenshots]] in the description field, it'll appear in that category, which I can see functioning as a level gallery of sorts.
  • Please post primary screenshots in the indicated section of each article. It should read: |image = [Insert name of uploaded image here]
  • If you'd like to add a screenshot with arrows and other indicators added as a visual aid for a walkthough, feel free to do so, but please display them elsewhere on the same page as the primary screenshot. The reasons for this are that (1) walkthroughs are not the only purpose of the level articles and (2) there may be more than one walkthrough for one level article, which would make things considerably more confusing. Use the following format:

    [[Image:Walkthroughaid.png|thumb|270px|Right|Description]]

    Add the name of the screenshot where it says "Walkthroughaid", and a short description identifying the pic where it says "Description".
