N.U.D.A.: N User Demo Archive
An addition to NUMA

Many users enjoy watching fast demos, as well as stylish ones. Hence the spawning of NTTS and other, smaller high scoring competitions. Not only is it fascinating to participate in high scoring competitions, it is entertaining to some (me, at the least) to watch quality demos.

I suggest an addition to NUMA in which demos to any NUMA level can be posted, as they are now, except given ratings and assigned to the user that posts it.

This opens up many possibilities for DEMO LISTINGS:

1. Top-Rated
2. Browse by Newest
3. Search by User
4. Top-Rated User

[/color]It could also allow for USER CUSTOMIZATION:

1. Manage/Monitor Self-posted Demos
2. Create Favorites List
[/color]
I am sure more useful applications exist, but these seem the most prominent.

Thoughts? Again, I cannot tell how difficult this would be to implement code-side; it's just a suggestion.

Allow me to clarify my idea on how this could be implemented. The most obvious way to submit the demo is as now; go to the page and the server associates the map with the demo. The demo would be submitted to a different archive that links back to that map.

An easier way to submit demos would be to release the map as well as the demo. One potential problem with this, however, would be holding people accountable for properly crediting the map to which their demo belongs.

Make sense, 99? You would need a map associated with the demo the instant you send it to the server.
