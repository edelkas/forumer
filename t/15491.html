#290570 2 2007-01-27T17:47:12Z Twistkill
Sure you can. You must beat the first episode in a column that have the white box around them with practice mode off. For example, if your sister cheated on episodes 26-29, you must make sure you have personal bests for episode 25. (You never said which episodes she cheated on, so this is just an example) Go the highscores menu, click the episode, and make sure you have personal bests for all of the levels in that episode in the upper left hand corner. Then, go to the configure menu, turn practice mode off, and start completing the episodes that were cheated on.
