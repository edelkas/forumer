#210349 6 2006-08-02T11:49:56Z LittleViking
End some processes and see if it shows up again. Go to Task Manager and kill anything that wasn't started by SYSTEM, LOCAL SERVICE or NETWORK SERVICE. If for some reason a program is covering or hiding it, that should make it visible again, and then you'll know what the problem is. Also, start up in Safe Mode (F8 at the Windows boot screen) and see if it's visible in there. Safe Mode starts with only the most basic services, so onec again, if a program is hiding it, it should be okay there.

Report back here afterwards.
