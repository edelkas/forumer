#258713 2 2006-11-24T00:58:52Z Atilla
To make a thwump move backwards, you should place it one-pixel less than halfway inside a wall, facing that wall. I find that the easiest way to do this is to use x-snap to place one halfway inside a wall, then go through the level code and change the number for the thwump's position by one. Thwumps have code of the form "8^767,564,0" where 8 indicates the object is a thwump, the first number is the horizontal distance from the left of the map, the second is the vertical distance (from the top of the map, for some reason) and the final number is the direction the thwump is facing. All you need to do is reduce or increase the horizontal or vertical position by one, depending on the direction the thwump is facing. The code above is for a glitched thwump at the bottom of the map, embedded in the right-hand wall, for instance (it was 8^768,564,0" before I edited it).
