#291173 8 2007-01-28T23:53:32Z iangb
OK.... I can make this (for example: 'space invaders' much better, very easilly.

For example, you can replace all the code in collision.bas with this, which will account for every possible collision between o1 and o2:
Public Function coll(o1 As Object, o2 As Object)
    Dim result As Boolean
    result = False
    
    if (o1.left + o1.width) > o2.left and o1.left < (o2.left +o2.width) then 'horizontal collision 
          if (o1.top + o1.height) > o2.top and o1.top < (o2.top + o2.height) then 'vertical collision
               result = true
          end if
    end if

    coll = result
End Function
