#250491 2 2006-11-05T20:47:19Z Twistkill
Very common problem which is easily fixed.

What you must have done is moved N somewhere outside of that folder that it came in. A way to make N easily accessible without this happening is to create a shortcut in your desktop, but you must leave the original copy in the same place as your userlevels.txt folder or else nothing will show up.
