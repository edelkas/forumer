Quote: Atilla, January 12, 2008 10:09 pm
Check that userlevels.txt is in the same folder as the N executable.

To create further clarification, this is very important. When you unpacked the .zip file that N came in, be sure you leave the original N.exe and the userlevels.txt in that folder. If you wish to have convenient access to them, create shortcuts and place them on your desktop, Quick Launch bar, et cetera. Alternatively, as long as the original N.exe and the userlevels.txt are in the same directory, such as the desktop or any other folder, it will still work fine... but I recommend the shortcut method, just to be safe.
