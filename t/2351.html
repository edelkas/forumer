Heres a few comments. Im working on a few assumptions as its impossible to know how your doing it without the source.

- First of all I wouldnt use the line and shape control (Your useing them right?). I would just use form1.line to make the line. And for the player form1.circle.
- You need to have a backbuffer. You do all the drawing onto that and then bitblt it onto the form that the user sees. It means that there isnt any flickering.
- I would make it so the ball cant leave the form.
- I wouldnt use the timer. This is because the maximum speed it can work at is about 50 ms.
- The collision detection system although awesome probably needs changeing a bit.
