Drain me up (Greedy Drone)
http://nmaps.net/133855

Restart NReality (a mod of N, download @ n.infunity.com) to retrieve this new update of Greedy Drone

Greedy Drone:
6^x,y,Path,0,141,direction^speed,chase_speed,collect_coin
Greedy Seeker Drone:
6^x,y,Path,1,141,direction^speed,chase_speed,collect_coin

For collect_coin:
value for stealing 1 second = -40
value for stealing 1 frame = -1
value for giving player 1 second = 40
This value must be an integer

Greedy drone -> specialOn -> seeker Greedy drone
seeker Greedy drone -> specialOff -> Greedy drone

Updates to Zap Drone & Rocky Drone
Zap Drone:
6^x,y,Path,1,0,direction^speed,chase_speed
Rocky Drone:
6^x,y,Path,1,121,direction^speed,chase_speed

So you can also set chase speed for zap and rocky drone now

Also for rocky drone:
rocky drone -> specialOn -> seeker rocky drone
seeker rocky drone -> specialOff -> rocky drone
