Ok, you can play them in the level editor or put them in your userlevels text.

To play them in the editor simply press the "`" key which is found in the top left corner of the keyboard, that will take you into debug mode.
Now paste the data into the level data box, click the cursor outside the box, press "L" to load the level and "P" to play it.
Make sure you have capslock switched on.

To play them in userlevels mode you have to find the text file named "userlevels" (It will be in the same folder as N).
Then you need to scroll to the bottom of the file, paste in the data, and save the changes.
Be careful if you mess around with the syntax or the text up the top because you could mess it all up.

Hope that helped.
