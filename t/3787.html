#93200 16 2005-08-22T15:23:26Z shoftee
You can do that in just 3 lines:
onClipEvent(enterFrame) {
this._x += (Key.isDown(Key.RIGHT) - Key.isDown(Key.LEFT)) * 2;
}

If you're pressing right, the result is 2:
(1 - 0) * 2 = 2
And if you're pressing left, the result is -2:
(0 - 1) * 2 = -2
If you're pressing both, the result is 0:
(1 - 1) * 2 = 0
