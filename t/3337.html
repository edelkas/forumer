#69627 6 2005-05-26T06:06:27Z Raigan (guest)
well, for SURE this one has got to be in there: noiz2sa, a shooter by kenta cho

possibly some of kenta cho's other games would be useful.. A7Xpg is strange-looking and a fairly unique sort of game, and parsec47 is cool because every level is unique and randomly generated.

i guess it really depends on what you're saying in the paper; some other interesting games are:

spout, a tiny 1-bit-graphics homage to the "cave flier" genre.

warning forever, a vertical shooter made of endless boss fights, where each boss is generated using genetic algorithms which adapt based on how you beat previous bosses.

a2k, a minimal vector-graphics arcade-shooter game.

seiklus, a strange abstract action/adventure "game", where you mostly just run around and explore the world.

iteration games have several interesting/weird games.

flapflapflap, a strange classic-yet-modern game with abstract graphics.

UFO, a very simple and yet quirky sumo-ufo-wrestling game.. the aiming is handled in a unique way.

every extend, a combination of vertical shooter and puzzle game.

klass of 99, a remake of a very old game, which is sort of.. an adventure game stuck inside a school simulator.

medieval clash, a strategy game that's simple to play but fairly deep.. or maybe i'm not very good at it.

frontline, very abstract stickman war game..

puchi, stickman puzzle-platformer (a big inspiration for N).

hope this helps

#69840 13 2005-05-27T01:27:37Z syntax
And tktktk,

If you're researching graphic art throughout the times i advise the following (incomplete) list):

Pacman -> first game using non grid sprites
Major Motion -> first upward scrolling, non random racing game
Double dragon-> first "pseudo 3d" 2d area
Dungeon Master -> first real-time immersive 3d vision of a 2d plane
Another World -> first polygon-based one man adventure game using video to film his brother to work out the sprites [forgot the term but same idea behind Flashback]
Voyeur -> on the [Jaguar ?], first to use FMV in a game
7th guest -> One of the first games to come out on CD, and the first ever to use 2
Ultima underworld -> first ray traced real conversion into 3d
Doom -> first fluid based 2d->3d conversion (first real 3d engine)
Riven -> 7th guest/Riven (?) taken beyond game play and becoming an artists game
Cadavar -> first 45 perspective adventure game
Little Big Adventure (1 and 2) -> first free roaming graphic genius
Chaos engine/Ultima 7 -> first 72 degree perspective action game

The above part of the thread will substantiate the rest graphic wise... but if you want history, there it is
