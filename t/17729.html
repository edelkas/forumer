#329255 2 2007-06-09T17:43:02Z ZeroTruths
Ok, I found th problem, but first, i do realize that I'm double posting. Think of this as the answer to the question above.

Anyways, I found out that while a Mouse Event can be added anywhere in the movie, a Keyboard Event can only be added if it's being added to the Stage object. If it's added anywhere else, the Keyboard Event will not register. If you want to declare a Keyboard Event within a class that isn't the Stage, then using the parent property will allow you to eventually reach the Stage class from within the current class.
