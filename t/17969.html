I'm pretty sure most MetaVeterans remember the classic One-Life Challenge. Such side-challenges such as this should be thrown in N+ and N 1.5, just for the toughness aspect. I wish to revisit this challenge, but this time, make it official.

Other ideas:

30min/1hr/2hr Endurance Time Trials - Complete as much of the game (in order) in one sitting before time runs out.
100% Endurance Time Trial - Finish the ENTIRE game in one sitting as fast as possible.


The part of N that pushes the game onward (besides level making, obviously) is the challenge. Making this game have tough, tough modes presses the replay value up.
