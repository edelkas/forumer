I'm not sure if this is actually a good idea, but I'm going to throw it out there because it's interesting. I don't think the whole thing has been suggested before, although some parts of it have.

What I'm suggesting is that there be an option to prevent anyone else seeing the ratings on your map, as is currently done for maps below five votes. This would be a compromise between the current rating system and the option of disabling ratings altogether.

What's the point of ratings if nobody else can see them? It's a quick and simple method for the author to get feedback. It may also improve the accuracy of the ratings you are getting. For a start, there will be less incentive to snipe - nobody else is going to see the results, it won't affect the all-authors list, and the author will just dismiss the offending vote anyway*. It will also prevent the more subtle effects of people being swayed by the existing score.

Basically, this option considers ratings to be a tool which helps authors to improve their mapmaking, rather than as a way to gain fame, or a way for the general populace to find good maps.

*A list of votes, which has been suggested several times, could aid in this. However, I don't think it's really necessary or even desirable. eg.
0: 1 0.5: 0 1: 0 1.5: 0 2: 0 2.5: 0
3: 1 3.5: 3 4: 2 4.5: 1 5: 0 Av: 3.5
