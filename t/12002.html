#217508 4 2006-08-20T10:19:15Z LoD
It is like a file manager, but for the Windows Registry consisting of keys (=folders) and values. It is used by Windows and programs running on Windows as a storage for global information, for example DLL locations, devices, file associations, etc. You can add new keys and values, and delete and move existing objects. Also, I will provide a search function running in the background (using multi-threading).

Icons for registry editors always look very similar. The left icon is used by Windows (there's a sheet in the background because it's the icon for registry backup files), the right icon is used by the TuneUp Registry Editor provided with TuneUp Utilities. As you see, the right one is only a nicer variant of the original one at the left.
