#194047 3 2006-06-24T21:31:33Z lord_day
Well, here I am sharing out my secrets . I actually was told this in another topic I started .

The way I made that level was quite complicated, and I had to use microsoft word. I'll give you some step by step instructions (the punctuation in quotation marks is what you actually use, not punctuation)

1) build the whole tileset, putting an obscure tile where you want the fake tiles to be later. I used the quarter circles that point down to the right. ( the S under 8).

2) Take the level data so far, making sure there are NO objects, and paste it into Microsoft word. Then press ctrl F and use the replace function to replace every character that represents the obscure tile ( mine was '-') and replace it with a '.'

3) copy and paste the new data into the neditor box and load the level. There will now be blank spaces where the other tile was before. Pressing H before loading will fill these tiles but not put anything there.

This technique is very hard if you want to edit the tileset, but you'll manage.

What I've written is very confusing..... tell me if it doesn't work/ you don't understand.
