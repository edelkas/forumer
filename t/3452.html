Renaming a file to another extension changes nothing. Just because you rename your file to '.avi' does _not_ make it an AVI file. Programs that deal with AVI files will not understand it. Pretty much universally when someone is referring to a 'file type', they don't mean the extension, they mean the format of the file - the agreement on how to represent data in that particular type of file. Extensions are just a convention for indicating what file type a particular file is.

There is one *extreeeeemely* remote chance of n running on a PSP. The game Wipeout Pure has a web browser intended to download game updates and high scores and such. Wipeout uses the DNS settings in the PSP to find the update page; the really cool thing about this is that people have set up their own portals designed for the Wipeout Pure browser. All you need is a wireless internet connection and the game. Go here to see an example portal.

After this, there are two nigh-insurmountable obstacles:
1) embed the n "movie" in a webpage
2) find a PSP browser that supports flash.

Number one doesnt seem likely; R&M seem to like the external player for performance. Maybe after the source code is released.
Number two may be possible in the future. The Wipeout browser doesn't support flash, but I hear, however, that Sony is going to release a new browser on a UMD (but considering the feet-draggin Sony did with their hard drive I'm a bit skeptical).
