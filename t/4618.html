#94567 6 2005-08-27T06:12:11Z astro
Just put the code anywhere under the &userdata=, it doesn't matter where - directly under is probably easiest. The $levelname#authorname#comments#leveldata# is how you enter the code - type a $, then the name of the level, then a #, then your name, then a #, then any comments you want to put there, then another #, paste in the level code, and then type a final #.
