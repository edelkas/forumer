All right then...as far as I can tell, x, y, Path, and direction are redundant, as it just follows you.

Text array, as far as I can tell, is an array of string to use when triggered, separated by a colon. For example:

I like milk:No wait, I'm lactose intolerant

HOWEVER! That uses spaces and punctuation and such. That's not accepted. Instead, paste each clause into the escape.swf Nreality posted to convert it into URL-ese.

The correct code for that would be I%20like%20milk:No%20wait%2C%20I%27m%20lactose%20intolerant%0D

That above string would only show "I like milk" until triggered otherwise, I think.

Align seems pretty self explanatory, in reference to the object you're aligning it to.

Border also seems clear, it's a simple boolean, 0 = false, 1 = true.

Textcolor & Backgroundcolor also seem simple, it's just a hex RGB value for either one. 000000 would be black, FFFFFF would be white, FF0000 would be red, etc.

Font: Choose from the three, I think. Might be more than that and he provided examples, but you should probably just stick with the default if it can cause problems as mentioned.

bold, italic, underline, are more simple booleans. Put a 1 in the correct spot to get the effect.

SpecialOn/SpecialOff, see his other map which implements these functions.



I'm probably wrong about some things, and left out other things. Anyone want to help me out?

#460531 63 2008-08-14T15:01:59Z Meta Ing
If you just want them to move side to side and up and down, why don't you just use the custompath? (eg.1^396,300^^^LLLRRR,6,,1)

However, if you really want to use coordinates, (say, to make the bounceblocks move in less than one tile increments), you would do something like this:

1^396,300^^^396.300:436.300,8,,1

The blue numbers represent the X coordinates, and the red the Y. Each coordinate corresponds to z snap, so you may want to use mouse keys to determine where the exact coordinates are. Seperate the X and the Y by a ., and seperate each coordinate by a :.

Hope this helps.
