#55585 2 2005-03-23T21:44:55Z Guest
hi,
this is a really hard problem to solve "right". we just project the ninja out of things one at a time, which _usually_ ends up converging on the best solution. it does create a sort of "squishy"/soft feel, try dropping the ninja into an acute pit and you'll see what i mean.

if you look at the source code for our second tutorial, you can find out how this really works; as far as i can remember we just find all the tiles touching the ninja and push the ninja out of each one individually: http://www.harveycartel.org/metanet/tutori...B.html#section5
