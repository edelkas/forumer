#68110 3 2005-05-20T11:58:05Z shoftee
Ok.... the quit thing is:

fscommand ("quit", "true");

and... the right-click menu (or also called a context menu) is a bit more difficult.
The problem is that you can't "disable" it completely.
The only thing you can do is shorten it a bit 

fscommand("showmenu", "false");

That removes all context menu items except "About Flash Player..." and "Settings...". Now... if you want to put your own things in the context menu... that's a lot more difficult (well not A LOT, but I'm too lazy to explain )
