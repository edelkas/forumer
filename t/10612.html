AH Numa Map Downloader V2.0

Mission Statement: The point of this program is that it's designed for people like me who love NUMA, but hate having to copy and paste the mapdata into the userlevels.txt file, or into the editor in N, play test it, then decide if they like it, then copy and paste it into the userlevels.txt.

This program will download a specified number of maps from the numa website based on your search criteria, then you decide which to add to your userlevels.txt file. It offers a picture preview just like NUMA and includes all the maps' details like author, mapname, category etc.

If you like the look of the map and want to try it out, just select it from the list and hit the "Add Map" button and the map will be added to your userlevels.txt file. Alternatively you can add all the maps by hitting the other button.

Then just go into N and go to user levels and they should be there.

A perfect example of this programs use is if you wanted to download the 50 best maps of a certain category. Before with NUMA this was easy but then you had to go to each map and copy and paste the map data into your userlevels.txt file. Now you just have to hit a few buttons.
I just downloaded the top 50 DDA maps of all time in less then one(1) minute.

FEATURES ADDED: I have coded a download progress bar for the large preview images

BUG 001 FIXED: The Bug that wasn't firing the programmed events for the search criteria, has been fixed and a new version uploaded. This should work properly now. There is a problem with the new VS IDE that wasn't using the events that I had programmed, it was just ignoring them even though they were right there and it never complained while I was coding. This happened because I changed something in the GUI but decided to change it back later. The changes I had made didn't reset the way they were supposed to.

BUG 002 FIXED: The situation where even though all the maps had been downloaded when using the "Add All Maps", not all the maps were removed from the list, has been rectified.

BUG 003 UNRESOLVED: I have noticed a new bug here at my workplace. I have v2.0 of the .NET installed but for some reason the image previews (large and small) aren't the proper size. This isn't a problem with my code as these values are hard coded, but for some reason they aren't being used correctly. I will have to change the code to make it more flexible later.

BUG 004 FIXED: I have found that when using the "Add All Maps" button, the remaining maps aren't showing the proper data such as description and author etc. This has been fixed and as such the performance has increased as a side effect.

BUG 005 FIXED: If a map maker used a quote "" in the map title, then my program will parse it as; "e;. This breaks the N parser as N can't parse past this point in the userlevels.txt file. You can check to see if this has happened by opening your userlevels.txt file, hitting Ctrl+F, and searching for "&quote". If you find it, delete it and this should restore your user levels text file.


Remember when using ANY third party software, ALWAYS BACKUP your data that you don't want to lose.
