Quote: darkone, April 23, 2006 12:47 pm
Anyway, I won't modify N, but how are the maps put into the game? There's no document that has the map data on it.
The format of .exe and .dll files is called "Portable Executable". This format mainly consists of three areas: The import area imports DLL functions. The export area contains objects and interfaces other applications can use, including functions (for DLLs), icons, and other resources. The third area contains the machine code of the application and private data. The level data will be in this third area. Because changing this area will definitely corrupt the machine code, recompiling the source code using the new level data will be the only way.
