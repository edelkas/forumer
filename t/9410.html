hi, this is a program i made to distract myself from my AP test i had today (i made the program yesterday).

What it does:
it makes a maze then appends the level data to the end of userlevels .txt

what i mean:
this program creates a maze (either 20x9 or 20x23 depending on version) using an algoryth that always creates solvable mazes.
there are three flavors of generators:
1) 20x9 "blind" Maze maker (NmazeB20_09v1.exe)
2) 20x23 normal Maze maker (Nmaze20_23v1.exe)
3) 20x23 "blind" Maze maker (NmazeB20_23v1.exe)

by "blind" i mean that the walls of the maze are made of trap doors so that when you start nothing is visible, as you go the maze forms around you. (dont go too fast tho, sometimes trapdoors bite)
normal maps use oneway platforms

How to:
just copy the program to your N folder (must be able to run windows programs) then run it, type in the info for your level and check your userlevels for the level.

written in C++

personally, i think that program 3 is the hardest followed by 1 then 2

feedback appreciated

oh and just so you know the level sizes go in order of smallest to bigest (1, 2, 3)
