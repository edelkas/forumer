#298750 5 2007-02-18T23:19:50Z cyberjuda
Ah well. Lemme start off by congratulating the organizers i.e. spect, KinGAleX and krusch. You guys have been great. Thanks.

Now for some criticism. The map selection was good, but my idea for a map for NTTS is simple.

a) Completion

The exit switch and the door should be reachable even for a 'not so good' player of N. The purpose of NTTS is not to test the skill of completing the map. That is the basic criteria for entering the contest, so if people cannot compete because they cannot even complete the level. That sucks. In that respect I think there were a couple of maps included which I don't really need to mention.

b) Gold.

In my opinion there should not be gold spamming (duh). There should be gold placed in the maps so that there are different skill levels required to get each piece/bunch. This is what should be categorizing the skill levels of the NTTS player. How fast can you get each gold? How much can you get? That should be the underlying question for scoring. In that respect I think majority of the maps were very nicely selected, but still I think more concern was given to personal feelings, which can sometimes be good but can be pretty screwy too.

c) Tileset/Items/Enemies.

This is of course very hard to decide. My personal preference is a one which has lots of corners and ramps. The map should be open with tiles combined with items scattered to create opportunities for nice jump moves to be created. As I said, this is very hard to determine and cannot really be written in words. Items that are good for a NTTS map are bounce blocks and thwumps. Of course too many of them are in the end just boring.


I seriously hope that made some sense. Overall regarding this season, I would've liked to see many more mapmakers, but I guess it's hard to incorporate everyone in ten weeks.


Last but not the least, I think I'm not gonna get any better at N and NTTS. So with that I would like to say that this was my last season for NTTS and from next season I'm not gonna be competing. So in principle I'm retiring from highscoring. I would love to help out if I could though.
