Okay then.

Right-click the image you want to post and save it to your computer somewhere. Go here[/b] and upload the image. When you upload it, it will give you some codes. Go to the very bottom one that says "Direct Link to Image", then select all and copy it. Open your reply window, and type this:

[img][/img]

Then paste the URL you copied in between those tags, hit add reply, and you're done.

An alternate method that is somewhat faster, but only allows you to upload one thing at a time, is attaching an image directly to your post. Save the image you want by repeating the first step above, then open the add reply window. Underneath the text area is a bar that allows you to upload anything. Find the picture and then click open. The file path appears. Then hit add reply and you're done.

Actually, this can be a shortcut for all images instead of having to go through imageshack, but it may not work with some.

Go to the map you want. Right-click the thumbnail of the map that is shown and select "Copy image location." Then, come here. Apply the [img][/img] tags like I explained above, and then it will show the thumbnail of the map.

If you want to make that thumbnail clickable so it'll go to the map itself, do this:

[URL=*the map link*][img]*the copied image location*[/img][/URL]
