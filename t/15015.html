You would need to give your object in question a velocity vector, and calculate the sum of all forces applied to the object each frame. Forces to consider would be your jumping and movement, gravity, and friction. Then it is simply a matter of adding these forces to your velocity vector, which in turn is added to your objects position.
If your calculations are done correctly your object will rise and fall gracefully just like in N.

#281866 7 2007-01-06T06:17:52Z jtbandes
The way I do gravity in all the mini pointless games I make is to have an xvel and a yvel variable, and a gravity constant defined at the beginning. Each frame, if the up key is not held (or in N's case, if jumping has run out of time), add gravity (because positive is down) from the yvel. This way, you accelerate downwards. Don't forget to add xvel and yvel to your character's position each frame.

@Sephorith:
// Force of gravity.
var g = 3;

// Force of movement.
var m = 5;

// Force of jump.
var j = 20;

// Object properties (position and velocity).
var px, py = 0, 0;
var vx, vy = 0, 0;

// This function is called every frame.
function update() {
    vy += g;

    if(/* Left is pressed. */) {
        vx -= m;
    }

    if(/* Right is pressed. */) {
        vx += m;
    }

    if(/* Shift is pressed. */) {
        // Make sure the object is on the floor.
        if(py == 500) {
            vy -= j;  // Jump.
        }
    }

    // Update position.
    px += vx;
    py += vy;

    // Check for collisions.
    px = Math.max(px, 0);
    px = Math.min(px, 500);
    py = Math.max(py, 0);
    py = Math.min(py, 500);

    // Bleed movement (causes object to slow down);
    vx *= 0.95;

    // Draw the object at position (px, py).
    draw(object, px, py);
}
This probably isn't exactly what you wanted and the algorithm is crap, but hopefully it will get you started.
Instead of "bleeding" away the players movement abitrarily, it would be better to implement friction, and I have magic numbers in there for the boundaries which should be variables somewhere really.
I've also tried to keep it fairly "ActionScripty" so you can just paste most of it in (I made up the draw part, and there is no update() function in ActionScript as far as I know).

#282493 10 2007-01-07T17:00:53Z smartalco
heres a simple equation for just the gravity part (note: in C++ since i dont really know AS, but you should still be able to understand it)

int gravity = 2;
int velocity = 0;
int fall_max = -10;
int position = 100;

do while (*every frame*) {
  *check if character will hit ground or other object when falling*
    velocity = velocity - gravity;
    if (velocity < fall_max) {
        velocity = fall_max;
    }
  position = position + velocity;
}
