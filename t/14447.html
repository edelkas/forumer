GASP!! A HIDDEN MESSAGE!!

EDIT: Any plans for continuing this have been cancelled

*gasp* Another program.

This one's simple. I did it in less than an hour. It's still cool though.

EDIT: Now it's more than an hour

This program takes advantage of the thumbnail glitch on NUMA where 0'd springs appear as triangle tiles, but usually not snapped.

It can create cool effects because it renders the image EXACTELY like it would on NUMA with the enlarged image.

Current Tools:
Use of the arrow keys to move the mouse (very useful for making light-grey areas)
circle generator (oooooooooooooooooo)
clear workspace tool
compiling to map data (of course)
implode/explode tool
vortex tool NEW!
rotate tool NEW!
switch between fake tiles, gold, mines, and bounceblocks NEW!

Coming soon:

non-lag version
move tool
add springs, turrets, one-ways, door switches
Oh, and for the controls, READ THE README

Download link: http://www.box.net/public/9hb5ayyx5g

By the way, it only compiles the object part of the code (oops). You have to add it onto a blank (or not) map.
