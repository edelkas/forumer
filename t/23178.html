I believe this is the most revolutionary update I have ever made.

I mod N for real usage, I don't mod N just for personal favourite features. Try this map and you will understand

Play And Stop (Triggered Objects)

http://nmaps.net/131345

I implemented the Trigger Functions on the objects, so that you can play and pause individual object by touching the corresponding door trigger.

Restart NReality (a mod of N, download @ n.infunity.com) to retrieve this new update of Triggered Objects

To add "Trigger" to a door switch, append
^startTriggers(separated by "."),stopTriggers(separated by ".") to the door switch object (which starts with 9^ )

To make the object triggerable, append
^^waitForTrigger,startTriggers(separated by "."),stopTriggers(separated by ".")

For an example, the first line of drones can be started by the triggerID 1, and can be stopped by trigger ID 2
so their codes are
!6^180,180,3,0,0,2^^,1,2!

The door switch which starts it has the code of
!9^228,276,0,0,27,11,1,-1,0!
and the door switch which stops it has the code of
!9^228,240,0,0,2,11,1,0,0^,2!

The boo is initially stopped, and can be started with trigger ID 5, so it has a code of
!6^756,276,3,0,101,2^****,5!
