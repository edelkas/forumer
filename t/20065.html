Hey Everyone,

This is the forever-awaited Request topic, where you can request a composer, performer or editor.

If you have composed something for someone, start a new topic for it.
If you have performed something for someone, post it in that topic.
If you have edited someone's composition or performance, post it in the original topic.
Also, please put a link to that topic/recording/edit here!

Below are some recommendations for requesting a composer, performer or editor. I advise following them, or it will just lead to more questions.

Note: Please state what you are requesting, as well as the below.

Requesting a composer:
  • Your instrument
  • Solo or accompanied?
  • Any particular person you want to compose for you
Requesting a performer:
  • The instrument(s) you need played
  • Any particular person you want to perform for you
Requesting an editor:
  • What you need done (merging of tracks / synth / whatever)
  • Links to the tracks (if merging)
  • Any particular person you want to edit for you
OK, I think that's all. If there's anything that I should put in, please tell me.
