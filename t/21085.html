#400271 2 2008-01-12T23:46:55Z wedgie
Firstly, search your computer for 'n_v14b_userdata.sol' or failing that, just search for '.sol' and look for the one referring to N. You may get a couple come up, so look for the one that is the biggest in size to get the one that will have all of your progress on. Now that you have your .sol file:
  • Re-download N, or
  • find the original .zip folder containing N that you downloaded in the first place.
  • Extract the files from the .zip folder into a new N folder.
  • Copy your existing .sol file that has your current progress into this new N folder that you have created, overwriting the new .sol file that is in there.
This should work, hopefully. Though this is just a way of fixing the paths so that N will look for the .sol file that you want it to. If you cant actually find your old .sol file on your computer, then I'm afraid that there is nothing you can do.
