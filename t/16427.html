#306102 4 2007-03-18T16:22:19Z apg
There are actually two ways.
  1. Copy and paste the level data into your userlevels.txt. If you're not using the default file, check that there's a "&userdata=" -tag before the maps. Now, start the N application and go to the "user levels" -menu. Just choose the map you want to play.
  2. Open the N application and go to the debug mode. Copy and paste the map data to the upper box, load the map with "L", turn Caps Lock on and press "P" to play. Press the Ned key again to exit the map, and "R" to reset it if you want to try again.
This all was explained in the manual that came with your game package, so you might want to read that before asking more questions. Read the rules and FAQs and you're welcome.

Have a nice day.

#306106 8 2007-03-18T16:31:08Z Twistkill
Ah, a common inquiry. An easily solved one, at that.

At the top of this forum, click the big black button that says NUMA. Search around for maps that you like. When you found one, copy all the data that says "1.4+ Map data" and go into your userlevels.txt. Read the first part of it. There is a big line that says "***PASTE EVERYTHING BELOW THIS LINE***", so it's obvious what you do. You paste the data you copied below that line, but make sure it does not interfere with any other level data you currently have, (Make some room between other data) and make sure it is also underneath the &userdata= line.

Now, go into the Userlevels menu in N and find the level you just copied in there. If you see a list if userlevels and the map is there, congratulations! If not, then you may have moved N.exe or the userlevels.txt out of their original location. If you want them easily accessible, make shortcuts to them on your desktop instead of dragging them out of the folder.
