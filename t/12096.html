Az, I fixed the EP4 problem, but I said in the readme that the shortcuts all target to C:\WEP\.

Quote: Pavel
Microsoft Windows Entertainment Pack with Tetris

This took lots of hard work to find, so enjoy!
Requires 8mb RAM, 386 PC or better, and 5mb hard drive
space, (Basically will install on any Windows PC running
3.x to Vista).

Installation:

Run SETUP.exe in the Ent Pack1 folder. When it is finished,
copy the "Entertainment Pack One" shortcut provided in the WEP
folder to your start menu folder, (right click the start button,
hit explore, hit Programs, paste the shortcut in there). Default
targets for all shortcuts in the Entertainment Pack 1 shortcut folder
target to "C:\WEP\program.exe"

Run SETUP.exe in Ent Pack2, wait for it to finish. It will copy
shortcuts automatically.

Run SETUP.exe in Ent Pack3, wait for it to finish. It will copy
shortcuts automatically.

Run SETUP.exe in Disk1, wait for it to finish. It will copy
shortcuts automatically.

Compiled by Pavel.
