3 options...global CSS, local CSS, dont do it:

1) global CSS (in the head):
<style type=text/css">
td {
 margin: 0px 0px 0px 0px; /*top, right, bottom left*/
}
</style>

2) local CSS (the tag itself contains the data):
<td style="margin-right: #px; margin-top: #px, margin-left: #px; margin-bottom: #px;">

That's it...pretty much all there is that is current with the latest markup. have fun

#293966 13 2007-02-05T10:15:14Z Ethrel
The simple answer:
IE (Internet explorer) renders HTML different from Fx (Firefox) which renders it different from Opera, which is different from Netscape. All other browsers tend to follow the basic rules of one of these four main browsers, so they tend to be the usuals.

The complex answer:
Most likely from a quick diagnosis is that the IE box-model is messing up once again. The margins, paddings, and everything else need to be adjusted until they work. This usually happens with pixel-perfect layouts when a pixel width and height is set along with exra padding and margins, because IE adds the margins and padding outside the element width whereas the rest add it within that width. simple difference, amazing screw-ups.
