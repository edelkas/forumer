Hey! Today I'll show you how to create cool looking metallic shapes using nothing but blending options. See the end of this post for a couple examples if you want.

:: STEP ONE ::

Open a new Photoshop document of any size with a white background. Open a new layer and select the Custom Shape tool which is found here:


:: STEP TWO ::

Choose a shape you want from the menu at the top. Make sure it has large areas of pure black. For my examples, I'll use a hand. So, draw the hand somewhere in the middle of your canvas as shown and Rasterize the layer by right-clicking on the layer in the layer menu and selecting Rasterize:



:: STEP THREE ::

Open up Blending Options by double-clicking on the layer in the layers window. To start, we want to add a drop shadow, an inner glow, a bevel and a gradient overlay. Apply the following changes:

Drop Shadow

Opacity = 100%
Distance = 0 px
Size = 12 px

Inner Glow

Color = Pure White
Choke = 10
Size = 10

Bevel and Emboss

Gloss Contour = Ring

Gradient Overlay

Opacity = 60%
Gradient = Black to White (should be black at the bottom and white at the top)

Your final product should look like this:



:: STEP FOUR ::

Open a new layer, choose a new custom shape and put it in the middle of the canvas again. Rasterize it. You can click the eye beside the previous layer to make it invisible for the time being. Right click that first layer that already has the layer effects and click Copy Layer Style. This copies all of the effects you added before. Then, right click on the new layer with the new object and click Paste Layer Style. Ta da!

As far as this tutorial goes, you're done. You can add lots of other things including color overlays, pattern overlays and reflections. If you have any problems, ask away.
