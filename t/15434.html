The MSRH

The MSRH is based on an idea that has been suggested quite a few times before. While I don't know if it will ever be implemented, I do know that I can make my own Highscores table to substitute for the time being.[/i]

The Deal

The concept is simple. You make a Speed-Run on any Metanet Level, and I organize it all neatly onto a web-page, which will be the N Wiki for now. The rankings will be organized by the number of frames. The lowest number wins. You can either attach the run here, or PM me with your demo.

The Cheaters

If I suspect you of cheating, by means of speed-hack or fbf, your run will be ignored, and not included in the rankings. Also, don't even think about editing the Wiki page. I'll be keeping very good care of it.

The Runs

You can find the levels using Eeyore's amazing program, N Level Data. When submitting your demo you must include both the level and the demo.

The Idiots

Still don't get it? I'll break it down for you.
  1. Download your desired levels using Eeyore's N Level Data.
  2. Put the data into Ned.
  3. Record your speed-run demo, which means gold isn't an issue.
  4. Put the level data into a text file.
  5. Put the demo data into the same file.
  6. Specify each level that you have.
  7. Put into userlevels if you want to make my life easier.
  8. Attach the file to a post.
