#295387 3 2007-02-09T09:12:03Z Lazylump
Shared objects are quite simple, you can access them like variables from your code.

var mysharedobject = SharedObject.getLocal("yourgamename");
mysharedobject.data.foo = "bar";

The variable 'foo' now has the string 'bar' saved in your application data on the hard drive. To load it, just access it from:

mysharedobject.data.foo

Assuming you still have mysharedobject defined... (ie, if you defined it locally and then try to access it from another object).

If the file is non-existant, it will return undefined so you should check for that.

As far as it goes with text files, I don't think flash is capable of saving to files not under the control of the flash player because this would be a huge security risk.

#306367 4 2007-03-19T20:21:47Z RedShift
Lazylump basically covered it, but there were a few things they left out.


You can define a new SharedObject to recall data that was saved by a SharedObject of a different name, as long as the variable being accessed is the same.

So basically, as long as these variables are declared correctly both this:

mygame.data.foo

and this

yourgame.data.foo


access the stored variable "foo"
