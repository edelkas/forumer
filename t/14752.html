Hey guys,

These past few days I have started work on my map editor again, trying to build on the feedabck from last time I posted it.

I have added several features since then, and also completely re-written the interface in a non-idiotic way.

Current release version is 0.0.0.1 (development is approaching 0.0.0.2), I have implemented as many features as I thought were necessary for a release, and have greyed out the buttons which don't do anything yet.

Please read the readme for the controls, as I made my own control system. Many of you will probably dislike this because it is different from Ned, but please give it a chance. I prefer this style.

So please try this out and give feedback, I am particularly looking for crashes/bugs you may find.

Note: You do need the Microsoft developer dll, this build is only for people who have this. If you have not got Visual Studio, you will need to have used the installer located lower down in this post.

Note2: This is not compatible with Mac OS I made this in VB6, and there is just no way to port it that I know of. This is nothing personal, honest!

Installer: This installer is mainly for the VB6 runtimes, but also contains my program. Please only download/install this once, and for any updates I post just replace the .exe created by this installer.

Installer

Current bugs/issues:

Flip horizontally misses out middle column if the selected area is an odd number of columns. Fixed in v0.0.0.2
When tabbing from a map with objects to one without, the objects were added onto the second map's data. Fixed in v0.0.0.2
GUI is clipped in lower resolution monitors (ie, 1024x768).
User-levels window not closing with main window ending program. Fixed in v0.0.0.2
