this has come up a couple times before, and i guess we _could_ post them, but the reality is that they'd be very confusing, because drawing all of that stuff is quite different than calculating it.

for instance, for the seperating-axis diagrams, it takes a single line of code to calculate the projected size of a box, but many lines to actually draw it -- this is because drawing it requires calculating closest points, etc, while the actual projection just gives you a single number result (which is all you need).
