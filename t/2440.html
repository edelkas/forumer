#53570 3 2005-03-10T22:44:01Z Eeyore
This is the most fool-proof method I could come up with.

Get to the point "1" and then follow the path to "2". I find it helps to jump at the red line. This all needs to be done fast so that you can get to "3" without the missile getting to you. I drew it that you should jump instantly but thats not what you should do. Instead run and then jump. You want the missile to pass above you. The missile will crash into the ground meaning that a new one will be spawned, so be quick. The path at "4" isnt how it should go but I didnt have any problems there so just do what comes naturally.

Hope this helps.
