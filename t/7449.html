First off, we need a name. Secondly, we need to figure out what we're doing with it.

Our choices? Well, they're limited, really.

1. We can simply run a contest for those who finish the levels first, supplying all of their replays for validation. In this, members would have to PM or E-mail us, and we would have to judge the entries as they come in, to validate completion of all maps.

2. We can have a contest, similar to the NTTS, where we judge performance. This would take an ungodly and enormous amount of work, and I don't quite like it.

3. I was pondering on this. And it may or may not work. Hearkening back to what Tim and Brad wanted, I think that it may be possible to code an "N Replay Interpreter," much in the same fashion as Nick has done for NUMA's N Level Interpreter. Ours would be quite a bit more primitive, but it could work.

What we would do... is we would have a place to submit the userlevel.txt replay data to a processor program that reads which level it is, and submits it to a database, which then compares the data, and ranks it amongst the other levels.

From there, we would have a highscore page, where it would list the top 20 highscores for each level, and it would have a text-box (Much like Arachnid's replay data thinger), except for the replay data that was submitted, so that people could copy said replay data from that textbox, and play it.

All in all, this seems relatively painless, if I can get a hold of Nick, I'll let you guys know how feasible this would be, and how much server space we could expect it to take up. Since Sweep's doing an awesome job for us hosting, I wouldn't want to put the burden upon him to have to deal with traffic the size of the entire N community through Madnesstemple.

And thirdly, we'll need rules (And in the case of #3, we'd need a security measure so that players couldn't submit someone else's run to the database).

So, did I explain that well enough?

All Submissions Must be in a .txt file, and the file must be attached to the submission E-mail.

All Submissions Must include completed Demo data from each of the 400 Legacy levels. MAKE SURE YOUR DEMO DATA IS COMPLETE. Incomplete demo data files may result in disqualification.

All Submissions Must include your N username and your first name at the top of the file. Failure to do so will result in disqualification.

All submissions must follow these formatting rules:

-For each level, your finishing time must be recorded upon completing the level, and placed on the line directly below the demo data for that level, in parentheses.
- All demo data must be presented on its own line in the .txt file.
