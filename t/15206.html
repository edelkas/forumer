#284949 2 2007-01-12T23:06:21Z Twistkill
You press Tab to go into Boss mode by default, but you can re-map your keys in the Customize menu.

Boss mode is a feature of N that has several handy features.

1. N itself takes up lots of your processor power, and Boss mode makes N only use a fraction of your processor power so you can do other stuff, like other games, documents, internet porn, etc.

2. Well, it's called Boss mode for a reason! When your boss, parents, dominatrix, etc. comes by, you can simply press the button to hide the N window from view for a minute.

3. An annoying bug in Ned is when you press ~ to go back to the main menu, if a rocket is flying by, N is sliding down a slope, when a laser drone goes by, or when N is smokin some weed, the sounds will loop infinitely. Boss mode stops all of the sounds.

So you see, it's actually quite handy.
