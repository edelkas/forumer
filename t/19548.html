The Web Interface Contest
There seem to be a few people (namely chase and usaswim) who seem to want to get into web interface making. Just thought I'd post a short contest for web inferfaces!

Design Brief
To design a website for your company. This can reflect anything you want, wether it be graphic design, web design (it can be fictional), pottery, whatever. Seeing the web these days inspires great-ness, different-ness and think-outside-the-square, I'm not really putting any limitations on it, except make it 900 px wide max. No coding required, just the image. your allowed 2 entries max, and each of your 2 sites can be about a different product.

Some pointers
Colour schemed, page flow, gridding, themed, Design suited to product, etc will all get you brownie points.
I (and 2 other mystery judges) will, at the end of the competition, judge each web interface fairly using this criteria:

Color and general design suits product */5
Colours go together */5
Design taste */5
Realistic of design (possibly codeable) */5
Page flow (vertical rhythm, spacing) */5
Included graphics */5
Judge's opinion */5
Total */35
Comment:

Thats it. If you would like to judge, or nominate a judge, or have more criteria, edited criteria, anything that I need to fix/make better. I need 3 judges: 2 judge-all-entry judges, and a backup judge that judges the judge-all-entry judges!

Prizes!
I will code (providing they aren't absolutely extremely hard) and setup with hosting the top 2 winning entries. Yeah, from scratch I will set up a hosting account and code the site, finishing with the winner having their own site.

Promotion
Now, so more people come so there is more to judge so it makes the competition all the more interesting, if you sign up to enter the comp, or judge and you would like to promote, put a badge in your sig to say so!
So far I have 4 different sizes, 50x50px, 100x100px, 150x150px, 200x200px. If you would like to contribute a badge so there is more selection, please do!
