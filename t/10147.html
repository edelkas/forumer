Backup your .sol (saved game) regularly and set CCleaner not to clear Flash, or manually copy it yourself. N can't be made to save to a physical file because it is made in Flash (an unfortunate limitation). Once again because of Flash, N runs slowly even on good computers. For one thing, it only uses software rendering, so the graphics card makes no difference.
