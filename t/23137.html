...or at least it shouldn't, if the problem is what I think it is.
But unfortunately, I'll have to conclude that I don't *actually* know what exactly the problem is, just that it's the same one I have. I only use Windows for gaming, so I just haven't taken the time to debug anything yet, so I haven't found a fix or even looked into what's happening.

It doesn't sound like it's a permissions issue with the application itself, because it can clearly go online. But it might still be a blocked port issue if waypasteleven is trying to bounce something back to you, is failing, and therefore drops your connection. Go to Start > Control Panel > Security > Windows Firewall > Ports (or whatever those exact names are; I'm not using a Windows machine right now), and add a port for the IRC connection (6667, is it?), and let us know if that solves anything.

Other questions:
Are you trying to do this at home? (My lab blocks all ports commonly used for chat, such as those for AIM and IRC.)
Do you use a router to connect to the internet, or is the cable coming straight from your wall and into your computer without anything else between them?
Go to Start > Run, type in "cmd" in the box (without quotes), and click Run. In the window that appears (it should say something like "C:\Windows\system32\>"), type in (without quotes) "ping waypasteleven.com" and hit enter, then paste what it spits back at you here.
