#179876 3 2006-05-24T18:00:36Z iangb
Stardeash, just because you haven't done it doesn't mean that it isn't possible.

It does happen sometimes. The only thing you can do about it is to back up your N save file periodically.
The save file is n_v14b_userdata.sol and is stored in the following folder (assuming you're running Windows XP):

C:\Documents and Settings\[your user name]\Application Data\Macromedia\Flash Player\#SharedObjects\[Random set of letters&numbers]\localhost

You will need to be able to view hidden files and folders to see it.

To back it up, just copy the .sol file to another folder (for example, the folder containing N). If your game gets reset, like has happened to you, just copy the file back into the original folder. Unfortuantely for you there is no way to recover lost data, but now at least you shouldn't have the same problem again.
