I actually came up with this on my own, but I wonder if anyone has thought of this before .

Well, I thought up this game a few minutes ago, and decided it might be a pretty cool message board game. It's pretty simple, but you might need certain programs (particullary freeware image editing, like Gimp, or if you already have Photoshop, even Flash can help you) I think the name sort of explains the game.

Now here are the rules:
  • You must have a box (the image file of course) with multiple colors in it.
  • These colors are for each word, or may contain parts of a word.
  • With the image posted from the member above you, made with some program that can read hexadecimal color coding, and put it into you program (not paint) and read each of the hexadecimal colors in the box, and post it so others without any programs can read it too.
  • Next, post your own image file with colors representing words, in a single order.
  • I don't want H-scroll rapings, so wrap up your images so that doesn't happen. provided a phrase ever being that long
  • No poor image quality please! That means no compressed .jpgs, so none of this can be doen with paint. only 100% quality .jpgs, .gifs, and .pngs are allowed. otherwise we can't read the HTML color as bad JPEGs can mix up colors.
  • Enjoy it!
Oh, and if you didn't clearly get how to read these phrases, just open your program and paste the member above yourself's colors and use the tear dropper to read the hexadecimal code on each color. Each Hex number can contain more the one word, and where letters aren't there, you can replace them with numbers. Just don't overuse 1337 in it.

And in case you didn't know, Hexadecimal is limtied to the following characters: 1 2 3 4 5 6 7 8 9 a b c d e f.
Instead of a period, if you have more room on you phrase on the last hex code, type in 3s to fill that in. Like in my example you'll see.
