p.s - Grimil, could you post code? here's orughly what our code does for circle-circle (i think.. ) ..notice the lack of trig

(given circles A and B, each with position .x,.y and radius .r)

var dx = B.x - A.x;//dx,dy is the vector from A to B
var dy = B.y - A.y;

var dist = Math.sqrt(dx*dx + dy*dy);//dist is the length of the vector from A to B

var diff = (A.r + B.r) - dist;

if(0 < diff)
{
//if we're in here, we know the two circles are colliding because the distance between them is less than the sum of their radii

var nx = dx/dist;//nx,ny is a unit-length vector that points from A to B
var ny = dy/dist;//is describes the direction of the collision (surface)

var px = nx*diff;//px,py is a vector that points from A to B and which
var py = ny*diff;//is the same length as the amount of overlap between the circles

//so, at this point, px,py will move B out of A, if we add px to B.x and py to B.y
//or, we can add -px and -py to A to move it out of B.. etc..

}
