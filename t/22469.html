NReality v6c2 didn't come with the mods programmed in; it accesses the code online. This allows Unreality to add new features without forcing everyone to download a new version of NReality.

On the other hand, the NUMA downloads seem to be programmed in and only require a connection to NUMA.


Finally, everything should either work or not work. If the mods are working, try waiting a little for the highscores to load.
