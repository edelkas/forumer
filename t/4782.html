Aim: To create great maps encompassing unusual use of the objects Ned provides you with. Objects should be used in ways that Mare & Raigan (creators of N) didn't intend or imagine them to be. Of course, you're allowed to use objects normally, in their intended fashion, but unusual use of objects should be highly prominent in your map.

This is NOT a bug map contest. Taking advantages of bugs within the game is allowed, but this is not a bug map contest. Also, you're not required to come up with new uses of objects. You can take heed of previous unusual uses, for example the backwards thwump effect, or the glass door effect. If you do come up with something entirely original you will gain points from it, but it is perhaps a better route to use your favourite odd objects uses in the quest to create a great map.

I figured it'd help if I gave you some examples of the types maps this contest is and isn't looking for, and why in each case.

Example of a good entry...
Pressed for Time - Lucidium.
This map encorporates backwards thwumps into a great level. This is a good entry because it uses enemies unusually and is a fully playable, enjoyable map.

Example of a bad entry...
4-bit binary adder - AlliedEnvy.
It's nice that you can use doors to create a 4-bit binary adder, but it's not a playable map in the slightest.

Example of a good entry...
Electrons - MacrossDreams
Unusual use of drones in the way they almost act as 'prison guards'. Very playable.

Example of a bad entry...
Totally Buggered - Formica (The Daily Llama)
It's a bug map. 'Nuff said.

Example of a good entry...
Compartment - Lucidium.
Well, as you've probably caught onto by now, there are two boxes to tick - unusual use of objects and playability. This one has both. The drones are used unusually in two ways... firstly, they're set still. This isn't that unusual, but isn't how M&R originally intended. Secondly, and most importantly, they're placed so they only have one clear line of view, which has rarely been seen before in this context.

RULES
- No DDAs
- No maps submitted to NUMA before the 10th of September
- Closing date for entries - 22nd of October (No more entries are allowed)
- All submitted maps should be submitted to NUMA and linked to in this thread
- No silly business
- No editing your map after it has been judged by any judge
- No more than four entries each
- No withdrawing a map that has already been partially or fully judged
- If a judge submits a map then instead of them judging it our backup judge Maximo will

Scoring of maps:
Map Quality - out of 50.
This is simply a score out of 50 points based on how good the judges think the map is, irrelevant of how it uses objects.
Object Use - out of 50.
This is a score out of 50 points based on the use of objects within the map. These 50 points should be given considering the following factors:
- the prominence of unusual object use in the map
- the importance of this unusual object use in the map
- the originality of the unusual object use in the map
- how seamlessly the unususal object use fits in the map
- generally how well the unusual used objects work within the map.
Total - out of 100.

There will be three judgings of each map, making a total out of 300.

Judges should judge the maps in order of which they were submitted.

A date for the judging to be finished has been pencilled in for the 10th of November.

Map Quality
This is a very unusual map. There's a lingering sense of no matter what you do, you have NO control over what's going to happen. This is good and bad.
