Okay, a while ago I thought it would be a good idea for members of Numa to see other information about other Numa members, on the Numa website. It would take quite a bit of server space, but I think it would be a good thing for users to show of things like their current best map, best demo on a map, favourite map etc... And maybe even an "average rating" as in what thier average is on voting other maps.

Rather than the plain old:

User information for whaleshow527
Member Number : 3248 
Maps : 37 
Average Rating :
Rated Maps : 33 
Votes Placed : 747 
Favorites : See this user's favourites list

Something like: 

User information for whaleshow527
Member Number : 3248 
Maps : 37 
Average Rating : 
Rated Maps : 33 
Votes Placed : 747 
Average Vote Placed : 
Latest Map Played : 
Latest Comment Made :
Personal Best Map : 
Favourite Map :

There's probably more to add to that list, but it gives you the general flavour of what I mean.
