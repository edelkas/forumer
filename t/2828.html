This is a program I have spent a while on and am quite proud of. (So if you criticize it I WILL hunt you down ).

It's basically the level data for the level from N v1.4 displayed in a nice and appealing way. It lets you easily navigate to find the map you want using a specially created GUI. Once you have selected the level you want, the level data is displayed and a picture of the level is created from the level data. (It isn't a stored picture, it's built up dynamically, kind of like what numa does. It took a long time to make and I'll probably be using it in another program I'm planning.) By clicking on the half size picture of the level you can bring up a full size picture of it. Also by right-clicking on the pictures you can put the picture into the clipboard. Similarly you can double click any text to put it into the clipboard

This program is as useful as you are imaginative. A few things I have used the program for so far are:-
- If you are stuck on a particular part of a level, use this program to get the level data for that level. Then in Ned, change the location of the ninja so that you can practice just that part of the level.
- You can create remixes of the original levels.
- If you want to find a level but don't know what the number is you can quickly check through the levels till you find it.
- If you want to try a level you haven't yet got to, but don't want to leave the evidence that you have cheated.

I dumped N from the ram. This meant that all the data wasnt encrypted, meaning I could get at the level data. (that's how I found out the level passwords in the thread "interesting"). I then had to work out which level data corresponded to what level (they werent always in order). Then I had to format each level data so that the level data could fit into a variable (Most levels wont fit into 1 line of code). The formatted level data then had to be copied and pasted into the right place. All 450 levels. Then there is the dynamic building of the picture. The program ended up being around 13000 lines of code if I remember correctly. Ive been working religiously on this...
