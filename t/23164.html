#452588 3 2008-07-13T05:23:13Z Atilla
Yeah, there's a cap on the number of maps to prevent abuse. It used to be 500, but I believe it's lower now...

Also, you can just change "browse?" to "userlevels?" in any NUMA URL to download those maps as a text file instead of browsing the site. If you want to download a bunch of maps with specific criteria (action maps with bounceblocks by Atilla, for example), it's often easiest to just use NUMA's search function to get the type of maps you want, then change the URL to download a bunch.
