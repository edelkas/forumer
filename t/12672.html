That would be because you're using the flowchart mode, not the programming mode

I've started programming in Java and Flash Actioncript and there are so many similarities. It is a completely legitimate programming language. It's a great starting language that is fully object oriented and uses common commands that you can carry on to other languages such as object-oriented skills and general logic using all the types of loops and conditions that other common languages use: the for-loop, do-while loop, while-loop, switch statement, if statement, etc. It's just like any other programming language but it comes with many useful pre-made functions, and it makes some of the trickier things easier (for example, you can reference instances from their object name and create instances without specifying their instance name or depth- having instance IDs made for you is extremely useful) It's meant as a beginner program but it can do almost anything (at least as far as 2-dimensional display goes. My only complaint is that it doesn't have any pre-made GUI functions so you have to code your own.)

If you want to make life harder and use the room creation code to create all your objects, events, actions, and instances instead of using the nice list of objects and events, guess what, YOU CAN DO THAT. I just see no reason to not use the objects and events functionality- though I never drag and drop actions because it can only do a fraction of what you can do using code (especially with loops).

Sure it's made easier to use than something like Java, but that's the whole point of the program. Don't rant about how it's not meant for non-beginner programmers when it's not intended to be. It's purpose is to get people interested in programming by making a really really easy-to-use flowchart type programming method, then to let the user go and expand their programming skill and actually start coding by using the actual in-game code. It's meant to allow you to go from basic and limited games to fairly advanced games using file reading and writing, OOP, and recursion without going too advanced for the user to be confused and turned away. And it accomplishes this task amazingly well. I'm so thankful for Game Maker because its what really got me interested in programming and the skills I learned making my own games in GM are transferable. Of course, you can't exactely make Halo or Half-Life with it, but it most certainly is a programming language.
