#79680 5 2005-06-29T19:17:30Z LittleViking
Whoa! If you're planning to reformat, the data won't be saved automatically. Do a search for *.sol on your hard drive. Make sure hidden files are shown. You should find something like n_v14_userdata.sol. Back that up. After you reformat, download N again, start it up once (to set the storage limit and create a blank save), search for the file again and replace it with the old one.
