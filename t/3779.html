I know it's been suggested before. People seemed to like it but it would be too hard to implement on a database system like Numa has now. I think the ratings system would be more accurate if people had more incentive to rate maps that fall past the first page or two.

So, I suddenly thought of an easy way to have random maps. Rather than 10 random maps on a page, the link could give you maps in their current order, with only a random start point. The link would basically look like--> numa.notdot.net/browse?start=<random number here>

And the great thing about this idea, is that it could be implemented independent of Numa. If Arachnid doesn't find it neccessary, it could just as easily be put on N-vision, or any simple javascript ..script. I don't know how it took so long to come up with this idea, but it's here now.

Pseudo-Edit: Hm. Seems the rating system is going away. Well, still, there's nothing wrong with playing a random set of maps from the past.
