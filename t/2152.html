#48290 8 2005-01-28T05:00:59Z Guest
hi,
we definitely are going to do our best to get some type of "play custom made-in-ned levels".

this is so far _really_ complicated by the fact that flash doesn't allow access to the filesystem. this means that we can't do the NICE thing, which would be having a directory full of files, each of which contains info for one map. no, that would be too easy, wouldn't it macromedia?! AGH!

the way it will probably end up working is something like: we'll store a "library" of maps in the user's .sol file. you will add/remove/save/load maps to and from this library using ned (and _possibly_ numa, we have to actually get off our ass and email arachnid). then, in the main menu, there will be a "play from library" type option.

the main problem will be: episodes. we still don't know how to let users define their own episodes. mostly the problem is that the interface becomes horribly complicated.. it would be _so_ nice to be able to use text files so that users can just save each map as a different .txt, then make another .txt with the 5 mapfile names, and tada.

so far 1.4 is really a bit pain, because it's all interface stuff which neither of us is good at, and also which the existing code is VERY unfriendly towards. so the majority of work is going towards boring crap that's not very rewarding..

there has also been talk of supporting some type of contest. however realistically i think what's going to happen is that we're going to try to spend most of our time cleaning things up and adding the basic features that are still missing, and then opensourcing it so that hopefully someone else will be able to add all of the 1000s of things we want to add

anyway..
raigan
