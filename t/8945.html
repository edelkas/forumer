You must choose a map which has tiles.

All maps MUST be submitted as test level.

You must credit the original map in the description

Number of entries allowed per entrant: 3

When you submit an entry, you must post in this thread.

The tileset has to be significantly altered. I will inform you if it is not substantially altered. It is up to you to then either edit the map or leave it as it is and get disqualified
