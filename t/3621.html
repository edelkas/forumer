#93572 13 2005-08-23T17:49:25Z Maniac
Okay, listen to this post and only this post.

If you want to play a demo on a user level, copy and paste the 1.4 level code (the stuff that goes into the userlevels.txt file) into the demo box. Then, go to the end of the code. After the last #, copy and paste the demo code and add an # at the end. Click "replay" and it should load the level and the demo. It sounds hard, but when you're playing userlevels, replays are saved in that format, so userlevel -> userlevel is a lot easier than NUMA -> userlevel.
