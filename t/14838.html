The main purpose of beta testing is to see how it runs on different hardware. The game might run fine on Mare's computer, but there are tens of thousands of different hardware configurations for Windows users. When the 1.4 beta was released, they compiled two or three different copies and asked us which one ran the fastest. Strangely, some computers ran copy A the fastest, some ran B the fastest, but most ran C the fastest. If Mare and Raigan just released copy A because it was the fastest for them, then the majority of our members would have gotten the slower version for them.
