Concerning the slowdown mode: it can be used for 3 purposes:
1) Testing very hard tricks and stunts etc..
2) Making a fast demo and passing it as legit (think cheating )
3) Making a fast demo and not passing it as legit (think tool-assisted)

If you're going for the third, then it's logical to try making a perfect demo, for which slowdown is clearly worse.
