#62636 19 2005-04-28T23:02:27Z syntax
Keron Cyst... A while ago I tried to get Metanet interested in my freeware inline java app chat client. A few peeps here and elsewhere had a go (we reached 15 simultaneous connections at one point). Basically, from a server point of view, it requires just copying a jar file to a directory, and editing some html to display the applet (assuming you can host java).

The applet itself can be inline or on a seperate page, and the jar contains the messaging server. As with all java server apps (thread pool), there is overhead, but I like the fact it's totally unique and uses swarm technology to propagate messages i.e. there are no central logs, and no way of tracing any conversation.

In fact, if you were to packet sniff your connection to the server, you'd only get parts of random conversations inversely proportional to the amount of people logged in. So if you had 1000 people, your connection would be handling 1/1000th of the traffic of *everyone*. No way to log anything anywhere.

My idea was to create a free web-browser based messaging platform with total privacy. It is buggy, and not as pretty as it will be, but let me know if you're interested...

The reason I pulled it was:
1) I was hosting it locally because I haven't got time to set up my own domain
2) Without a user base, I can't improve it as I need feedback
3) Windows 2000 defaults to using the Microstf JVM which isn't compatible

Therefore

My aim is:
1) To deploy this where there is interest
2) To only expect full operability once XP (+) becomes widespread
3) To implement any improvement suggested
4) Get it hosted so I don't put my own PC at risk
