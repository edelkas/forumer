#5165 1 2005-11-13T18:52:28Z Eeyore
In my opinion the main problem with numa is that only a fraction of the maps submitted ever actually get rated. Even worse, of the people who get rated most of these are established map makers who have already built themselves a reputation. I'm sure that this is very demoralising and is actively dissuading new map makers from continuing to make new maps. This means we are killing off the future generation of map makers. This is my proposal to attempt to alleviate the situation.

The idea is that there is a points system. For every map you rate you receive a point. There would then be a score table where the people with the most points would be displayed. This would attempt to encourage a sense of competition where people would be rewarded for rating maps. There would be a link to the score tables in the left sidepanel so that the majority of people would know about this.

This would be easy to implement as the number of maps you have rated is already stored. Hopefully it will be implemented as I feel something definitely need to be done.
