When your system crashes and you have to re-install Windows, it is always better to keep a backup of your N game progress. Up to now, you had to search in cryptic folders for a .sol file, but the N Backup Assistant manages a backup of your N game progress in a easy way.

It is pretty self-explanatory. You select the (desired) path of your backup, then you create the backup, or restore your game progress from the existing backup file.

EDIT: If the program doesn't work correctly, visit this Microsoft help page and download and install msvbvm50.exe. After this, the N Backup Assistant should work.
