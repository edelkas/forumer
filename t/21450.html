Visual Styles

Windows XP has a built in theming engine.
uxtheme.dll is the file in Windows that controls that engine.
By default, uxtheme.dll is locked, so you can not use any non-microsoft skins.
This can be easily unlocked though, either by a application such as StyleXP, or by replacing the uxtheme.dll file with a pre-unlocked one, which I will cover below.

Method one
Using a third party app

Head on over to http://www.stardock.com and see what they have on offer over there.
Although a little costly, and sometimes CPU/RAM intensive, these programs offer the skinning solution for those who do not want to get their hands dirty.

Finding and Installing Themes


1)Download a theme or visual style you wish to use. Some good sites to get these off include:
http://www.deviantart.com
http://www.themexp.org

2)Extract the downloaded file.
There should be a *.msstyles (eg theme-name.msstyles) file in there somewhere.

3)Browse to C:\WINDOWS\Resources\Themes
(C:\WINDOWS being your windows directory)

4)Create a new folder here, with the same name as the theme file.
For example, if the theme was called 'blah.msstyles', you would create a new folder called 'blah'.

5)Copy the *.msstyles into the folder you just created.
(eg copy 'blah.msstyles' into C:\WINDOWS\Resources\Themes\blah)

To apply your visual style- Go to Display Properties > Appearance > Windows and Buttons, and in the drop down menu, you should see your newly installed visual style
