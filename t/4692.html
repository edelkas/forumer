#4281 1 2005-09-03T00:05:36Z Mare (guest)
Hi,

We just wanted to let everyone know what's goin' on.



The new game:

Unfortunately, work on the new game has been very slow, for a number of reasons. The biggest thing is that we've only been working on it part-time, which is a bit frustrating: it looks like we won't be in the IGF this year.

After the IGF, we had planned on quitting our jobs and starting to work on our next game full-time, using savings to live for a few months. However, we moved in june, and the move was WAY more expensive than anticipated. The new office is great, and very productivity-friendly, but we're also broke

As a result, we've been forced to work on programming contracts since july, so that we can amass some more savings.

We're aiming to have something finished before the end of the year, however it all depends on how quickly we can stop working these contracts.

We've also been looking into a government-sponsored program that helps people start their own business; if we get in, there will be two months of courses which will slow the next game down, however we'll then have an entire year paid for, so that we can do nothing but work on new games. So hopefully we'll get in!


So far we're really excited about the next game.. we're sorry it has to be top-secret, but it's only just been started. You'll be the first to know any details about it, we promise! Especially since we'll need beta-testers

Also, the next game will very probably _not_ be free, since at that point we'll be working on games full-time. However, it certainly won't be expensive, and we will definitely continue to release free games -- the current plan is to alternate between shareware and freeware.. we're hoping that this will work out.



N:

At the start of the summer we said we were finished with N, and would release the source sometime in September. Since then, several things have occurred which have made us change our mind:

-an .swf version of N 1.2 has been floating around the internet

-the next version of Flash is out (or, will be _very_ soon)

-it's been sufficiently long since we made 1.4 that we've forgotten how hellishly painful it is to work on N

-there have been several good suggestions on the forums


So, we've decided that N needs one more release. We're not sure when this will be, possibly around the same time as the new game is released.
It will probably just be another incremental update, like 1.3 to 1.4, and not a drastic change like 1.2 to 1.3. Thanks to the new flashplayer, it should be much faster and processor-friendly.

As a result, we won't be releasing the full source until then.
BUT!! we're going to release the source to the "in-game" part (i.e the interesting part of the source) with tutorial 3, which will be coming very shortly. (I know we've been claiming that tutorial 3 will be done soon, but this time we mean it!)


In order to counter the illigal swf version, we're also going to be releasing an official swf version, which will be like 1.4, except with fewer levels, no editor, read-only highscores, etc.. and a nice giant link to the download page. This isn't really for existing N fans, but is more of an attempt to let webgamers know that the 1.2 swf abomination they had been playing is terrible, and that there's a much better version altogether available for download. Also, since it will be running in flash8, it should hopefully be able to match the speed and smoothness of the downloadable version.



Donations:

You may have noticed that we've finally got around to putting up a donations link on our site. If you feel like donating, it would be greatly appreciated!



Thanks so much for your continued support and enthusiasm, we're eagerly anticipating really getting to work on the next game.. it's exciting!

Mare and Raigan
