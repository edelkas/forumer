Diplomacy is an excellent board game. It's set in 1901, in Europe, just before World War One begins. It's designed to simulate diplomatic negotiations, tensions, and eventually all-out war. The game board is extremely well-crafted, and there is no real luck involved in the game at all. The complete rules can be found here.

My friends and I have been getting together and playing this game once a week, and I've fallen in love with it. Are there any enthusiasts around these parts?

If so, let's talk strategy!
If not, then you guys should round up some friends and try this game out!

P.S. If you want to play the game with yourself, or just mess around with the in-game mechanics, you should download JDip.
