hi,
the cheating/beating logic is definitely working, it's been very well tested.

however, i think i know what your problem is.

let's say you made it to 23-3 without cheating, then you give up. in the progress menu, episode 23 will appear "unlocked" (grey). if you then proceed to cheat to get to episode 24, episode 24 will appear "cheated" (white).

if you later want to beat 24 properly, you MUST start be beating episode 23, since you never beat it fully -- you cheated through 23-4.

in the progress menu (in highscores), 23 will be grey/unlocked, but clicking on it will show you that 23-4 is white/cheated.

so, please go to the highscore menu and click on the episode(s) you think you've beaten properly. at some point, you should find an episode which has been unlocked without cheating, with some levels which have _not_ been unlocked without cheating. you need to start by beating that episode.

please post if this doesn't work or you still need help.

thanks,
raigan
