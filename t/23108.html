#454889 4 2008-07-24T20:48:10Z Lightning55
You basically search up a mod that you want to use. Use the above links to find the type of mod. Then type | accordingly to go from one type of mod to another. Then use |(object number if required), mod name, mod (semicolon after if you want to add another object/player mod, then another |

ex. |image1|image2|11,fallspeed,500000||
attach that to the end of your level data and bam, its a NReality mod
