*sigh*

N is a great game. Really awesome. I really enjoy it.

But why does the edit mode have to be so messed up? For a start, instead of pressing keys it'd be far easier if there was a menu bar at the top or side instead. I managed to start Ned a while back, using that key, which has the vertical bar on it, but since then it just hasn't worked. Didn't work before that either, and ~ is completely unsuccesful. WHY CAN'T THERE JUST BE A BUTTON? Imagine the problems solved.

The editor in itself is quite nice, simple to use, could be better but I have no quibbles. Of course, then comes the debug mode caps lock business. Now, I'm sorry but the average user will just have a quick glance at a manual, and take out the important bits. The moment I see 'debug mode' or something like that I ignore it. I'm playing a game, not assembling a PC. And the editor seems simple enough to ignore stuff like that anyway. So I start playing. With it in slow-mo, my first reaction is to close the window and start again. And so I did. And of course, since then I haven't been able to use Ned at all for some inexplicable reason.

And I bet that 3/4 of N's users don't even know it exists. They will just start up the game, you don't need to read the manual to get going. What is this about? Do you have an obsession with having some secret club of people that know the editor exists?

I just don't understand how someone who creates such a brilliant game as N, with all the collision physics and what not, cannot use common sense and use buttons instead of keys. Oh, and put up in capitals: 'TURN ON CAPSLOCK'. Or, instead of that, have a button in the top left or something to switch it on and off. Oh, and start with debug mode off automatically.

I just don't get it. N is so beatifully executed, and so could Ned. I don't know or care if it was done in a rush, i've used Flash and know that creating simple buttons is mind-numbingly easy. The main editing screen is clearly the difficult bit to do, yet that's been executed perfectly.

/end of rant
