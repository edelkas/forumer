1) If two trap doors close on a location, it is always impassable.
2) If two locked doors open on a location, it is always impassable.
3) If one locked door opens on a location, it becomes passable unless (1) or (2) is in effect.
4) If one trap door closes on a location, it becomes impassable.
5) Disregarding all other rules, if a location contains a normal door, it is always passable unless that location also contains a locked door, open or closed, placed before the normal door, in which case it is always impassable.

This is really weird...
