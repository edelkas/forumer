There are all of the level types I've seen. What do all the types mean? Also, which ones are allowed to be impossible?
#370878 2 2007-10-09T21:27:37Z usaswim
Action - Generally no specified path to follow

Puzzle - You need to plan ahead

Race - Has a/some paths you must follow

N-Art - Art made using N. There are playable and non-playable types

DDA - Don't do anything

Tileset - A map that consists only of tiles and a ninja

Test - Test map for a possible concept/idea

Survival - A map with no exit

That's basically a generic description of all the map types.
