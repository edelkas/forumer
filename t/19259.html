The usage of "it's" and "its"

When talking of things as they should be, as in saying "it is" or "it has" you can shorten that to become "it's"

"It is a nice day" can be changed to "It's a nice day."
"It has become dangerous" can be changed to "It's become dangerous."

When using "it" and you are saying "its" ask yourself first if the sentence, when spelled out fully, reads the "its" as an "it is." if so put the apostrophe. If not then put the S afterward.

"Its candid behavior was annoying."
