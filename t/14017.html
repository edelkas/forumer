I believe that this is something new.

The main idea for this messageboard game is to add a letter onto the user above you's word.

Rules:

The word that you post must be a real word.
You can only add on one letter each post.
No double posting.
You can use a dictionary.
Once you can't add another letter onto the word, you start with a new 1/2/3 letter word.
The person that adds the last letter onto the word gets a point.
You can add a letter in any part of the word, not only after the other letters.

Was that confusing? Here's an example:

Player 1: An
Player 2: Ant
Player 3: Ants
Player 4: Aunts

...And so on.
