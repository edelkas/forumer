If you dont know so much about flash you should read some tutorials here Actionscript.org. To make something response to keys, put this code on a movie clip:

onClipEvent (enterFrame) { //if you want to put this code in to a frame change this to on(EnterFrame) { 

//In case u want to do something with two keys, add it up here

if (Key.isDown(Key.DOWN)) { 

//if Down is pressed
//do something

}  else if (Key.isDown(Key.UP)) { 

// if Up is pressed
//do something else

} else if (Key.isDown(Key.LEFT)) { 

// if Left is pressed
//put something creative here

} else if (Key.isDown(Key.RIGHT)) { // if Right is pressed
//and something else here
}
}

After the // everyting on that line is comments

Good luck
