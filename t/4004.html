Quote: LLCoolDave, Jul 12 2005, 06:29 AM
It's a simple image with transparent background put in front of N, nothing special, really.

I understand what you are saying but whats actually going on is a lot more complicated. Its using some pretty heavy code to selectively display the background of the picture and not the foreground ground. This isnt so much a picture as a program and there is a reason most programs are rectangular.

Also, what you are seeing is not what what the difficult thing to do was. It was the actual making of the level that was difficult. Can you see how if you have a picture on top of N you cant see where you are putting the objects. To overcome this I had to make the program semi-transparant. The real problem however was that if you want to place an object you are clicking on my program and not N. This means that my program gets the focus and N is clueless about me wanting to place an object. To overcome this I had to artificially send messages to N's message queue. Not an easy thing to do in any language and expecially not from vb. This is not even mentioning all of the many little things that you wouldnt even think about

So in conclusion, it looks simple but in actual fact far more complicated. I'm making an N skinning program at the moment that should hopefully simplify making skins.
