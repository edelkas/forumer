Er, the idea is to take one of the half-dozen links in this thread and replace the author name with the name of the author you want. If you really want to know how it works, this is how it breaks down:

http://numa.notdot.net/userlevels?count=1000&author=littleviking001

http://numa.notdot.net/
This part of the URL tells us that we are, in fact, accessing Numa. This is a very important step which is commonly overlooked by people who don't understand the internet.

userlevels
This is a page on Numa that generates Userlevel data out of whatever maps are fed into it. The alternate of this page is browse, which displays the levels rather than creating the Userlevels file.

count=1000
This tells Numa to call 1000 maps. If there are less than 1000 maps available (which is the case with all the authors now), then it'll just grab all of them.

author=littleviking001
This tells Numa to only take maps by the author, littleviking001.

When used together, we get a userlevels file with 1000 (or the max available) maps by littleviking001.

#341253 19 2007-07-10T06:00:30Z apg
The tags make it just a bit different.

http://numa.notdot.net/userlevels?q=author:name&count=1000

Instead of '&author=name', put in 'q=author:name'. You can also insert any other tag after the 'q=', for example:

http://numa.notdot.net/userlevels?q=bitesized&count=99

This would download the 99 newest bitesized maps.

Separate multiple tags with a +.

http://numa.notdot.net/userlevels?q=puzzle+minimalistic&count=99
