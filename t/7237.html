#139931 20 2006-02-05T20:43:51Z iangb
...no.

You've managed to delete your .sol file (basically the .sol file is the N save file). Clearing cookies will _not_ do this. A bug in the game sometimes does - unfortunately there isn't anything you can do about it. Next time, back up your .sol file periodically by copying it out of it's folder to somewhere else.

The .sol file is stored in this folder: C:\Documents and Settings\[your user name]\Application Data\Macromedia\Flash Player\#SharedObjects\[random set of letters/numbers]\localhost


edit: oh, and don't use cheats to try and get back to where you were - it means you won't be able to unlock any secrets.
