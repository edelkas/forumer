So here it is.
People do a lot of collabs, and collab accounts are made, etc. I don't think this will really be that useful, but my idea is that there should be a system for crediting maps to two people.
E.g., when you submit a map, there should be a check box that says "This is a collab" (rather like that which says, "Disable ratings on this map.")
If you check it, you then type in the other member's name in a box below the check box or find it in a dropdown list. When you click "Submit," the server will send a message to the user in question, asking them to approve the collab request.
If they do, the map will be credited to both users. It will show in both of their galleries and, when someone views the map, it'll say both users' names by "Author."
