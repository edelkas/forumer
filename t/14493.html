dude! did you even read the topic?
Read the thread before you start abusing people (or, preferably, don't abuse people at all). He wants to play his levels through the "Userlevels" menu, not in debug mode.

Anyway... read the information at the start of userlevels.txt, which should be in the same folder as N. If you don't have userlevels.txt, download N again from the Metanet Sofware Homepage. Basically, what you have to do is add your level to the end of userlevels.txt in the form "$Level Name#Author#Category (Action, Puzzle etc)#Level data (you know, all the numbers and stuff that appears in the 'level data' box in debug mode)#" If you've done this and it isn't working, make sure userlevels.txt is in the folder you're running N from, make sure you aren't trying to run it from a zipped folder, and make sure there are no special characters ($, #, ^ etc.) in the level title.
