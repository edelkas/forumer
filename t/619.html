#25123 5 2004-07-19T16:14:21Z Guest
hey,
we've actually been in contact with macromedia people about this; because of how flash handles anti-aliasing, things get exponentially slower as the window size gets bigger.

stretching is pretty much just as slow because it's all done in software.

if you think about it, there really haven't been many games which run at 800x600 using software rendering (which is basically what the flashplayer is). most software-rendered games stick to 640x480 cause it's such a huge hog to push all those pixels.

for instance: 800x600 is 480000 pixels. each pixel is 32bits -- which means copying the entire framebuffer from main memory onto the screen/recipe memory means transferring 1.92mb!! at 40fps, that's 76.8mb/s.. granted that's not _soo_ much since agp is 100's or 1000's of mb/s.

but anyway, we can't make N any bigger. hopefully in the future we'll be able to add automatic resolution-changing so that you can play it full-screen in 800x600.
