Is there any way to make this game alot less computer resource intensive? The game looks awesome, but it doesn't seem like it should require such a large amount of processing power. I can hardly talk to someone on AIM when the game is running.

Other sugesstions:

Add as many objects as possible. Give the user as much freedom and as many options as possible in the editor. Is there any way to quadruple the number of "spaces" on the board? I mean make each current block split into 4? You could make more interesting level designs that way, I think.

What someone already said about environments, I second. Variety is great.

Can you make the game fullscreen? Bigger levels would allow for more freedom.

It was said in another thread that powerups don't seem to fit into the theme of puzzle solving game, but I disagree. Powerups can merely be part of the puzzle, and it, again, allows users more options when constructing levels. Suggestions on powerups: high jumping, ability to land safely from twice as high, very short duration force field, ability to run twice as fast. Nothing crazy, just things that augment N's current array of skills temporarily and would allow completion of otherwise impossible puzzles.

When this game really gets going (I'm already telling people about it), I will be telling all my friends about it and putting messages up on boards I frequent. N's awesomeness will get people in the door, but the ability to create and share levels will be what keeps people around. There will have to be a nicely designed website where people can easily upload their own levels, and then download others, rate them, and leave comments. The message board method works for now, but will be very unweildy if the community grows to the point I'd love to see it grow to.

So to end, My suggestion is Variety. Whatever you can do to offer more customizability, do it.
