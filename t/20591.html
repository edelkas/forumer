#388295 2 2007-12-11T08:03:41Z mattk210
I'm no expert, but the whole idea behind the tutorials is math and physics for collision resolving. It works based on variables such as coordinates and sizes. So, the best approach is to store variables for object position and such, calculate the collision resolving and physics, and THEN render the graphics onscreen. Because of that, the objects displayed can be drawn with the API or moved as movieclips, it doesn't matter. The system doesn't depend on the graphics on any way.

And yes, there isn't much code in the tutorials, but all the code is in the source at the end.
