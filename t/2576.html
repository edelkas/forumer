For custom mods to the game, how will you impliment them?

The logical assumption would be to just make the modified version and you play that when you want to use the mod.

However, I think that each mod should be a seperate special file readable by the same program that N uses to load custom map files. From that program, you can enable and disable mods that you want, and maybe comfigure them if you want to.

Of course, the map/mod program should never be modable, in case there's a problem with a mod and N becomes unusable.

What do you guys think? Any suggestions?
