#254867 2 2006-11-15T03:14:50Z Twistkill
Perhaps this is the solution:

Right-click anywhere in the window that N is running in, and click on Settings. Then click on the tab that has a folder on it. The slider that is there is for Local Storage, which is how the Flash Player saves data. Make sure the slider is all the way to the right, which is an unlimited amount of storage, and then click Close. I'm pretty sure that is the solution to your problem, but if this persists, you should also try re-downloading N.

If the slider is already currently all the way to the right, I don't know what else could be wrong. You could also try System Restore if you're using Windows XP.
