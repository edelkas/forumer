This is actually my first post on these forums, although I've lurked for a while. I'm currently writing a full walkthrough/ level guide for all of the official N levels, episodes 0-99. I've never actually played completely through the game, but I'm writing the easiest way I've found to complete each stage (not to get highscores) as I go along. I've gotten a fair bit done (I started with episode 25, and went to 33, before going back to 0 to work back through to 24, which is what I'm still in the process of doing).

I hope I get some interest from you fellows on the forums, since I'm starting to lose enthusiasm. It's just a project I saw the need for (since the NEHS isn't very complete). I want to have this done within a year from now, but I'm not going to post what I have until I'm done, unless someone wants to request a level I've already written (please, not too many requests, I'd like to spend more time just seeing this thing through).

One question I have is, where might I host this? I don't have a good server, and I'm completely broke so I can't buy a domain. Does anyone have some server space to host text/links? I'm not using images to map out paths, so a great deal of space shouldn't be needed.

So y'all tell me what you think about my project. Any "features" I could add to make it more useful? Any feedback is welcome.
-Ike
EDIT: I just wanted to clarify my reasoning behind making this walkthrough. Although the N wiki project is a wonderful way of making information/guides for each level, it seems rather orphaned as a project at this point in time (not to dwarf the efforts made by so many of the contributors). And the help thread works, but it can be disorganized and painful to browse through it before posting a level for help. So I simply decided that people would want a simple level guide for each level. I'm making it searchable, even as a text file, so if I don't host it on the internet with a way to link to each level, I can still have a single text file with every level that you can immediately search for an episode. Just explaining that for you .
