OK, I know that my second thought has already been suggested somewhere, but I'm going to suggest it again anyway, I'm pretty sure my first thought hasn't been suggested before though

When you first open N, you see various replays of someone playing N and invariably dieing at some point. I thought that it would be far more interesting if it used your own high-score replays (randomised) rather than what it uses currently. Obviously this would have to be an "unlockable" option after you had finished at least one column, to ensure that there were a fair bank of replays to be replayed.

Also, if we could see the level number at the bottom, of said replays it would be good, because sometimes, upon seeing the replays that are there currently, I think "wow, I haven't played that level in ages"... This would help me (and people like me, hopefully there are some people like me out there ) find these levels far more easily

Hopefully this all makes sense and with any luck, the first point hasn't been suggested before. If it has been, I apologise
