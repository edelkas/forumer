after more testing, we noticed that when a parameter is deleted or replaced by a space, newline character, letter or other character and saved, the next time the level is loaded and saved, that character is replaced by NaN (which makes sense).

#24367 7 2004-07-07T14:29:35Z Mare (guest)
well yeah, like this thread describes, you've got NaNs in your level code.

You'll have to manually remove the offending NaNs to fix your level code. In the second part (much harder), when you load the code with the existing NaN, N removes the NaN, which leaves an object missing a parameter:

original level code:

396,252,3,1,0,NaN


after loading entire level into N, pausing and recopying the level data from the debug menu:

396,252,3,1,0,


that'll cause bugs for sure.

I didn't check to see if there were already objects missing parameters, but if you've loaded code with a NaN in it and re-saved your level, then there are others.
