Quote
Porrasturvat is one of the very first games to use ragdoll physics in gameplay. The game was originally written just to contribute in the game development competition of a demoscene event called "Assembly", released a few days before the event was about to start, so that people would have some time to test the competition entries before voting. By the time when the event started, the game had already found its way to tens of thousands of gamers in just a few days, and the word about the game and how fun it is kept quickly spreading around different forums. The game won the first place in the competition.

Porrasturvat is also known as "Stair Dismount".
Download Porrasturvat

Quote
Truck Dismount is the successor to the Porrasturvat. After half a year it has already received over half a million downloads from the game home page, and it has also been included in numerous magazines' cover CDs and other websites for download. Like Porrasturvat, this game was again made for a game development competition at the "Assembly" -event next year, and Truck Dismount won the competition.

Truck Dismount is also known as "Rekkaturvat".
Download Truck Dismount

All quotes from Jetro Lauha's website.
