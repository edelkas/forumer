Have you simply pasted the map data into the userlevels.txt? I mean the format starting with 0s and 1s and things like that. If you have, that is wrong. This is the plain data. The correct format for a userlevel in a userlevels file is:

$levelname#authorname#type#data#

If you dunno what I mean, open a map in NUMA. The upper text box "Map data" contains the plain data, the lower box "1.4+ Map data" contains the userlevels format.

If this doesn't solve your problem, post your userlevels.txt here.
