#68348 4 2005-05-21T17:54:22Z Guest
a fast way to clear progress is to run N, then right-click and go into the "settings" menu. drag the storage slider all the way to the right -- it will warn you that this will erase all data. say "yes", then quit N; the next time you run N, say "yes" when it asks you if you want to allow it to store info on your HD.
