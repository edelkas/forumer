#298472 62 2007-02-18T03:13:24Z rennaT
Alright. So Line Rider is totally cool except that you can't share maps, right? Wrong. Tanner's here for ya.

Because Line Rider is a flash game, this is going to be filthy easy for anyone's who has already done anything with the N .sol. The Line Rider .sol is located in much the same place as the N .sol, except that the folder it is in is named after the website instead of "localhost." It should be at "C:\Documents and Settings\<username>\Application Data\Macromedia\Flash Player\#SharedObjects\<random letters and numbers>\official-linerider.com\savedLines.sol" if you are using the official Beta release which I recommend.

When you are at that file, all you have to do is back it up and replace it with another person's .sol. If you don't back up your .sol, all the maps you have made will be lost and be replaced by the other person's. When you have named the new file and have it in the right directory, all you have to do is click the load maps button, and the other person's maps should be ready to be played and modified.
