Quote: Jumpeplowski, December 03, 2006 03:38 pm
Okay, so I pasted the replay data in the little replay box in User Levels, and then pressed 'watch replay', but nothing happens.

Userlevels, not the boxes in Ned...

When you defeat a userlevel and then go back to the userlevels menu, it shows the replay data in that box afterwards. If you wish to view that replay later, select all of the data, and save it in a .txt file somewhere.

AMLT described how to use level and demo data, which is also in the editor_manual.txt that comes with N. If you do not have this file, for any reason, download a fresh copy of N off the Metanet website by clicking the banner at the top of this forum.

Just for clarification. PM me for any further questions or if you need something cleared up.
