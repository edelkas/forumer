#24299 6 2004-07-05T07:53:09Z Escher0
What I do is open up the task manager and set N's thread priority to below normal. On most decent machines, you don't actually need all those CPU cycles so changing priority rarely affects performance (unless something else tries to hog everything) and it allows all other programs to functoin fine.

Maybe in the future have an option to auto set either normal or below normal priority level? I've seen it done before, but I'm not sure about Flash.
