#23413 5 2004-06-02T18:20:26Z Guest
Hey,


Excellent -- yeah, missiles can go through doors which are open (even a tiny bit), which may explain what was happening. In the tests I've done so far, missiles haven't been able to get through completely closed doors side by side (as in your map), but I'm still testing.


As for the level code and screwed up jump pad, the first test I did had the screwed up object because I had copied a 'newline character' at the end of the level code.
(these characters are invisible, which adds to the confusion)


In this case, when you paste your data into the text box, click outside of the box and press [L] to load, you should be able to see a cilantro NaN at the end if you've accidentally added something that wasn't supposed to be there. (this is before you press [P] )


The second time, I put the cursor right at the end of the level code in the text file, pressed [shift] and then [Home] and pressed the up arrow key until I had selected all the text. Then the level loaded properly.

Hope this helps!
