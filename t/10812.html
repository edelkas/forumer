I suppose my first post in this thread didn't make sense. If you want an exact proof, you have to go about it with limits.
You can't simply define a number as 0.99~ with infinity nines, because infinity isn't a number.
So, 0.99~ is defined as the limit of the sequence
{0, 0.9, 0.99, 0.999, ... , (1-(1/10)^n)}
at infinity. The sequence is equivalent to the function 1 - (1/10)^x.
By the definition of a limit, the limit L of a function at infinity (assuming the function is monotone increasing or decreasing, which this function is) is any number such that given a number δ > 0, there exists an ε such that |L - f(ε)| < δ. For any given δ > 0, set ε to be -log(δ) + 1. Then |1 - f(ε)| = 1 - (1 - (1/10)^(-log(δ) + 1)) = δ/10 < δ.
Since there exists an ε for all given δ > 0, 1 is indeed the limit of the function as it goes to infinity, and 0.99~ is equal to 1.
