#259685 13 2006-11-25T23:07:54Z Tsukatu
Quote: greenpencil, November 25, 2006 11:00 am
What's the difference between Megabytes and Megabits?
1 bit = a switch that can be 1 or 0
1 byte = 8 bits
1 kilobyte = 1,024 bytes = 8,192 bits (1's and 0's)
1 megabyte = 1,024 kilobytes = 1,048,576 bytes = 8,388,608 bits
1 gigabyte = 1,024 megabytes = 1,048,576 kilobytes = 1,073,741,824 bytes = 8,589,934,592 bits

You can commonly find 500 GB (gigabyte) hard drives for sale, which basically contains 4,294,967,296,000 (4.2 trillion, or 4,200 billion) tiny magnetic switches that can each be a 1 or a 0.
(Except that they usually specify on the back of the box that the terminology they're using is 1 gigabyte = 1,000,000,000 bytes, so if you convert their 500 fake-GB into real-GB, you're actually buying a 465.6 GB hard drive.)

When you're shopping for a wireless router or adapter, you'll notice that Netgear, Linksys, Belkin, etc., don't use bytes because wireless connections aren't restricted to using a physical, 8-bit bus (that and they like to put as big of numbers as they can on the box ). So the standard G speed, 54 megabits per second, is really 6.75 megabytes per second.
