Decipher

This game is rather simple and quite challenging at the same time.
One person, in this case being me as I'm starting the game, posts a picture of a paragraph/sentence that is written in a code, fictional language, odd position, puzzle-like placement, etc...
Also in that same image can be a few hints. These hints can also be in a code, but should be easier to decipher than the actual code if they're coded as well.

The person who deciphers the previous code gets to make their own code for the next "round" to decipher.

Also, try not to make the images gigantic in pixels.
