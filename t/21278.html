~T3chno's Photoshop Sig Guide!~

*Note*:
First off, this tutorial will not require any brushes, other than the ones already pre-installed with Photoshop.

With that, let's get started.
In this turotial, you will be making:




Open a new canvas. Use these demensions: 350x125. It's short, sweet, and to the point.

Next, find a render that you'll be using. This is the main focus of you sig. Go to Planetrenders.net and sign up to get access to a great amount of renders. The render I'm using is here.

Scale you render for the perfect size and paste it into your empty canvas.


Now what you want to do is duplicate the render several times.[Ctrl + A then Ctrl + C on one layer to duplicate it.] Spread the renders out so no white is seen.


Go to the top layer. Now merge the duplicated renders [Ctrl+E]. All the renders should be merged except for your original one.Then move your original render to the top.


Click on the layer which contains the duplicated renders. What you need are the .PSD's for 3 different sigs. PM me and I'll send you some if you don't have any. What you're going to do now is Filter -> Distort -> Displace.
Use the preset settings. Find your PSD. Click OK. Repeat this again with your two other .PSDs.


Duplicated the duplicated-renders layer (now renamed mergerenders]. On that duplicated layer, Filter->Distort->Ripple. Then on that same layer, Filter->Distort->ZigZag. Use the default settings on both. Set the layer to Lighten and merge it down.


Duplicate that layer again. Go to Filter->Brush Strokes->Spatter.Use default settings. Merge it down afterwards.


Okay, now what we're going to use is a C4D. This is the one I used: From Planetrenders.net
Place it in your sig's canvas. Place it nicely because this is key. Set the layer to lighten or luminosity or whatever fits nicely.


Go to Layer->New Adjustment Layer-> Gradient Map.


Then lower the opacity of that until it looks cool. (mine was around 66%.)


Go to Layer->New Adjustment Layer-> Brightness and contrast


Now do the Gradient map thing again. But instead of lowering the opacity, set it to Luminosity.


Now go to Layer ->Adjustment Layer-> Photo Filter


Okay, time to use our standard brush. Take out the 45 px. soft brush (the round fuzzy one). On a new layer on top, draw lines with that brush that go along with the flow of the sig. Make sure the color is white. Erase the lines that run over your render. Set that layer to overlay.


Now to darken parts of the sig to add a lighting effect. Take out the gradient tool and use the following settings.


Use the gradient on a new layer. Set it to soft light and reduce the opacity to make it look better.


Now to brighten it up a little. We're doing this back and forth stuff to add some texture depth to this sig. Go to Layer->New Adjustment Layer-> Curves


Now create a new layer. Then Image->Apply Image. Take out the Burn Tool and use it to darken areas that are too bright.


Now for lighting.Make a new layer. Take out the 65 px soft, white, fuzzy, round brush and make one line over the render that follows the sig's flow.


On that layer, Filter->Blur->Gaussion Blur. Set the blur so that it looks like a ray of light shining.


Erased the light over the render then reduce the opacity of the layer.


Okay, for the final touch of lighting. As you can tell, this render was originally in a picture where light was hitting it from the top right. But when this Autobot was rendered, that part was cut away. So time to add that light back in. (This works for some other renders too). Take a 100 px soft white brush and use one click to put it along the border, where you think the source of light is.


Make a new layer and Image->Apply Image. On this layer, Filter->Blur-> Motion Blur. Make the blur strokes follow your sig's flow and don't make the blur too intense.(45 pixels is a good blur distance)


Erase over the render and set the layer to Lighten.


Okay, almost done. Now, you may want to take out that burn tool and darken places that don't look good. Now you're ready for the text. I'm using a font called Technovia which can be found on the internet (Duh). Try http://dafont.com. Place your text in a nice spot. Set the text layer to Soft Light and duplicate it twice.


Now for the border! Create a new layer, Ctrl+A, then go to Edit->Stroke. Use these settings:


Now save it as .png, or whatever you wish. And you're done!
