Either way, this is a way I've recently come across that does well to explain the meaning of atheism (thanks to a man named XOmniverse):
Let's take a look at the word "moral."
"Moral" means "having a behavioral code that encourages good actions."
There's also the word "amoral," which is a- (not) moral (moral), or "not" + "having a behavioral code that encourages good actions" = "not having a behavioral code that encourages good actions."
BUT, there is also the word "immoral," which is im- (against) moral (moral), and it means "having a behavioral code to the opposite effect of morality," or "having a behavioral code that encourages bad actions."
So we have the a- prefix which tells us that something is not something else, and we have the im- prefix which tells us that something is against something else.
So let's look at "theism" again.
Where "moral" means "having a behavioral code that encourages good actions," "theism" means "having belief that the divine exists."
We attached the a- prefix to turn "moral" into "amoral" - "not having a behavioral code that encourages good actions," or "lacking in a behavioral code that encourages good actions." In the same way, we can attach the a- prefix to "theism" to make it "atheism," which means "not having the belief that the divine exists," or "lacking in the belief that the divine exists."
We attached the im- prefix to turn "moral" into "immoral," which means "having a behavioral code to the opposite of morality," or "having a behavioral code that encourages bad actions." In the same way, we can add the im- prefix to theism to get "imtheism" (if such a word exists), which would mean "having belief to the opposite of theism," or "having belief that the divine does not exist."

Your definition of atheism is the definition for the theoretical word "imtheism." If you know the distinction between "amoral" and "immoral," you should see the distinction between my definition of atheism and your definition of atheism pretty clearly.
"Antitheism" is slang, and I never claimed that it was anything more. I have in fact even taken the time to mention every so often that it is slang. Either way, its prefix, anti-, has the same meaning as the prefix im-, which means "against." So "antitheism" describes beautifully the same concept as the theoretical word "imtheism," and it means "having belief to the opposite of theism," or "having belief that the divine does not exist." This is what you are describing.
(Note also that you can be both immoral and amoral - if you have [a behavioral code that encourages bad actions], you clearly are [lacking a behavioral code that encourages good actions]. In the same way, antitheism can be called a flavor of atheism because having [belief that the divine does not exist] means that you are [lacking the belief that the divine exists]. But do keep in mind that just because someone is amoral (no behavioral code) that he is not necessarily immoral (behavioral code to the opposite of morality), and in the same way someone who is an atheist (no belief in the divine) is not necessarily an antitheist (belief that the divine does not exist).)

Meaning is not of necessity defined by common usage. For example, "weight" is commonly used to mean "mass". However, this does not mean physicists are incorrect when they define weight and mass as separate concepts. When using these terms in serious discussion, the correct usage is not determined by majority, but rather by the technical meaning which is required in those circumstances. If you say that you've lost 5kg (rather than 49N) since you started going to the gym in casual conversation, that's fine. If, however, you write on your physics exam that something "weighs" 50kg, you will lose marks, because that usage is incorrect for the context regardless of popularity.

By the same token, many people use "atheist" to describe what I would call an "antitheist". Their definition of atheism is used in common speech, but is not suitable for scholarly debate. In a similar fashion, when asked about my religious affiliation I usually say that I am agnostic, rather than that I am an agnostic atheist, because most people would understand what I mean. However, when in-depth discussion arises, we should adhere to the technically correct definitions - that agnosticism is separate from theism and atheism, and that atheism is simply lack of theism.

In upholding the correctness of this definition over macaddict's, we may examine an unfortunate problem with the latter: theistic and atheistic are supposed to be binary descriptors. If you're not one, you're the other. However, under macaddict's terms, there are many positions which are neither.
