I have an idea that I think would be awesome to implement.

I was thinking back to when Arachnid asked for all the collaboration accounts on NUMA so that he could disable the voting priveleges on all of them. But wouldn't it be easier if you could just have the option to choose a collaboration option when submitting a map?

Here's how it would work:
  • When you are submitting a map there would be a checkbox above the Map Name section that you could select that said something like "collaboration?" or "Multiple authors?". Doing so would open up a single text box with an option to create more text boxes beside it.
  • In the text boxes would go the names of the author(s) that you collaborated with. This would then signify that you and the said author(s) created a map together and that you are submitting it to all the names. All names would also be verified so that you couldn't put in a name that didn't exist.
  • When the map is submitted and voting takes place on it the votes will go not only to the author that submitted it but also to the author(s) that were involved as well. For example, if Yahoozy_Guacamole and remote collaborated on a map and Yahoozy submitted it any votes that were placed would also count toward remote's average NUMA rating.
  • To prevent faulty ratings, and using the example above, if remote were to rate the map a 5 the rating would only go toward Yahoozy's NUMA rating and not remote's, in this way eliminating any ability for personal gain. Likewise, Yahoozy would be able to rate the map as well because his vote would only be counting toward remote's average NUMA rating.
I know that there are probably a few holes in this system. Fortunately that's where you, the community, come in. What do you think?
