#86178 2 2005-07-26T12:13:12Z shoftee
To know which object to project out of the other, you should first think which object is supposed to move, and which not. Obviously, if the object that's supposed to move(or also called a dynamic object) will have to be projected out of the other object.
Of course, that's the idea if only one object is dynamic. If both objects are dynamic, then you'll have to move each object by a certain amount. That amount depends on the mass of the objects. To fix this problem... you need to know the mass of each object. If object A has mass M and object B has mass N, and you have a penetration vector with length plen, then you have:

lenA = (M/M+N) * plen; // projection length for shape A
lenB = (N/M+N) * plen; // projection length for shape B

I think that's what you were looking for.

You should know that I haven't tested this, but I'm pretty sure it's correct.
