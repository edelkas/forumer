#193251 2 2006-06-22T22:18:42Z Hellheart
The problem with propulsion is that the user has some control over where the ninja launches from and where he goes in midair, causing some nasty issues unless you're doing a DDA. It's good to remember that if the ninja hits an exit the user loses control until the ninja hits a jumppad, which helps there a lot.

1. An unusual form of Thwump propulsion uses the map Slippy. You should also be familiar with the thwump that moves backwards only until it goes off the map, as that can be used fairly easily to push the ninja through bounceblocks and oneways.

2. You can stealthily place oneways inside a door or a set of doors to control where N goes somewhat easier. I'm not sure if the door voids oneways placed in the same direction, but I know oneways placed perpendicular can really affect normal doors.

3. Bounceblock propulsion relies on the ninja somehow not being able to go through the block, which is usually what happens at high velocities. Diagonal directions work best for this purpose; bounceblocks will certainly serve to modify the ninja's flight path.

4. I've seen times where a ninja compressed into a space that hits a locked door switch - where the locked door keeps the Ninja trapped in - can blast him out quite well. This is hard to pull off, though, in a non-DDA.

Normal Door Propulsion: in my experience, it only works with 6 gold on the door-otherwise you leave gold behind or the propulsion fizzles out. It's tough to pull off, and the only way to control it is the speed at which the ninja hits the door.

Bounceblock Propulsion: The easiest way (for me) is to c-snap the gold to the edge of the bounceblock. From there, varying the amount of gold changes the propulsion.

Others: Aside from the Lucidium Effect, seen in Tower Loop, the main I'll mention is from joe_kapow's awesome DDA Immortal, which was sniped off the top rated page so it's unlikely that you've seen it. The idea is that a thwump pushing backwards onto a oneway can either push the ninja through the oneway, or cause him to shoot off to the side. I've never actually used it, though.
