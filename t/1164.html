Basically, you can simulate what I'm thinking with locked doors, but this would be far easier on the designer. Have a square area (minimum 1 square, but could be 2 x 2, 3 x 3, etc.) that is surrounded by doors that are all triggered by a single switch.

Or, a much more flexible version would be to string any number of doors together into a single switch (maybe just auto combine switches stacked onto the same square?). The problem with trying this now is that N doesn't always trigger every switch stacked on a single square. This would solve that problem and still allow the square orientation noted above.
