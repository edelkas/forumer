#266794 2 2006-12-09T01:13:34Z LittleViking
There's no difference between 510 and 512 MB of RAM. If that's the bare minimum requirement to run it, you would be fine. However, I've heard people saying that the real recommended amount of RAM to turn on all the visual effects in Vista is more like 2 GB. If you only have 512 MB, I'd stick with Windows XP. Edit: Oh, I see you've already installed Vista. Well, in that case, it would still probably take an extra 512 stick to run Aero.

Also, I've heard that Windows Vista requires Pixel Shader 2.0 for some of its effects, which I think is ludicrous. Why should I have to buy a $200 video card just to run the operating system? But yeah, for your question, a new video card and maybe a RAM upgrade should allow you to run Aero.

Edit: Also, keep in mind that I have no experience with Vista. I haven't installed it and probably never will on my computer. Just think of this as common sense advice from an experienced computer technician.
