#404025 (forumer) 24 2007-10-23T14:01:00Z Wannas1693
Mmm. Fixing up the grammar would be nice. And try to place the text in order from top to bottom--it tends to be in better reading order then.

A note on your graphics; I suppose that you have downloaded N Poser. Don't. For some reason, the downloaded version lacks the ability to retain a fixed size, and the entire program scales to the window instead of the normal specifications. Depending on your browser, resolution, etc. this will probably cause the ninja to be slightly scaled up. I recommend either scaling the ninja so that it corresponds to the in-game one (the scale slider in N Poser is below the RGB colour sliders; move it towards the left until it is about the same size, and then calibrate it fully with a close comparison in MSPaint or a similar application, and write the result down).

In other words, it could use some work. But at least I can read it.
