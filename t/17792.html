Quote: Azjps, June 12, 2007 07:43 pm
By the way, while I'm here, is there anyway to adjust the size of an image (outside of directly changing the image)?

You could be either meaning the size as in the dimensions or as in the storage size (number of kB). For the first, if you're using paint, just go to Image>Stretch/Skew. If you mean the storage size, just save it as a .jpg or .gif rather than a .png. While it will look worse, quality doesn't really matter for a route map
#330725 5 2007-06-13T03:21:53Z Atilla
On the image thing, some programs (the GIMP) let you set the level of compression/quality for PNGs, JPEGs and so on. Obviously, increasing the compression/decreasing the quality will decrease the file size. Paint doesn't give those options, if that's what you've been using... I'm not sure what level of compression it uses by default.
