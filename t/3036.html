#2730 1 2005-05-03T02:28:26Z Raigan (guest)
Hi,
At long last, v1.4 has been finished.

You can get it here:

pc: http://www.harveycartel.org/metanet/n_v14pc.zip

mac: http://www.harveycartel.org/metanet/n_v14mac.sit


We're not releasing it "officially" until a week or so has passed and we know it's stable; that way if there are any bugs we can fix them before all hell breaks loose.

Please let us know about any bugs/etc. you find by reporting them on this thread.
Please do NOT post 1.4 bug reports anywhere else until the release is "official".


So, what's new in this release? Lots of stuff.

We added an unlockable feature, support for playing user levels in-game, and a whole whack of improvements to Ned.

We couldn't get filebased save/load working the way we wanted to, however we think that the current version does a pretty good job.

As always, please familiarize yourself with the readme and editor manual for more details.


This will be the last release of N for a while; right now we're starting to work on a new game for next year's IGF, so we'll be busy until at least september. We will almost certainly be releasing one or two more versions of N before we're finished with it for good (for instance, when the next flashplayer is released we'll want to release a new version of N to take advantage of the increased performance).

We'll be releasing the source code when we have time to fix it up; by october at the very latest. We know that we still have to finish the tutorials as well, but we've also got 8762565 other things to attend to right now (such as getting a new game done), so it will have to wait until we have a few weeks of free time.


Anyway, we hope you like it. Thanks again to all of you guys for the encouragement and support, you really kick ass.

mare and raigan

p.s - The highscore/server problems have still not been resolved; right now the highscores are working, however that might not last. We'll hopefully be changing servers in a month or so.
