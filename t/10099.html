#181969 2 2006-05-29T21:50:15Z RedKlonoa
This is preety complicated, but easy to do if you have the time.
First to do collisions.
If Hero.x-4 is collision free with solid objects
Jump: Object Hero, x-4, relitive
This moves the hero left. I suggest using this with the event Left Keyboard, not the events Left Pressed or Left Released.
btw, x- = left, x+ = right, y+ = down, y- = up

now, for projectiles... this is a bit more complicated than movement.
to make it simple, ill just make it so u control your aim by the mouse 
Event Mouse/Global Mouse/Global Left Pressed
Create instance of object
Object = Shot

For object Shot
Event Create
Set movement toward point
mouse_x,mouse_y
Event step/step
[If object collides with...
Object = shot
Collides with = solid only]
destroy object (self)

I hope this helps, but maybe not.
