Forum [?] (Custom Icon)
http://nmaps.net/133174

Restart NReality (a mod of N, download @ n.infunity.com) to retrieve this new update of Custom Icon

To set custom Icon to objects, used
||||,_icon,x_offset^y_offset^url

Please kindly beware that in N, all the object icon size are scaled down by default, so the image you loaded will probably be scaled down too. You can set _xscale,100 and _yscale,100 to restore your image default size.
The eye movieclip of the drone will disappear if you change its icon.

Since the image loaded into the object will not auto center itself, so you probably need to set x_offset and y_offset to adjust the correct position of the image to the object

e.g. the zap drone here
||||0,_icon,-10^-10^http://metanet.2.forumer.com/style_images/Invision_Power_Board/icon14.gif;0,_xscale,100;0,_yscale,100;
