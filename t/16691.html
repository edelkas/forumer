#309398 10 2007-04-01T04:08:43Z George
Okay, you can start from the very beginning.

1. Download N with this link.

2. Create a folder called 'N' in your 'My Documents' folder and save the .zip file in there.

3. Download Winzip and install

4. After installing, right click on the zip file and select 'Extract to here' in the Winzip subsection.

5. Now run N and check out your userlevels.
