Hm. I'd show you a screenshot of this in action, but it doesn't work that way. Sorry.

---

Step 1: Go here, install it. Don't go for the lite package.

Step 2: Open some random song in it.

Step 3: Press ctrl+P. Go to Visualization. Select "Advanced Visualization Studio v2.81b [vis_avs.dll]". If you have a newer version, bless you. Start it.

Step 4: Select a preset. Find one you like or one you find particularly trippy.

Step 4b: If you can't find one you like, go here. Browse by favorite count if you want. Go here for my half-crappy presets. They're all at least a year old.

Now the real fun starts! As soon as you stop staring at the screen, go to the next step.

Step 5: Is AVS running? Good. Open up the AVS editor.

Step 6: Click "Settings", select "Display".

Step 7: Look at top right. See overlay mode? Enable it.

Step 8: Click on the box labeled "color". Change it to 202/202/208.

Step 9: Open up N. Have fun.

---

Other things to do:

Change the overlay to the color of the N walls... or the overlay color to the color of the N walls. Guess what happens?

Change the overlay color to 121/203/227. Yes, you can have your rasta drones now. Heck, you can skin your drones now.

---

Once you stop staring, twiddle with the settings. You should be able to make the colors blend better to the usual background...

Have fun... don't die from starvation!

P.S.: AVS was used to make my avatar and sig.

P.P.S.: Yeah, you want a fast computer for this

#324228 55 2007-05-25T22:07:39Z Gforce20
Dude, here is like the best use for this ever.

Enter AVS editor, make new visualization, add effect Trans / Color Clip. Set the outcolor to 121 121 136 (walls). Make sure that you're also clearing each frame (Main). Then set the transparent color (Settings > Display > Overlay mode) to the object color you want; the objects of that color all have the wall color.

Set the overlay mode to 202 202 208 (background color in N) for an all-walls surprise. You can see the borders of tiles other than E, D, and 5, but everything else is all walls. Set it to bounceblock color and you have some tiles that bounce.
