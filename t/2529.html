First of all, we're crediting each author and listing each map name as named on NUMA.

we're testing maps on a bunch of things:

-speed
-difficulty
-fun
-uniqueness

and we're trying to ensure the greatest possible range of authors.

So far we've noticed that many maps run very slowly because of the number of objects... we may have to omit some because of that.
And tons are so difficult we've had to develop a few new levels in our rating system: very very hard, insanely hard, etc.

We're trying to be fair, and to select the best maps while considering all those things. We totally welcome input when 1.4 is finally released...
