NHigh version 2.0.1

This program reads the highscore list and gives you various types of information (for example: list of new 0th scores, list of top players, etc.)

New in version 2.0.1

- Fixed: Highscore download now works again.
- Fixed: Unsubmitted scores report now works again.

Features

- Generated reports include: new 0th scores, players with most 0th scores, players with most top-20 scores, information about a specific player, and more.
- save and load highscore lists
- automatically ignore specified players (to be used for fake highscore submitters)
- Cross-platform (I have tested on Windows and Linux).
- Full source code (written in Python)

Installation

- If you downloaded the Windows executable version, just unzip and run it.

- If you downloaded the source version:
1. Python 2.3 or later is required. Download and install it
from http://www.python.org/download/
2. Run nhigh.pyw. On Windows, this is done by double-clicking the file.

Basic Usage:

First thing to do is download the current highscores by selecting File->Download (This takes a few minutes). Then you can view different reports about the highscores. Some reports compare the currently loaded scores with a file containing previously saved scores - so it's recommended to save the highscores you've read to a file before quitting.

Configuration:

Configure NHigh using Tools->Options. To reset the configuration, search for the file "nhighconfig" and delete it. On Windows it is usually stored at:
C:\Documents and Settings\<user-name>\Application Data\NHigh

Downloads

Windows executable version: (2.2 MB, Python not required): at Quicksharing.com

At the moment when you add someone to the ignore list their scores are not saved at all in addition to not seeing them in the program. In my opinion it would make more sense for the high scores archives to have exactly the same high scores as you would see in N itself, and for the NHigh client to do the ignoring rather than not recording them in the archive. This way you could always check the standings as they are displayed in the game if you wanted.

There is a workaround: first you remove players from the ignore list before downloading and saving the high scores. After that you put them back into the list, close and restart NHigh, and load the high scores you downloaded. This gives you a complete save file while ignoring the players you want in the program, although it's irritating if you are removing and re-adding lots of players to the ignore list.
