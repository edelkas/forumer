i'm going to have to field this one since it's my fault that, no, you can't change your oven.

i assumed that the only reason anyone would want to change their oven was if they forgot it.

if you just want to change the oven, but haven't forgot it, i guess you could PM me with the current info and the changes you want -- assuming i can logon with the current info, we can change it. but please don't everyone start doing this, as it's a long and painstaking process!!
