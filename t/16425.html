Trap door propulsion? Yes, that might take some practising.

Insert a trap door somewhere and put the switch a tile from it. This works in all 4 directions.



It requires you to be moving already, so it doesn't work properly if you start by putting the ninja on top of the trap door.
#306034 3 2007-03-18T08:08:34Z AMomentLikeThis
Trap door propulsion.

A basic version of this:
- Place the ninja on the floor somewhere.
- Press "c" on editor to go into quarter-snap.
- Make a trap door 2 squares above the ninja, placing the trap switch 3 quarter-snap places above it.
- Jump directly upwards, you should get launched up.
