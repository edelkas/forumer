#119459 3 2005-12-01T03:03:31Z Eldrial
both Macs and Windows use the same .sol file. their formats are no different and are compatible.

Windows .sol location: C:\Documents and Settings\(Username)\Application Data\Macromedia\Flash Player\#Shared Objects\ usually a one way street from there...
*Note: Application Data will probably be a hidden folder

not sure if this is exact because i don't have a Mac....
Mac .sol location: Home > Library > Peferences > Macromedia > Flash Player > #Shared Objects\ usually a one way street from there...


just put the .sol in that location. replace the current .sol if necessary. always keep a back-up.
