I can see nobody will be able to understand what the hell I was talking about so Ill explain. Im kinda guessing on how this works but it seems sensible but here goes.

Whenever you click to play a level (ie click "play game", then choose an episode) a variable is set and depending on what is contained in the variable a different level is loaded up. So for instance if the word "deli" is contained in the variable, episode 1 is loaded up. The cheat mode lets you directly enter a value into that variable. So for instance if you type "deli" into the cheat mode prompt, "deli" is entered into the variable and the episode 01 is loaded up. Since you can automatically play the 1st episode of each column M&R didnt choose an easy word. Instead they choose a really complicated long one, beleiving that it would be impossible for somebody to guess it.
