#47882 6 2005-01-25T04:49:28Z Tsukatu
The n_v13c.sol file is the file that contains all of your saved game information, namely your personal highscores. Try running a search on your computer for that file. Make sure that it's substantial in size. If it's a few KB, then you're permanently screwed. If it's larger, then the problem is more confusing than it originally seemed. If there are two, we've found your problem: move the larger one into the same folder as the smaller one, replacing it. The problem could have resulted from your computer spontaneously deciding to reorganize itself. Did you recently un/reinstall anything having to do with Flash / Windows?
