hey,
just wanted everyone to know -- now that Adobe has finally launched "Apollo" (no pun intended), it'll be easy to implement proper file-based save/load in the next version of N.

We haven't looked into the other features of Apollo, there might be stuff for resolution/gamepad/etc. functionality (i.e proper stand-alone application functionality).

Also, we've been using actionscript3, and it's _fast_.

Sadly, the demo we wanted to get done for GDC wasn't finished, soon we'll post something about how things are going on the Robotology front. There is still a lot of work to be done, but things are definitely coming together in exciting ways!

So, now we just need to get Robotology finished so we can start work on N v1.5
