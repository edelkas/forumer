#323196 5 2007-05-22T00:08:41Z ZeroTruths
Personally, this is how I do it:
var myListener:Object = new Object();
myListener.onKeyDown = function() {
	switch (Key.getCode()) {
	case Key.LEFT :
                mc._x-=10;
  break;
	case Key.RIGHT:
                mc._x-=10;
  break;
        //Obviously, you can add more cases for more keys...
};
Key.addListener(myListener);

I use VControl for my C++ work; it's a library that's intended to abstract away the keyboard into a "virtual controller" (hence the name). The short of it is that you can take a file that looks like this:
jump: key Space
left: key Left
right: key Right
feed it into VControl's initialization, and then turn your input loop into this:
  while (SDL_PollEvent(&event))
  {
    VControl_HandleEvent(&event);
  }
  for (int i = 0; i < numActions; ++i)
  {
    if (curInputState[i] != 0)
    {
      switch (controlTable[i].name)
      {
        case INPUT_JUMP:
          foo;
          break;
        case INPUT_LEFT:
          bar; 
          break;
        case ET_CETERA:
          break;
      }
    }
  }
where numActions is the number of actions you have recorded in the text file and controlTable is an array of VControl_NameBindings that you get when you initialize it. It's all pretty simple; you don't need to worry about keydowns, keyups, and the like, and you can assign arbitrary names to keys (and multiple keys can get the same name, for example if you wanted to have multiple keys for left and right).

The big win, mind you, is that all of your control definitions are in a text file, so they're easy to change, either by you or by your players.
