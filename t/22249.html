#19916 1 2008-04-13T04:46:07Z usaswim
I'm introducing an entirely new interface, one that is more functional. I feel that the current NUMA feels a little empty, with only people submitting maps and not much more going on. I'd like to have more of a map-making community, rather than just a storage bin. Some things I'd like to implement are things like map-maker of the week, bring back the Sunday N or start a similar weekly newsletter, and have some featured maps that get selected by chosen members of NUMA daily. But overall, it would be cool to have more of a social map-maker network. None of this takes serious coding, but it will mean having to start from scratch with the layout. I don't think that it will use up much bandwidth, because there aren't any large images. There is a very simple solid-color background and a few small images around. The only reason it looks frightening is the font choice and the colors. The footer is weird, because I didn't know where else to put those icons. The map listing is double-columned to save space instead of scrolling down a lot, and I don't really think too many people acknowledge the map information anyway (other than the author and description). There is no ad as of yet to put, because I wasn't sure whether or not I could put it on the bottom.

I'd like to hear your feedback, and whether or not this is a step into the right direction. As for the compensation, I don't really care about it, because I believe this is a community effort.

Image. This is only the maps tab.
