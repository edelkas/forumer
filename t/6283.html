This is an idea that is slightly inspired by the neddis thread. Basically, I'm putting up a tileset I made, and all that's in the map is N, the exit and some gold. Every time someone changes the map, they can add three objects into the map. The first person can just edit it, after that the first person to beat the edited level makes the next edit. The goal is to make an edit in such a way that the map is made slightly harder without making it impossible. Here are the basic rules:

1. Beat the newest version of the level and add three objects of your own. When you post your updated version, post it as a text attachment with the new level data on top and your replay of the old version below it. Oh, and put the old data with the replay just to make viewing it easier. The first person to edit it wouldn't need to put in a replay because it's pretty hard to die on this level as is.

2. A person can't post two edits in a row.

3. If two people post an update at the same time, the person with the fastest replay is the one whose edit is used.

4. If it reaches the point where no one can beat the map, (or this thread dies) the player with the most edits wins. If the thread survives that long, the winner creates the next tileset to be played on.

Try to avoid instantly making the map too insanely hard right in the beginning I'm hoping to see this level get gradually harder. Anyway, here's the tileset.
