This Flash-based game is remarkably similar to N in many respects. There's only one level so far (and it eats memory like crazy) but the level is very expansive, so it'll give you more than a few minutes of entertainment. In this game, you control a character similar to N's ninja (he even wears bellbottoms). The physics are kind of the same; there is a Sonic type element to this game too, where you can run around loops. You can even unlock a walljumping feature, if you can find the right secret area.

My guess is that the developers read M&R's tutorial, and have come out with this game based on it. It still needs a lot of work, and more levels (and the memory thing is irritating if you play for extended periods of time). So go ahead and try it already!
